# 实战口才速查

## 一句话回应结构

`承认客户表达 → 复述可能含义 → 问一个澄清问题 → 提供证据或选项 → 确认是否继续`

口才的检验不是客户停止反驳，而是客户能说明自己的标准和下一步。

## 问题路由

| 原话主题 | 核心判断 | 章节 |
|---|---|---|
| 忙、烦、不认识、换渠道 | 时间、许可、信任 | ch01 |
| 银行股票、概率、退休金、理赔 | 功能和比较口径 | ch02 |
| 公司会垮、霸王条款、分红、品牌 | 三层信用证据 | ch03 |
| 健康、年轻、社保、储蓄、旧保单 | 替代资源净缺口 | ch04 |
| 房贷、没钱、贵、产品太多 | 预算五层与方案减法 | ch05 |
| 教育、养老、车房、旅行 | 场景到险种五步 | ch06 |
| 条款多、考虑、问家人、只要便宜 | 合同三层与犹豫分流 | ch07 |
| 不值、失联、退保、理赔 | 服务补救 | ch08 |

## 证据优先级

具体合同与批注 > 当前官方监管或公司文件 > 可核实客户数据 > 一般教育材料 > 个案故事。故事只能解释，不证明普遍结果。

## 禁用表达

- “您这个想法就是错的”
- “绝对安全、一定赔、肯定不会倒”
- “现在不买以后一定后悔/买不到”
- “别人都买了”
- “只要相信我，不用看条款”
- “先签了再慢慢解释”
