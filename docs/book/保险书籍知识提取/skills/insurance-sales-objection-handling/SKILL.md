## Core Frameworks & Mental Models

### 1. 客户原话翻译器

先把原话翻译为时间/许可、比较口径、机构证据、替代资源、支付能力、险种目标、合同决策或售后问题，再回应。原话只提示假设，需用复述和追问确认。

### 2. 观念重构

询问观点来源，找出安全、收益、流动、保障、便利或公平等评价维度，承认合理部分，补充缺失维度，再由客户自行比较。储蓄、投资和保险按功能分工，不做错位排名。

### 3. 需求与预算

替代资源按范围、金额、持续性和机会成本检验；剩余缺口再与预算五层对照：生活、债务、应急、核心保障、长期储蓄。预算不足时做方案减法。

### 4. 场景到险种

`生活事件 → 可能损失 → 已有资源 → 优先级 → 产品五要素`

产品五要素包括责任除外、保额限额、期限续保、费用缴费和给付方式；不按养老、教育、购车或旅行机械绑定产品。

### 5. 合同决定

条款按决策摘要、关键限制、执行信息三层阅读。犹豫按缺信息、需比较、共同决策、时点不合或明确拒绝分流；价格必须在同责任、保额和期限下比较。

### 6. 服务补救

接收问题、复述事实与期望、核对合同记录、给出选项/责任人/时限、跟踪改进。退保和理赔坚持客户利益、真实资料和正式渠道。
