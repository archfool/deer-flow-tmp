# Chapter 1: 第一章 化解客户拜访阶段遇到的问题

## Core Idea

拜访阶段的口才首先是边界感。客户说忙、烦、不认识或留下联系方式，表达的是注意力、信任和联系许可；回应应降低沟通成本、说明身份来源与价值，并允许客户结束，而非用更强话术抢占时间。

## Frameworks Introduced

### 客户原话翻译器

- “很忙” → 当前时间不便，或不愿投入时间。
- “免谈/真烦” → 明确拒绝，或对高频触达不满。
- “不认识，凭什么信” → 缺少来源、资质与服务证据。
- “需要时联系” → 客户希望掌握后续触达权。
- “选择其他渠道” → 渠道和服务偏好，不一定是产品异议。

### 三十秒边界回应

承认客户状态 → 说明身份和联系来源 → 用一句话说明主题 → 给出结束、资料或短约三个选项。客户选结束即停止。

## Key Concepts

- **注意力许可**：客户愿意在当前时刻听取有限信息。
- **后续触达权**：客户决定是否、何时、通过何种渠道继续联系。
- **初始信任**：由透明身份、来源、专业证据和尊重边界逐步建立。
- **渠道偏好**：客户对线上、银行、代理或经纪等服务方式的选择。

## Mental Models

- 首次拜访的目标可能只是留下可信、无压力的印象。
- 苦日子或消费习惯是了解风险承受方式的入口，不是需要纠正的人生态度。
- 客户不信任时先提供验证路径，不要求先相信人。

## Anti-patterns

- 把明确拒绝重新解释为“客户其实有兴趣”。
- 用熟人、礼貌或突然上门迫使客户留下信息。
- 贬低其他渠道以证明自己可信。
- 客户要求自主联系后仍频繁跟进。

## Worked Example

客户说“留个电话，需要时找你”。销售人员确认是否同意接收一份公开的保单检视清单；客户若不同意，只留下官方可验证联系方式并停止主动联系。口才体现在把权利说清楚，而不是找到继续追踪的借口。

## Key Takeaways

1. 拜访异议先翻译为时间、信任、许可或渠道问题。
2. 三十秒回应提供结束、资料和短约选项。
3. 初始信任来自可验证信息和尊重边界。
4. 客户掌握后续触达权。
