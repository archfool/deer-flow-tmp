# Chapter 7: 第七章 主动促成客户签订合约

## Core Idea

条款多、考虑、征询意见、非本人做主、人员离职、只买便宜和询问礼品，都是决策质量问题。促成应降低理解难度、让共同决策者进入、比较完整成本并说明服务机制，不以礼品和技巧替代合同价值。

## Frameworks Introduced

### 合同三层阅读

1. **决策摘要**：目标、核心责任、保额、期限和总成本。
2. **关键限制**：定义、除外、等待、续保、现金价值与非保证利益。
3. **执行信息**：告知、缴费、保全、理赔和投诉渠道。

### 犹豫分流

缺信息、需比较、需共同决策、时点不合适或明确不购买。分别对应补资料、同口径表、共同会谈、约定触发条件或结束。

### 总成本比较

便宜与否需在相同责任、保额、期限、免赔、续保和服务下判断；礼品不改变合同价值，赠送与激励按当前规定和公司制度执行。

## Key Concepts

- **共同决策**：对家庭或组织资金和责任有实质影响的人共同参与。
- **决策摘要**：帮助理解但不替代合同的关键内容页。
- **服务承接**：人员离职后由机构和正式渠道持续服务。
- **同口径价格**：控制责任和期限差异后的成本比较。

## Mental Models

- 条款复杂时分层解释，不以“相信我”跳过。
- 客户征询意见是合理治理，不是成交障碍。
- 巧妙离开意味着尊重边界并留下清楚记录。

## Anti-patterns

- 催客户不看条款直接签名。
- 教客户绕过家人或真正决策者。
- 用礼品、返佣或虚假限时影响决定。
- 以最低保费比较责任不同的产品。

## Worked Example

客户只想买最便宜方案。顾问先确认其核心目标，用同保额和期限比较两份合同，展示较低价格对应的免赔和续保差异。客户若仍选择低价，在充分理解后可以成交；顾问不借机升级，也不隐藏代价。

## Key Takeaways

1. 合同分决策摘要、关键限制和执行信息三层阅读。
2. 犹豫按信息、比较、共同决策、时点或拒绝分流。
3. 价格比较必须同口径。
4. 礼品和人员关系不替代合同与机构服务。
