# Chapter 5: 第五章 保险费支付问题

## Core Idea

贷款、资金紧张、保费贵和担心未来无法续缴，说明方案必须接受现金流约束。沟通的专业性在于帮助客户区分必要生活、债务、应急、保障和储蓄目标，并减少方案，而不是劝客户为保费牺牲财务安全。

## Frameworks Introduced

### 预算五层

`必要生活 → 债务义务 → 应急储备 → 核心风险保障 → 长期储蓄与可选责任`

前一层不稳定时，不以后一层挤占。用收入下降、失业或大额支出情景测试长期缴费。

### 方案减法

先删除与核心缺口无关的产品，再调整可选责任、期限、免赔和保额结构；主要责任保障优先，儿童和储蓄方案按剩余预算安排。

### “赚钱险种”澄清

确认客户要保障、稳定现金流还是投资回报；保证与非保证利益分开，保险不因具有现金价值就等同于高收益投资。

## Key Concepts

- **核心保障预算**：用于转移客户无法承受风险的可持续支出。
- **压力情景**：收入或支出不利变化下的缴费测试。
- **产品堆叠**：推荐数量超过需求和理解能力。
- **缴费中断后果**：失效、减额、现金价值损失或重新核保等合同影响。

## Mental Models

- 保险不是奢侈品，也不是必须品；是否配置由缺口与能力共同决定。
- 预算不足时先做减法，不用情绪做加法。
- 父母收入和责任保障经常支撑儿童方案，但仍按个案排序。

## Anti-patterns

- 建议客户借钱、刷卡或动用全部应急金交保费。
- 用生活小消费羞辱客户预算选择。
- 将储蓄型产品包装成“赚钱且无风险”。
- 一次推荐过多险种，利用复杂度掩盖不适配。

## Worked Example

房贷家庭认为推荐太多。顾问按预算五层删除高额储蓄计划，保留医疗与主要责任人的基本保障，并用失业六个月情景确认仍可承担。孩子教育目标暂由灵活储蓄处理，收入稳定后再检视。

## Key Takeaways

1. 保费预算排在生活、债务和应急之后。
2. 用不利情景检验长期可持续性。
3. 预算不足先减少非核心产品与责任。
4. “赚钱”需求要区分保障、现金流和投资。
