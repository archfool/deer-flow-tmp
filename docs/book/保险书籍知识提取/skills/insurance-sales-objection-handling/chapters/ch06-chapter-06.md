# Chapter 6: 第六章 客户选择险种时的问题

## Core Idea

月光、退休、教育、购车、房贷、无社保和旅行等场景不是产品答案，而是需求入口。险种选择应先识别保障对象、损失类型、时间与预算，再用责任、期限和给付逻辑筛选，不能按生活事件机械绑定产品。

## Frameworks Introduced

### 场景到险种五步

`生活事件 → 可能损失 → 已有资源 → 处理优先级 → 产品五要素比较`

产品五要素是责任与除外、保额/限额、期限与续保、费用与缴费、赔付/给付方式。

### 场景分流

- **退休**：健康、长期现金流、流动性和照护。
- **教育**：固定时间目标、父母责任和资金灵活性。
- **车与房**：财产本体、第三者责任、贷款责任和家庭现金流分别处理。
- **无社保**：先识别基础医疗、养老和职业风险缺口。
- **旅行/通勤**：频率低不等于后果可承受，按活动和合同责任核验。

## Key Concepts

- **生活事件**：改变风险暴露、责任或现金流的触发点。
- **损失类型**：费用、收入、财产、责任或长期现金流。
- **给付逻辑**：费用补偿、定额给付或第三者责任赔偿。
- **产品五要素**：比较险种的统一合同维度。

## Mental Models

- 一个场景可能需要多个工具，一个产品也可能不适合该场景。
- “不差钱”提高选择空间，不消除责任和适配判断。
- 低频活动是否投保取决于后果、责任与自留能力。

## Anti-patterns

- 听到教育、养老、车或旅行就立刻推荐固定产品。
- 月光客户用强制储蓄产品替代预算治理。
- 对退休或无社保客户忽略可保性与支付边界。
- 只看低价，不看责任、免赔和续保。

## Worked Example

客户新买贷款车辆，问“需要什么保险”。顾问分别识别法定要求、车辆损失、第三者责任、车上人员和贷款/家庭现金流，不把一份套餐称为“全险”。按车辆使用、驾驶人、责任承受和预算比较具体合同。

## Key Takeaways

1. 险种选择从生活事件和损失类型进入。
2. 已有资源与优先级先于产品比较。
3. 用产品五要素统一评价。
4. 不用场景标签机械绑定险种。
