# Chapter 2: 第二章 有效纠正客户对保险的偏见

## Core Idea

所谓偏见往往包含客户经验、价值观和比较口径。沟通不应以“纠正人”为目标，而应把兴趣、忌讳、保费去向、银行股票比较、费率、概率、退休金和理赔担忧拆成可验证命题，再用同功能、同期限、同风险口径讨论。

## Frameworks Introduced

### 观念重构四步

1. 询问客户这句话来自什么经历或信息。
2. 找到其真正评价维度：安全、收益、流动、保障、便利或公平。
3. 承认合理部分并补充缺失维度。
4. 请客户用新框架自行比较，不要求接受预设答案。

### 工具功能坐标

银行储蓄主要解决保管与流动，股票承担市场风险追求回报，保险按合同转移约定风险或安排现金流。一个工具不因不能完成另一工具的任务而“更差”。

### 理赔问题五项

责任定义、客户事实、告知与合同状态、证明资料、审核及争议渠道。诉讼是争议解决方式之一，不代表所有理赔必经诉讼。

## Key Concepts

- **比较口径**：目标、期限、风险和金额一致时的比较标准。
- **保费去向**：保费共同支持风险成本、费用、准备和合同利益，不等于个人储蓄账户。
- **小概率大损失**：发生概率低但后果无法承受，仍可能适合转移。
- **退休金缺口**：未来支出与可持续收入来源之间的差额。

## Mental Models

- 不争论“吉利”，只讨论客户是否愿意安排经济后果。
- 未出险不等于保费白交，就像安全措施的价值不靠事故证明。
- 个案理赔经历应被核实，既不全盘否定也不泛化。

## Anti-patterns

- 嘲讽客户迷信、从众或缺乏金融知识。
- 用股票亏损或灾难故事恐吓客户。
- 承诺费率、分红、理赔或诉讼结果绝对稳定。
- 用不同风险和期限的数字制造保险更划算的假象。

## Worked Example

客户说“存银行更踏实”。顾问先问他最重视本金可取还是家庭风险保障。客户确认是应急流动性，于是保留银行储蓄承担应急，另行评估重大疾病造成的收入缺口；不要求客户把存款换成保险，也不把两者收益作错误对比。

## Key Takeaways

1. 观念沟通先理解来源和评价维度。
2. 储蓄、投资和保险按功能分工，不做错位排名。
3. 小概率风险是否转移取决于后果和承受能力。
4. 理赔担忧用合同、事实、资料和渠道回答。
