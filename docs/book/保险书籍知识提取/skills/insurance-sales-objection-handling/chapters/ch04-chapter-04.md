# Chapter 4: 第四章 面对客户排它性措施的沟通策略

## Core Idea

谨慎、年轻、健康、储蓄、社保、子女、单位福利、不缺钱、熟人渠道和已有保单，都是客户提出的替代措施。沟通重点是评估这些资源覆盖什么、何时有效、在压力情景下是否存在，而不是把它们当成排斥保险的错误防线。

## Frameworks Introduced

### 替代资源四检验

1. **范围**：覆盖费用、收入、责任还是养老？
2. **金额**：足以承担多大后果？
3. **持续性**：离职、健康、市场或家庭变化后是否仍在？
4. **机会成本**：动用后会不会破坏住房、教育或其他目标？

### 资源净缺口

`具体风险后果 - 可验证替代资源 = 剩余缺口`

若剩余缺口可由客户自留，结论可以是不购买；若存在不可承受部分，再讨论保险。

### 熟人和已有保单

熟人关系解决信任入口，不证明产品适配。已有保单按责任、保额、期限、状态和角色盘点，优先补缺而非替换。

## Key Concepts

- **替代资源**：可以承担部分风险后果的资产、福利、家庭支持或合同。
- **持续性风险**：资源可能因离职、关系、健康或制度变化而消失。
- **机会成本**：动用资源导致其他目标无法实现的代价。
- **剩余缺口**：替代资源之后仍需处理的风险后果。

## Mental Models

- 小心能降低部分事故频率，不能消除全部后果。
- 财富高可能提高自留能力，也可能增加责任规模。
- 年轻和健康影响可保性与时间，不自动产生需求。

## Anti-patterns

- 贬低社保、储蓄、单位福利或子女支持。
- 用“以后一定买不到”恐吓年轻健康客户。
- 因客户不缺钱就假定应购买大额保单。
- 利用熟人竞争，未做合同和服务比较。

## Worked Example

客户说已有社保和单位高端医疗。核验后发现医疗费用覆盖充分，但福利随离职终止，家庭主要责任人的身故缺口没有覆盖。客户选择只补后者；若其资产足以自留，也可以不补。结论由资源净缺口决定，而非“商业保险必不可少”的口号。

## Key Takeaways

1. 替代资源按范围、金额、持续和机会成本检验。
2. 保险只处理剩余且不愿自留的缺口。
3. 熟人关系不替代产品适配。
4. 已有保单优先盘点和补缺。
