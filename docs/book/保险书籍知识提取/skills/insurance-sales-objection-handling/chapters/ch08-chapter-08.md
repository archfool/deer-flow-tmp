# Chapter 8: 第八章 用贴心的服务感动客户

## Core Idea

客户觉得不值、忘看免责、见不到顾问、不续保、交不起、想退保或需要理赔时，重点是恢复合同理解和解决实际问题。“感动”应来自及时、准确、可追踪的履约，而非私人关系或情绪挽留。

## Frameworks Introduced

### 服务补救五步

接收问题 → 复述事实与客户期望 → 核对合同和服务记录 → 给出选项、责任人与时限 → 跟踪结果并修正流程。

### 退保/不续保决策

核对原因、合同状态、现金价值或未满期影响、保障缺口、替代产品核保与等待、减保/贷款等可用保全、客户资金时间。是否保留由客户利益决定。

### 理赔协助

报案、查找全部保单、事故时间线、真实资料、责任核对、进度跟踪、结论解释和争议渠道。顾问协助流程，不修改事实也不保证结果。

## Key Concepts

- **免责重说明**：发现客户未理解重要除外时，重新说明并记录，必要时按客户权利处理。
- **服务失联**：承诺未履行或客户不知道正式服务渠道。
- **退保净影响**：现金损失、保障中断和未来可保性共同构成的后果。
- **老客户联系**：按客户偏好提供检视和服务，不把朋友关系用于持续推销。

## Mental Models

- 客户不续保可能是产品、能力、理解或服务问题，先分类。
- 不挽留错误保单，服务也包括协助客户合理退出。
- 理赔是合同检验，不是表演人情。

## Anti-patterns

- 客户忘看免责时归咎其没有认真阅读。
- 为保持续率隐瞒退保金额或替代风险。
- 理赔时教客户修改病史、日期或事故描述。
- 用频繁问候掩盖没有保全、检视和响应机制。

## Worked Example

客户资金周转想退保。顾问取得最新合同数据，比较退保、减保、保单贷款和其他资金来源的成本与时间，说明贷款利息和合同风险。客户确认退保最符合需求后，顾问如实协助并记录保障终止，而不是以多年保费“可惜”进行情绪绑架。

## Key Takeaways

1. 服务补救有事实、选项、责任人、时限和跟踪。
2. 退保与不续保要比较完整合同和保障后果。
3. 合理退出也是专业服务。
4. 理赔坚持真实资料与合同依据。
