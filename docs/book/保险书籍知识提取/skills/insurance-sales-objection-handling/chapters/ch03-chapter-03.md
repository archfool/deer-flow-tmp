# Chapter 3: 第三章 消除客户对保险公司的误解

## Core Idea

客户对公司“骗人、会垮、霸王条款、分红不可信、名气不足”的担忧，需要分别核验机构、合同和销售陈述。品牌、历史平安经历或其他公司产品都不能直接证明当前方案好坏；跨公司比较应回到同一责任口径。

## Frameworks Introduced

### 公司信用三层证据

- **机构层**：主体资格、当前公开监管与风险信息、正式服务和投诉渠道。
- **合同层**：责任、除外、保全、现金价值和保证/非保证利益。
- **销售层**：销售陈述是否完整留痕，利益冲突和服务承诺是否清楚。

### 跨公司比较表

统一比较保额、责任定义、除外、期限、等待、续保、缴费、现金价值、保证/非保证利益和服务。公司名气是客户偏好因素之一，但不能覆盖合同差异。

### 已有保单处理

先盘点有效状态与缺口；若考虑替换，比较退保损失、重新核保、等待期和新旧责任，不因来自其他公司就否定。

## Key Concepts

- **霸王条款疑虑**：客户认为权利义务不公平，需定位具体条款和提示过程。
- **分红非保证**：分红水平受经营等因素影响，必须与保证利益分开。
- **机构风险处置**：按当前法律和监管制度说明，不能简化为“绝对不会倒”。
- **品牌偏好**：影响信任，但不是合同适配的充分条件。

## Mental Models

- 公司、合同、人员三者分别判断。
- 过去没发生风险是一个结果，不证明未来风险为零。
- 允许客户比较，专业价值在于提供可比口径。

## Anti-patterns

- 承诺公司永远不会失败或客户绝不会受影响。
- 把非保证分红包装成稳定收益。
- 避开具体条款，只强调监管、规模和荣誉。
- 为抢单建议直接退旧保单。

## Worked Example

客户偏好知名公司。顾问认可品牌带来的服务感受，随后用同口径表比较两份合同，发现知名方案保费较低但某项责任定义不同。客户根据自己优先级选择任何一家都可以；顾问不把品牌偏好描述为愚昧，也不靠公司宣传代替条款。

## Key Takeaways

1. 机构、合同和销售陈述要分层举证。
2. 分红及演示利益与保证责任分开。
3. 跨公司比较使用统一责任与期限口径。
4. 已有保单先盘点，替换要计算完整成本。
