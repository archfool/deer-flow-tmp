# 术语表

| 术语 | 含义 | 章节 |
|---|---|---|
| 注意力许可 | 客户愿意在当前时刻听取有限信息。 | ch01 |
| 后续触达权 | 客户决定是否、何时、以何渠道继续联系。 | ch01 |
| 比较口径 | 目标、期限、风险和金额一致的比较标准。 | ch02, ch03 |
| 小概率大损失 | 发生概率低但后果可能无法自行承受的风险。 | ch02 |
| 公司信用三层 | 机构、合同和销售陈述三个证据层。 | ch03 |
| 分红非保证 | 分红受经营等因素影响，不属于合同确定利益。 | ch03 |
| 替代资源 | 可承担部分风险后果的资产、福利、支持或合同。 | ch04 |
| 机会成本 | 动用资源后其他目标受到的损失。 | ch04 |
| 预算五层 | 生活、债务、应急、核心保障、长期储蓄。 | ch05 |
| 压力情景 | 收入下降或支出上升时的持续缴费测试。 | ch05 |
| 产品五要素 | 责任、额度、期限、费用和给付方式。 | ch06 |
| 合同三层阅读 | 决策摘要、关键限制和执行信息。 | ch07 |
| 同口径价格 | 在相同责任、保额、期限等条件下比较成本。 | ch07 |
| 服务补救 | 服务问题发生后的核实、选项、时限、跟踪和改进。 | ch08 |
| 退保净影响 | 现金损失、保障中断和未来可保性的综合后果。 | ch08 |
