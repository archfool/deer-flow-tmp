# 方法模式

## 1. 原话翻译

**何时用**：客户给出一句拒绝或要求。

**怎么做**：提出两个以内可能含义并请客户确认，再进入对应框架。

**权衡**：不要把明确拒绝翻译成隐藏兴趣。

## 2. 替代资源四检验

**何时用**：客户说有存款、社保、福利或家人支持。

**怎么做**：核对范围、金额、持续性和机会成本，计算剩余缺口。

**权衡**：资源足够时结论可以是不买。

## 3. 预算五层

**何时用**：资金紧张、保费贵或担心续缴。

**怎么做**：生活、债务、应急优先，再安排核心保障和长期储蓄，并做压力测试。

**权衡**：不借款、不透支应急资金交费。

## 4. 场景到险种

**何时用**：客户直接询问教育、养老、车、房或旅行险种。

**怎么做**：从事件到损失、资源、优先级，再比较产品五要素。

**权衡**：生活场景不自动对应固定产品。

## 5. 合同三层阅读

**何时用**：条款太多、只看便宜或准备签约。

**怎么做**：先决策摘要，再关键限制，最后执行信息，并让客户复述。

**权衡**：摘要帮助理解但不替代合同。

## 6. 服务补救

**何时用**：客户不满、退保、不续保或理赔。

**怎么做**：接收、复述、核对、给选项责任时限、跟踪改进。

**权衡**：不以保持续率或佣金阻碍合理退出。
