# 方法模式

## 1. 利益相关者图
**何时用**：多人决策项目。**怎么做**：记录五类角色、目标、标准、影响和正式权限。**权衡**：不发展秘密关系或绕过流程。

## 2. SPIN问题链
**何时用**：企业需求访谈。**怎么做**：情境、问题、影响、需求收益逐步提问。**权衡**：不诱导、不夸大痛苦。

## 3. 买点卖点双栏
**何时用**：多角色目标不一致。**怎么做**：个人工作目标与组织采购目标分别记录并找合规交集。**权衡**：私人利益不能与组织责任冲突。

## 4. 工具六件套
**何时用**：项目标准化。**怎么做**：角色图、摘要、手册、证据、异议库、CRM。**权衡**：真实、最小化、授权、可退出。

## 5. 项目七阶段
**何时用**：招投标或复杂企业销售。**怎么做**：资格到客户成功逐阶段设置证据和退出条件。**权衡**：不得串标、泄密或伪造背书。
