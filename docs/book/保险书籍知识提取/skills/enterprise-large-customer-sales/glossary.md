# 术语表

| 术语 | 含义 | 章节 |
|---|---|---|
| 企业销售四维 | 角色点、关系线、部门流程面、组织生态体。 | ch01 |
| 利益相关者图 | 记录角色、目标、权限、态度和影响关系的项目图。 | ch01, ch02 |
| 决策中心 | 共同影响企业采购的使用、影响、把关、采购和决策角色。 | ch02 |
| 内部支持者 | 在授权和合规范围内帮助理解组织问题与流程的人。 | ch02 |
| SPIN | 情境、问题、影响、需求收益的问题链。 | ch03 |
| 约哈里窗口 | 通过适度披露和反馈改善共同理解的沟通模型。 | ch03 |
| 授权跟进 | 客户同意的时间、渠道、主题和价值明确的后续联系。 | ch03 |
| 买点 | 角色个人工作目标与风险。 | ch04 |
| 卖点 | 组织公开目标、采购标准和可证明价值。 | ch04 |
| 客户成功 | 客户通过交付获得可验证业务结果。 | ch05, ch06 |
| 决策摘要 | 书面记录问题、标准、方案、取舍、责任人和未决项。 | ch05 |
| 授权CRM | 只存储实现项目和服务所需、已授权的信息系统。 | ch05 |
| 教育营销 | 提供真实专业教育并清晰披露销售目的的活动。 | ch06 |
| 第三方证据 | 经授权、可验证且说明适用边界的案例或推荐。 | ch06 |
