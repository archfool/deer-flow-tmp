## Core Frameworks & Mental Models

### 1. 企业销售四维

点是关键角色，线是影响与汇报关系，面是部门目标和正式流程，体是客户组织、供应商与监管环境。组织架构图升级为利益相关者图，不把单一联系人当作客户。

### 2. 决策中心与SPIN

识别使用者、影响者、把关者、采购者和决策者。内部支持者只能在合规边界内协助。SPIN依次确认情境、问题、影响和需求收益，不用诱导问题或放大痛苦。

### 3. 买点卖点与项目价值

买点记录各角色工作目标，卖点记录组织公开目标和采购标准；二者只有在不冲突、可证明且合规时才形成价值主张。关系服从制度，客户成功优先于订单控制。

### 4. 工具与书面记忆

工具六件套包括利益相关者图、决策摘要、产品服务手册、证据演示、异议事实库和授权CRM。书面材料用于减少误解，不用于给客户“重新编程”或制造锁定。

### 5. 企业项目七阶段

`资格需求 → 决策中心 → 方案共创 → 正式招采 → 合规报价 → 第三方证据 → 交付与客户成功`

教育营销、投标和案例证明均受公平竞争、授权、真实性、保密和利益冲突约束。
