# 企业大客户销售速查

## 项目地图

- 使用者：实际使用和定义痛点
- 影响者：技术、财务、法律或业务标准
- 把关者：控制信息和流程入口
- 采购者：执行询价、合同和交易
- 决策者：承担最终授权责任

## 每阶段交付

| 阶段 | 交付物 |
|---|---|
| 资格需求 | 问题、预算、时点和退出条件 |
| 决策中心 | 利益相关者图 |
| 方案共创 | 买点卖点双栏和备选 |
| 正式招采 | 流程、保密和答疑记录 |
| 报价 | 分项成本、假设和有效期 |
| 第三方证据 | 授权、真实性和适用边界 |
| 交付 | 责任人、指标、反馈和客户成功 |

## 红线

不诱导内部泄密、不规避招标、不串标、不伪造推荐、不用私人利益换采购支持、不以重复骚扰征服客户、不以提高转移成本制造忠诚。
