# Chapter 2: 第二篇 一网打尽篇—找对人

## Core Idea

找对人不是只找到拍板者，而是识别使用者、技术/财务影响者、采购把关者、决策者和内部支持者的不同责任。所谓教练必须是透明、合规的内部协作人，不能被利用传递机密或规避程序。

## Frameworks Introduced

### 决策中心五角色

使用者定义问题，影响者制定标准，把关者控制信息流程，采购者执行交易，决策者承担最终责任；同一人可兼任。

**何时使用**：企业项目进入本章对应阶段时，用框架记录多方目标、事实、权限和正式流程。

## Key Concepts

- **概念关系**：内部支持者、反对者、使用者、买点与组织目标通过“决策中心五角色”形成组织决策链，不能被简化为找到一个人或一句话。
- **伦理边界**：尊重采购、公平竞争、隐私、授权和利益冲突披露。

## Mental Models

- **组织决定而非个人征服**：找对人不是只找到拍板者，而是识别使用者、技术/财务影响者、采购把关者、决策者和内部支持者的不同责任。
- **客户成功优先**：项目价值以客户可验证的业务结果和履约为标准。
- **关系服从制度**：内部支持不能绕过采购、合规或信息边界。

## Anti-patterns

- 诱导教练泄密。
- 把中立者视为雷区。
- 在底层发展私人关系。
- 用免费利益换采购支持。

## Worked Example

供应商联系人愿意提供公开流程，但拒绝透露竞标底价；销售人员尊重边界并通过正式答疑获取信息。

## Key Takeaways

1. 找对人不是只找到拍板者，而是识别使用者、技术/财务影响者、采购把关者、决策者和内部支持者的不同责任。
2. 使用“决策中心五角色”管理项目：使用者定义问题，影响者制定标准，把关者控制信息流程，采购者执行交易，决策者承担最终责任；同一人可兼任。
3. 先排除“诱导教练泄密”，再推进正式下一步。
