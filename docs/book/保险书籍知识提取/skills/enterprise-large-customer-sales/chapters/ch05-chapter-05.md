# Chapter 5: 第五篇 无敌工具篇——工具妙

## Core Idea

销售工具应帮助客户记忆、比较和执行，而不是给大脑重新编程。关系卡、手册、视频、书面方案、CRM和快速说明都要真实、最小化收集数据并可审查；忠诚来自客户成功，不是提高转移成本。

## Frameworks Introduced

### 工具六件套

利益相关者图、问题与决策摘要、产品服务手册、证据型演示、异议事实库、授权CRM分别服务准备、沟通和履约。

**何时使用**：企业项目进入本章对应阶段时，用框架记录多方目标、事实、权限和正式流程。

## Key Concepts

- **概念关系**：书面记忆、快速说明、CRM、客户成功通过“工具六件套”形成组织决策链，不能被简化为找到一个人或一句话。
- **伦理边界**：尊重采购、公平竞争、隐私、授权和利益冲突披露。

## Mental Models

- **组织决定而非个人征服**：销售工具应帮助客户记忆、比较和执行，而不是给大脑重新编程。
- **客户成功优先**：项目价值以客户可验证的业务结果和履约为标准。
- **关系服从制度**：内部支持不能绕过采购、合规或信息边界。

## Anti-patterns

- 夸张演出。
- 客户一有信号就索要订单。
- 用锁定制造忠诚。
- 未经授权保存联系人资料。

## Worked Example

会后发送一页决策摘要，记录责任人和未决项；客户可纠正内容，比口头重复更能减少误解。

## Key Takeaways

1. 销售工具应帮助客户记忆、比较和执行，而不是给大脑重新编程。
2. 使用“工具六件套”管理项目：利益相关者图、问题与决策摘要、产品服务手册、证据型演示、异议事实库、授权CRM分别服务准备、沟通和履约。
3. 先排除“夸张演出”，再推进正式下一步。
