# Chapter 3: 第三篇 一剑封喉篇——说对话

## Core Idea

企业沟通的核心是提问、倾听、共同定义问题和谈判取舍，而不是用反问把客户拉回成交。SPIN和约哈里窗口可用于发现信息与反馈；重复触达必须有授权和新价值。

## Frameworks Introduced

### SPIN问题链

情境问题确认事实，问题问题识别困难，影响问题量化后果，需求收益问题由客户表达解决后的价值；避免诱导和夸大痛苦。

**何时使用**：企业项目进入本章对应阶段时，用框架记录多方目标、事实、权限和正式流程。

## Key Concepts

- **概念关系**：SPIN、约哈里窗口、谈判、授权跟进通过“SPIN问题链”形成组织决策链，不能被简化为找到一个人或一句话。
- **伦理边界**：尊重采购、公平竞争、隐私、授权和利益冲突披露。

## Mental Models

- **组织决定而非个人征服**：企业沟通的核心是提问、倾听、共同定义问题和谈判取舍，而不是用反问把客户拉回成交。
- **客户成功优先**：项目价值以客户可验证的业务结果和履约为标准。
- **关系服从制度**：内部支持不能绕过采购、合规或信息边界。

## Anti-patterns

- 先求小同意诱导大同意。
- 找客户软肋。
- 重复到客户屈服。
- 把谈判对手化。

## Worked Example

客户拒绝系统方案，SPIN访谈发现真正问题是实施资源，双方改为分阶段试点而非继续反问施压。

## Key Takeaways

1. 企业沟通的核心是提问、倾听、共同定义问题和谈判取舍，而不是用反问把客户拉回成交。
2. 使用“SPIN问题链”管理项目：情境问题确认事实，问题问题识别困难，影响问题量化后果，需求收益问题由客户表达解决后的价值；避免诱导和夸大痛苦。
3. 先排除“先求小同意诱导大同意”，再推进正式下一步。
