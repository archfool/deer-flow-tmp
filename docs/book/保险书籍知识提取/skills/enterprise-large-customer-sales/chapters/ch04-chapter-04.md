# Chapter 4: 第四篇 战胜盲点篇——心态好

## Core Idea

心态管理用于识别自身盲点、区分客户买点与组织卖点，并在项目周期中保持稳定。愿景和风险后果应由客户确认，不能把痛苦想透变成恐惧营销；拜访量也要受适配和服务容量约束。

## Frameworks Introduced

### 买点卖点双栏

买点记录各角色的个人工作目标与风险，卖点记录组织公开目标、采购标准和可证明价值；只有不冲突且合规时才形成项目价值主张。

**何时使用**：企业项目进入本章对应阶段时，用框架记录多方目标、事实、权限和正式流程。

## Key Concepts

- **概念关系**：认知盲点、意愿图像、80/20、平均法则通过“买点卖点双栏”形成组织决策链，不能被简化为找到一个人或一句话。
- **伦理边界**：尊重采购、公平竞争、隐私、授权和利益冲突披露。

## Mental Models

- **组织决定而非个人征服**：心态管理用于识别自身盲点、区分客户买点与组织卖点，并在项目周期中保持稳定。
- **客户成功优先**：项目价值以客户可验证的业务结果和履约为标准。
- **关系服从制度**：内部支持不能绕过采购、合规或信息边界。

## Anti-patterns

- 放大痛苦。
- 用私人利益冲突推动采购。
- 追求数量骚扰客户。
- 把死单强行做活。

## Worked Example

项目团队确认财务关注总成本、HR关注员工体验，方案用双栏同时回应并公开取舍，不通过私人好处换支持。

## Key Takeaways

1. 心态管理用于识别自身盲点、区分客户买点与组织卖点，并在项目周期中保持稳定。
2. 使用“买点卖点双栏”管理项目：买点记录各角色的个人工作目标与风险，卖点记录组织公开目标、采购标准和可证明价值；只有不冲突且合规时才形成项目价值主张。
3. 先排除“放大痛苦”，再推进正式下一步。
