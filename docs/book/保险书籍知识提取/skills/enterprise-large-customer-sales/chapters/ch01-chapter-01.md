# Chapter 1: 第一篇 四维成交篇—学技术

## Core Idea

企业大客户成交通常由多人共同形成，四维方法的价值是看见组织、关系、流程和决策标准，而不是绕过正式程序操控关键人。组织架构图、一网打尽卡和一剑封喉卡应改造成利益相关者图、接触记录和决策摘要。

## Frameworks Introduced

### 企业销售四维

点是关键角色，线是汇报与影响关系，面是部门目标与流程，体是客户组织、供应商和监管环境共同构成的决策系统。

**何时使用**：企业项目进入本章对应阶段时，用框架记录多方目标、事实、权限和正式流程。

## Key Concepts

- **概念关系**：组织架构图、利益相关者、决策标准、项目记录通过“企业销售四维”形成组织决策链，不能被简化为找到一个人或一句话。
- **伦理边界**：尊重采购、公平竞争、隐私、授权和利益冲突披露。

## Mental Models

- **组织决定而非个人征服**：企业大客户成交通常由多人共同形成，四维方法的价值是看见组织、关系、流程和决策标准，而不是绕过正式程序操控关键人。
- **客户成功优先**：项目价值以客户可验证的业务结果和履约为标准。
- **关系服从制度**：内部支持不能绕过采购、合规或信息边界。

## Anti-patterns

- 把客户组织当攻克对象。
- 秘密操控关键人。
- 用单一联系人代替采购流程。
- 记录或传播无关隐私。

## Worked Example

员工福利项目先画人力、财务、采购、员工代表和决策层关系，再分别确认评价标准和正式流程。

## Key Takeaways

1. 企业大客户成交通常由多人共同形成，四维方法的价值是看见组织、关系、流程和决策标准，而不是绕过正式程序操控关键人。
2. 使用“企业销售四维”管理项目：点是关键角色，线是汇报与影响关系，面是部门目标与流程，体是客户组织、供应商和监管环境共同构成的决策系统。
3. 先排除“把客户组织当攻克对象”，再推进正式下一步。
