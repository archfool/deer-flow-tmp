# Chapter 6: 第六篇 轻松复制篇——模式优

## Core Idea

教育营销、招投标和第三方证明可以规模化专业价值，但必须尊重采购公正、知识真实性和证据授权。培训不能成为隐性推销，投标不能串标或突然操纵价格，推荐信和客户名单不能伪造或泄密。

## Frameworks Introduced

### 企业项目七阶段

资格与需求、决策中心、方案共创、正式招采、合规报价、第三方证据核验、交付与客户成功七阶段逐项留痕。

**何时使用**：企业项目进入本章对应阶段时，用框架记录多方目标、事实、权限和正式流程。

## Key Concepts

- **概念关系**：教育营销、招投标、报价、第三方证明通过“企业项目七阶段”形成组织决策链，不能被简化为找到一个人或一句话。
- **伦理边界**：尊重采购、公平竞争、隐私、授权和利益冲突披露。

## Mental Models

- **组织决定而非个人征服**：教育营销、招投标和第三方证明可以规模化专业价值，但必须尊重采购公正、知识真实性和证据授权。
- **客户成功优先**：项目价值以客户可验证的业务结果和履约为标准。
- **关系服从制度**：内部支持不能绕过采购、合规或信息边界。

## Anti-patterns

- 培训套取全员名单。
- 规避招标。
- 与分包商串通。
- 伪造权威和客户背书。

## Worked Example

投标项目按正式澄清口径提交分项报价和可验证案例，客户授权后才使用推荐信，并披露案例边界。

## Key Takeaways

1. 教育营销、招投标和第三方证明可以规模化专业价值，但必须尊重采购公正、知识真实性和证据授权。
2. 使用“企业项目七阶段”管理项目：资格与需求、决策中心、方案共创、正式招采、合规报价、第三方证据核验、交付与客户成功七阶段逐项留痕。
3. 先排除“培训套取全员名单”，再推进正式下一步。
