# Chapter 2: 第2章 客户投保行为分析

## Core Idea

客观风险不会自动转化为购买行为。客户要先意识到风险，形成动机，建立对保险和提供者的基本信任，再经过信息收集、方案评价和购买决策。个人客户与团体客户的参与者、流程和影响因素不同，销售工作应先识别“谁在以什么标准做决定”。

## Frameworks Introduced

### 安全需要到投保行为的转化链

`客观风险 → 安全需要 → 被意识到的保险需求 → 投保动机 → 信息与方案评价 → 投保行为`

**何时使用**：客户承认风险却迟迟不行动时。先定位卡点是没有意识、心理障碍、缺乏信任、支付能力不足，还是方案没有通过评价，而不是笼统地归为“拒绝”。

### 保险需求四特征

- **客观性**：风险存在不因客户是否认识而改变。
- **层次性与差异性**：收入、家庭责任、经历和环境使需求优先级不同。
- **隐蔽性**：保险属于非渴求性产品，需求往往需要通过事实和后果显现。
- **可转化性**：宣传、体验、支付能力和信任会决定潜在需要能否成为现实购买。

### 客户三维分类

1. 按关系阶段：现有客户、潜在客户、未来可能客户。
2. 按购买主体：个人或零散客户、组织或团体客户。
3. 按互动倾向：顺意、逆意、独立型；分类用于选择沟通方式，不应成为性格标签。

### 个人购买决策角色与过程

识别发起者、影响者、决策者、购买者和使用/被保障者。流程通常经过需求确认、信息收集、方案评价、购买决定和购后评价；同一人可承担多个角色。

### 团体客户决策中心

团体投保通常涉及使用部门、倡议者、技术或财务影响者、采购执行者、最终决策者和信息把关者。新购、修订重购和例行重购的信息需求与参与范围不同。

## Key Concepts

- **促进型心理**：风险防范、储蓄安排、从众或信任等可能推动投保，但仍需核验真实需求。
- **制约型心理**：侥幸、不信任、怕吃亏、忌讳谈风险或把保险与其他金融工具简单比较。
- **认识、情感、选择**：客户不仅要理解产品，还要形成对机构和人员的情感判断，并在多个方案间选择。
- **购后评价**：投保后的理解、服务和体验会影响续保、增购及转介绍。

## Mental Models

- **需求存在不等于需求成熟**：销售的任务是帮助客户看清后果和选项，不是制造恐惧。
- **先找决策结构，再做表达**：对非决策者讲得再充分，也可能无法推动组织行动。
- **行为比类型更可靠**：性格分类只用于形成假设，最终以提问、选择和实际行动验证。

## Anti-patterns

- **把沉默当认可**：客户可能只是礼貌、没有理解或无权决定。
- **只处理表面异议**：说“贵”可能意味着预算不足、价值不清、比较基准不同或不信任。
- **把个人销售方法搬到团体客户**：忽略采购、财务、员工福利和管理层的不同目标。
- **用恐吓激活需求**：短期制造焦虑，长期破坏信任和决策质量。

## Worked Example

一家企业的人力资源经理询问补充医疗保险，但财务部门强调成本，员工代表关心覆盖范围，总经理只愿审批能改善留任的项目。销售人员应建立决策中心图：HR是发起者和使用部门，财务是影响者，员工代表提供需求信息，总经理是决策者。分别补齐理赔数据、预算边界和员工结构，再提交可比较方案，而不是只向HR重复产品卖点。

## Key Takeaways

1. 风险、需求、动机和投保行为是不同阶段。
2. 心理与性格分类用于提出沟通假设，不能替代事实调查。
3. 个人决策要识别角色，团体决策要识别决策中心和购买类型。
4. 销售阻力应定位在转化链的具体环节后再处理。
