# Chapter 4: 第4章 保险销售步骤与技巧

## Core Idea

专业销售是一条有退出条件的流程，不是从名单直接跳到促成。每一步都要产生下一步所需的信息或承诺：筛选合格准保户、准备接触、建立对话、发现需求、说明方案、澄清异议、确认投保、递送与持续服务。前一步证据不足，就不应靠技巧强行推进。

## Frameworks Introduced

### 九阶段销售流程

`开拓 → 资格审查 → 访前准备 → 约访/接洽 → 需求洽谈 → 建议书说明 → 异议处理 → 促成 → 售后服务`

- **开拓与资格审查**：同时检查需求、支付能力、决策权、保险利益和基本核保可能性。
- **访前准备**：整理客户资料、会谈目标、材料工具、预期问题和心理状态。
- **接洽**：电话、陌生拜访、信函或网络的目标是获得合适的下一步，不是在低信息条件下完成全部销售。
- **洽谈与说明**：从客户问题进入需求，方案说明遵循需求、建议、责任、成本和限制的顺序。
- **异议与促成**：确认客户是否理解、是否仍有未决问题；只有在需求和方案基本认可时提出明确行动。
- **售后**：递送保单、再次说明、保全、理赔协助和日常服务构成下一轮信任基础。

### 准保户资格五项审查

需求、购买能力、决策权、保险利益、核保条件。任一项未知都应标为待核实；“愿意见面”不等于合格准保户。

### 异议诊断程序

1. 完整倾听并复述确认。
2. 区分真实异议、借口、信息不足或尚未取得决策权。
3. 追问形成异议的事实与比较标准。
4. 选择询问、举例、间接澄清、提供证据或暂缓等方式。
5. 回答后检查是否解决，并回到决策流程。

### 促成信号与行动阶梯

客户询问缴费、投保手续、保障起期、替代方案或家庭意见，通常表示进入行动评估。促成可以从确认偏好、选择方案、安排核保到正式申请逐级推进；不能把情绪激动当成充分知情。

### 谈判五项沟通能力

提问、答复、倾听、叙述和说服。书中“兵不厌诈”“最后通牒”等策略与现代合规、客户自主决策存在冲突，仅可作为历史销售观念识别，不应直接采用。

## Key Concepts

- **客户资料卡**：持续记录角色、需求、接触和服务信息，不是一次性名单。
- **建议书说明**：将客户需求与方案责任建立对应关系，而非逐页朗读产品材料。
- **保单递送**：再次核对责任、除外、缴费、犹豫期或相关权利及后续联系方式。
- **渠道适配**：网络、电话和信函改变接触方式，不改变真实说明、隐私保护和需求适配要求。

## Mental Models

- **每一步只争取合理下一步**：首次电话的成功可能只是取得会谈许可。
- **异议是诊断入口**：异议暴露客户的标准、信息缺口或信任问题。
- **成交不是终点**：递送与服务决定客户是否理解、持续持有并形成长期关系。

## Anti-patterns

- **跳过资格审查**：把大量时间投入无需求、无权决策或明显不具备条件的对象。
- **制造不安代替需求分析**：用恐惧和紧迫情绪推动客户，弱化其理性判断。
- **预设反驳**：客户还没说完就套用“拒绝处理话术”。
- **把促成当施压**：使用虚假稀缺、欺骗、最后通牒或不合理纠缠。
- **签单后失联**：使客户无法完成保单理解、保全和理赔准备。

## Worked Example

客户在建议书说明后说“我再考虑一下”。销售人员先问需要考虑的是预算、责任、家人意见还是公司信任。客户说明配偶未参与且担心长期缴费。正确下一步不是继续强调风险，而是安排共同会谈，提供不同缴费期限和保障期限的可比方案，并明确退保和中断缴费后果。待两位决策者理解后，再确认是否申请投保。

## Key Takeaways

1. 销售流程的每一步都应有信息输入、动作和退出条件。
2. 资格审查同时关注需求、能力、权利和可承保性。
3. 异议应先诊断再回应，回应后还要验证是否解决。
4. 促成必须建立在需求确认、方案理解和客户自主决定之上。
5. 售后服务是专业销售流程的一部分，也是未来客户价值的来源。
