# Chapter 6: 第6章 保险建议书的设计与制作

## Core Idea

保险建议书是“客户事实如何推导出方案”的可审查记录，而不是产品宣传册。高质量建议书应让客户看见风险判断、方案取舍、保费与责任、服务内容和限制，并能回到正式条款验证。

## Frameworks Introduced

### 建议书四步设计法

1. **收集与整理资料**：客户/企业基本信息、资产与人员、收入负债、既有保障、危险状况、目标和预算。
2. **分析保险需求**：识别风险、估算频率与损失程度，区分预防、自留、转移和保险处理。
3. **拟定产品组合**：为每项优先风险匹配责任、限额、期限、免赔和服务，说明未覆盖部分。
4. **制作与校验文本**：核对计算、条款版本、客户事实、保证与非保证内容，以及方案之间是否可比。

### 建议书文本结构

`前言与目标 → 客户事实 → 风险/需求分析 → 方案与保费 → 责任边界 → 服务项目 → 方案优势与取舍 → 公司与人员信息 → 条款附件`

优势部分必须说明相对什么目标更优，也要展示代价；不能只写宣传性形容词。

### 财产风险三件套

- **风险评估书**：说明标的、危险源、暴露程度和可能损失。
- **防灾减损建议书**：提出降低频率或损失程度的措施、责任人和优先级。
- **保险建议书**：处理适合转移的剩余风险，明确责任、限额、免赔和条件。

保险不是替代安全管理，而是风险控制之后的融资工具。

### 人身建议书适配原则

个人与家庭方案应围绕生命价值、收入责任、健康费用、教育养老目标和支付能力；团体方案还要考虑员工结构、福利目标、参与条件、成本分配和管理服务。个人模板不能直接套到团体客户。

## Key Concepts

- **单险种与组合建议书**：前者解释单一责任，后者解决多个风险，但必须防止复杂度掩盖责任缺口。
- **客户群定位**：同一产品对不同客户的价值与说明重点不同，建议书应针对实际决策者。
- **配套服务**：风险查勘、保全、年度报告、理赔协助等需写清范围和交付方式。
- **条款附件**：建议书不取代合同，关键陈述应能定位到正式条款。

## Mental Models

- **可追溯推导**：每项保费都应回答“对应什么风险和目标”。
- **先减损，后转移**：高频风险先改善管理，保险承担适合转移的剩余损失。
- **决策文件而非成交道具**：客户即使不购买，也应能据此理解风险和比较选项。

## Anti-patterns

- **复制公司模板后补客户姓名**：没有体现客户事实、优先级与取舍。
- **只呈现推荐方案**：缺乏备选、未覆盖风险和预算变化的影响。
- **建议书代替条款**：使用“全保、保证、随时”等无法在合同中验证的表达。
- **财产方案只报价格**：未做标的估值、危险调查和防灾减损建议。
- **堆叠险种制造专业感**：组合复杂但风险与责任没有一一对应。

## Worked Example

一家建筑企业要求工程险报价。建议书先记录工程阶段、施工方法、周边环境、分包和历史事故；风险评估识别基坑、火灾、高处作业和第三者暴露；防损部分提出现场用电、消防和分包管理措施；保险部分再分别说明工程物质损失、第三者责任、免赔和除外。这样，价格差异能够追溯到风险和责任，而不是只比较总保费。

## Key Takeaways

1. 建议书从客户资料和风险分析推导产品组合。
2. 文本必须同时呈现责任、成本、限制、服务和取舍。
3. 财产客户要把风险评估、防灾减损和保险安排连接起来。
4. 人身、家庭与团体建议书的目标和决策结构不同。
5. 所有关键承诺最终以合同及当前规则为准。
