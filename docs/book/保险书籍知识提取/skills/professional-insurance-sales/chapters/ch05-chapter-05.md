# Chapter 5: 第5章 保险产品分析

## Core Idea

产品分析的目的不是背诵险种名称，而是把客户风险与合同构成要素对应起来。先判断保障对象和损失性质，再核对责任、除外、费率与缴费、期限和给付方式，最后才比较产品特色与渠道。

## Frameworks Introduced

### 产品五要素

1. **保险责任与除外责任**：什么事件在什么条件下承担或不承担。
2. **保险费率与保费**：风险成本和定价如何转化为客户支出。
3. **保费交付方式**：一次或分期支付，以及未按时缴费的合同后果。
4. **保险期限**：保障起止、等待或观察期间及续保条件。
5. **赔款或保险金给付方式**：费用补偿、定额给付或责任赔偿，以及限额、免赔和比例。

### 保障对象分类树

- **人身风险**：寿命、健康与意外伤害；再区分身故/生存、医疗费用、疾病状态、伤残和收入责任。
- **财产损失**：企业财产、家庭财产、运输工具、货物和工程等直接损失。
- **法律责任**：公众、产品、雇主或职业责任造成的第三方赔偿责任。
- **信用风险**：债务人不履约或被保证人违约所形成的损失。

分类树决定调查对象：人身险看健康、职业和家庭责任；财产险看标的、价值和危险状况；责任险看业务活动与法律责任；信用保证险看交易与履约能力。

### 人身产品比较矩阵

对寿险、意外险和健康险，至少比较：触发事件、给付逻辑、保障期限、是否具有现金价值、风险由谁承担、费用和适合客户。分红、万能或投资连结等产品中的非保证部分必须与保证责任分开。

### 意外伤害认定

不能只看结果是否“意外”。应同时核对外来、突发、非本意、非疾病等构成及因果关系，并以具体合同定义为准。

## Key Concepts

- **非渴求性产品**：客户通常不会主动体验或购买，销售说明更要基于风险事实而非冲动刺激。
- **期限性**：责任只在约定期间存在，不能脱离生效、终止和续保条件谈保障。
- **损失补偿**：财产和费用型保障通常以实际损失为基础，受保险利益、限额、免赔和其他保险等约束。
- **责任保险**：保障的是被保险人依法或依约应对第三方承担的赔偿责任，不等于保障其自有财产。
- **信用与保证保险**：两者参与关系和承保对象不同，销售前应厘清谁的信用风险被转移。

## Mental Models

- **先风险、后险种、再产品**：从风险后果进入分类，再用五要素比较具体合同。
- **名称不是责任**：相似名称可能有不同定义、除外和给付条件。
- **卖点必须落到条款变量**：所谓灵活、全面或收益，应翻译成明确责任、期限、金额和限制。

## Anti-patterns

- **按产品名称判断保障**：忽略责任定义和除外。
- **只比较保费或收益演示**：没有控制保障期限、责任范围和非保证假设。
- **把意外等同于“没想到”**：忽视合同构成与因果关系。
- **使用书中旧费率或旧监管资料做当前结论**：历史产品示例只能用于理解结构，当前销售必须查最新版条款和制度。

## Worked Example

一家餐饮企业问“财产险是不是能管顾客滑倒”。销售人员先用分类树拆分：厨房设备火灾属于企业财产直接损失；顾客滑倒可能形成公众责任；员工工作中受伤涉及雇主责任及法定保障安排。三种风险的保障对象和理赔证据不同，因此不能用一张“财产险”笼统回答，而应分别核对责任、限额、免赔和除外。

## Key Takeaways

1. 产品分析以五要素为骨架，以保障对象和损失性质为入口。
2. 人身、财产、责任和信用风险需要不同的调查与给付逻辑。
3. 产品特色只有映射到合同变量才有比较意义。
4. 书中具体产品、费率和制度资料具有时代性，不能直接用于当前销售。
