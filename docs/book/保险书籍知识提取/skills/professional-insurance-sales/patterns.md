# 方法模式

## 1. 投保行为卡点诊断

**何时用**：客户承认风险但没有进入投保行动。

**怎么做**：沿“风险认知、需求形成、信任、信息收集、方案评价、决策角色、支付能力”逐项定位；只处理真正卡住决策的一环。

**权衡**：风险教育不能变成恐惧施压；客户没有适合方案时应允许退出。

## 2. 准保户五项资格审查

**何时用**：名单筛选和首次接洽后。

**怎么做**：核验需求、购买能力、决策权、保险利益、核保条件，并记录未知项和下一步。

**权衡**：资格是动态判断，不应因健康或收入形成歧视性标签。

## 3. 异议诊断闭环

**何时用**：客户提出贵、不需要、不信任或再考虑。

**怎么做**：倾听 → 复述 → 追问事实和标准 → 区分真伪与角色 → 提供证据或备选 → 验证是否解决。

**权衡**：不是所有异议都应被“克服”；不适配、无能力或明确拒绝时应停止推进。

## 4. 产品五要素比较

**何时用**：比较同类或不同类型产品。

**怎么做**：统一列出责任与除外、费率与保费、缴费、期限、给付，再补充客户适配和服务。

**权衡**：历史产品示例不能替代当前合同；非保证利益单独展示。

## 5. 可追溯建议书

**何时用**：个人、家庭和企业方案设计。

**怎么做**：每项推荐都链接至客户事实和风险，写明金额、期限、条件、成本、未覆盖风险及条款位置。

**权衡**：精简与完整需平衡，正文用于决策，细节可进入附件但不能隐藏关键限制。

## 6. 活动漏斗复盘

**何时用**：目标未达或工作量失控。

**怎么做**：记录有效接触、访谈、建议书、申请、承保和服务的数量与转化率，定位最大损耗环节后选择增量或提质。

**权衡**：指标用于改善过程，不用于诱导虚假记录或压迫客户。
