# 术语表

| 术语 | 含义 | 章节 |
|---|---|---|
| 专业销售 | 以客户利益为导向，运用专业知识和技能并持续提供服务的销售过程。 | ch01 |
| 交易销售 | 以当次成交为中心的销售模式，容易忽略长期适配和服务。 | ch01 |
| 关系销售 | 依靠信任和关系开展沟通；仍须接受需求分析与合同说明约束。 | ch01 |
| 顾问销售 | 分析风险、生活和财务需求后提出解决方案并持续服务。 | ch01 |
| 不可感知性 | 保险保障无法像实体商品一样在购买前试用，需要用条款、流程和服务证据具体说明。 | ch01 |
| 异质性 | 服务质量会因人员、时间和方式不同而波动，需要标准化和反馈管理。 | ch01 |
| 客户终生价值 | 客户在续购、增购、转介绍和服务关系中产生的长期价值。 | ch01 |
| 保险需求 | 为转移风险形成的保险愿望；成为现实需求还受认识、能力和信任影响。 | ch02 |
| 投保动机 | 推动客户进入信息收集和购买决策的内在原因。 | ch02 |
| 决策角色 | 发起者、影响者、决策者、购买者与被保障者等参与身份。 | ch02 |
| 决策中心 | 团体购买中共同影响投保的多个角色和部门。 | ch02 |
| 购后评价 | 客户投保后对方案理解、服务和结果的判断。 | ch02 |
| 胜任力 | 完成专业销售所需的品德、知识、技能、形象和心理能力组合。 | ch03 |
| 刻意训练 | 对具体动作反复练习、获取反馈并持续修正。 | ch03 |
| 准保户 | 经初步识别、可能具有保险需求和购买条件的对象。 | ch04 |
| 资格审查 | 对需求、能力、决策权、保险利益和核保条件的核验。 | ch04 |
| 异议 | 客户在理解、信任、价值、预算或决策流程上的未决问题。 | ch04 |
| 促成 | 在需求和方案获得基本认可后，邀请客户作出明确下一步决定。 | ch04 |
| 保单保全 | 合同有效期间的信息变更、缴费维护和其他合同管理。 | ch04 |
| 保险责任 | 合同约定保险人承担赔偿或给付责任的事件与条件。 | ch05 |
| 除外责任 | 合同明确不承担责任的情形。 | ch05 |
| 损失补偿 | 以实际损失为基础，并受限额、免赔等条件约束的补偿原则。 | ch05 |
| 责任保险 | 对被保险人依法或依约应向第三方承担的赔偿责任提供保障。 | ch05 |
| 建议书 | 展示客户事实、风险分析、方案、成本、限制和服务的决策说明文件。 | ch06 |
| 风险评估书 | 记录危险源、风险暴露与可能损失的分析文件。 | ch06 |
| 防灾减损 | 降低事故发生频率或损失程度的管理措施。 | ch06 |
| 领先指标 | 有效接触、访谈、建议书和服务等可提前影响业绩的过程指标。 | ch07 |
| 滞后指标 | 签单、保费、收入和续保等已经形成的结果指标。 | ch07 |
