# 专业保险销售速查

## 一次销售是否专业

- 客户问题是否先于产品？
- 需求、支付能力和决策角色是否核实？
- 关键陈述能否由合同或记录验证？
- 是否说明责任、除外、期限、费用和非保证部分？
- 客户是否有真实理解和自主选择空间？
- 成交后的递送、保全和理赔协助是否安排？

## 流程退出条件

| 阶段 | 进入下一步前至少确认 |
|---|---|
| 开拓 | 存在值得进一步核实的风险或需求 |
| 资格审查 | 需求、能力、权利、保险利益、核保条件无明显冲突 |
| 接洽 | 客户同意合适的会谈目标和时间 |
| 需求访谈 | 事实、优先级、预算和决策角色基本清楚 |
| 建议书 | 推荐可追溯到风险，限制与备选可见 |
| 异议处理 | 客户确认问题已解决或明确仍需什么信息 |
| 促成 | 客户理解方案并自主同意下一步 |
| 售后 | 保单说明、服务承诺和下次检视已记录 |

## 产品五问

1. 保什么，又不保什么？
2. 保费如何形成、怎么交？
3. 保障从何时开始，到何时结束？
4. 事故发生后按费用、定额还是责任赔偿？
5. 对这个客户，为什么合适，代价是什么？

## 建议书最低结构

`客户事实 → 风险优先级 → 推荐与备选 → 责任/限额/期限 → 保费 → 除外与未覆盖 → 服务 → 条款`

## 禁止直接沿用的旧式做法

- 欺骗或“兵不厌诈”
- 虚假稀缺和最后通牒
- 用恐惧代替风险说明
- 把客户拒绝当作必须突破的障碍
- 用关系省略告知与合同说明
- 用历史费率、网站或制度信息回答当前问题
