## Core Frameworks & Mental Models

### 1. 专业销售三原则

以客户需求为中心，以售前、售中和售后的专业服务为手段，以客户、销售人员和保险机构的长期多赢为目的。关系能建立信任，但不能替代顾问式需求分析与合同说明。

### 2. 投保行为转化链

`客观风险 → 安全需要 → 被意识到的保险需求 → 投保动机 → 信息与方案评价 → 投保行为 → 购后评价`

客户不行动时先定位卡点；团体客户还要识别使用者、影响者、采购者、决策者和信息把关者。

### 3. 专业销售流程

`开拓 → 资格审查 → 访前准备 → 接洽 → 需求洽谈 → 建议书说明 → 异议处理 → 促成 → 售后`

资格审查包含需求、能力、决策权、保险利益和核保条件。每一步只争取合理的下一步；异议先诊断，促成以充分理解和自主决定为前提。

### 4. 产品五要素

从保险责任与除外、费率与保费、缴费方式、保险期限、赔款或保险金给付方式分析产品。先按人身、财产、责任或信用风险分类，再比较具体合同，产品名称和宣传卖点不能替代责任。

### 5. 建议书推导链

`客户资料 → 风险与需求分析 → 产品组合 → 责任/成本/限制 → 服务 → 条款校验`

财产客户还应连接风险评估、防灾减损和保险安排；建议书是决策文件，不取代正式合同。

### 6. 胜任力与活动管理

用职业道德、专业知识、销售技能、形象和心理五维诊断能力；再将结果目标分解为有效接触、访谈、建议书、签单和服务的过程漏斗。通过时间、客户和情绪管理维持稳定交付。

### 7. 使用边界

书中具体产品、费率、网站、机构资料和部分销售策略具有时代性。当前实践必须查最新版合同与规则；欺骗、恐惧施压、虚假稀缺和“最后通牒”等做法不得作为可执行建议。
