## Core Frameworks & Mental Models

### 1. 合规销售六步

`确定客户问题 → 收集事实 → 定位合同 → 查当前规范 → 说明适用与例外 → 记录理解和下一步`

法律政策用于解释合同条件，不能截取为权威促单话术。

### 2. 规范来源五级

依次区分现行法律行政法规、司法解释与裁判规则、监管规章规范、官方解释文件、历史或地方材料。每次引用记录效力、适用地域、生效修订和查询日期。

### 3. 四原则适用表

保险利益回答订约关系，近因分析事故与损失因果，损失补偿主要约束补偿性责任，最大诚信同时涉及客户告知与保险人说明。原则必须结合险种和条款。

### 4. 合同生命周期八站

主体角色、成立、生效与责任起期、解除撤销、无效、中止、复效、解释争议和代理责任按时间线记录。申请、承保、生效、等待期结束不是同一节点。

### 5. 纠纷条件树

先确定合同主体，再列关键时间、询问告知、事故事实、因果与资料，随后匹配责任除外、法定条件、举证和争议渠道。不可抗辩、遗产、执行、接管破产均不得用一句话回答。

### 6. 使用边界

本书法条和政策汇编是历史索引。回答当前法律问题必须重新核验，不提供替代律师意见的个案定论。
