# 方法模式

## 1. 规范来源五级
**何时用**：引用法条政策。**怎么做**：标注层级、效力、地域、日期和版本。**权衡**：历史汇编只作检索线索。

## 2. 四原则适用表
**何时用**：解释责任和理赔。**怎么做**：分别记录原则对象、事实、合同位置和例外。**权衡**：不把财产险原则机械搬到所有人身险。

## 3. 合同生命周期
**何时用**：投保、失效、复效或解除。**怎么做**：按申请、承保、成立、生效、责任起期和变更事件画时间线。**权衡**：口头承诺不替代合同节点。

## 4. 纠纷条件树
**何时用**：不可抗辩、遗产、医疗、自杀犯罪或执行争议。**怎么做**：主体、时间、告知、事故、因果、条款、举证、渠道逐层判断。**权衡**：仅做初筛，个案由专业人士处理。

## 5. 销售证据包
**何时用**：建议书和签单。**怎么做**：保存问询、告知、条款版本、说明、利益演示、客户确认和变更记录。**权衡**：真实最小化并保护隐私。
