# Chapter 5: 第五章 人身保险合同的八个基础知识

## Core Idea

合同当事人和关系人、成立生效、解除撤销、无效、中止复效、格式条款解释及代理人责任共同决定保单是否有效可用。销售人员必须把申请、承保、生效、责任起期和复效等节点说清并留痕。

## Frameworks Introduced

### 合同生命周期八站

主体角色、成立、生效责任起期、解除撤销、无效、中止、复效、解释争议与代理责任按时间线记录事实和文件。

**何时使用**：销售说明、保单检视或争议初筛时；先核验规范时效，再应用框架。

## Key Concepts

- **概念关系**：投保人保险人、被保险人受益人、成立生效、中止复效、格式条款通过“合同生命周期八站”进入同一条件分析，任何单个术语都不能直接决定结论。
- **来源边界**：区分书中历史材料、当前规范、合同文本、客户事实和专业意见，并标注日期。

## Mental Models

- **条件树而非口号**：合同当事人和关系人、成立生效、解除撤销、无效、中止复效、格式条款解释及代理人责任共同决定保单是否有效可用。
- **合同与法律双定位**：先找合同责任，再找当前规范对其成立、效力或解释的影响。
- **销售留痕也是证据**：询问、告知、说明、客户确认和版本均需真实可追溯。

## Anti-patterns

- 把申请当生效。
- 代签代告知。
- 隐瞒解除与现金价值。
- 口头承诺覆盖格式条款。

## Worked Example

客户补交保费后以为自动恢复保障，顾问核对合同复效申请、核保和批准节点，不先承诺责任已恢复。

## Key Takeaways

1. 合同当事人和关系人、成立生效、解除撤销、无效、中止复效、格式条款解释及代理人责任共同决定保单是否有效可用。
2. 使用“合同生命周期八站”完成条件分析：主体角色、成立、生效责任起期、解除撤销、无效、中止、复效、解释争议与代理责任按时间线记录事实和文件。
3. 先排除“把申请当生效”，再形成带来源日期的结论。
