# Chapter 3: 第三章 两类典型问题的实务探讨

## Core Idea

离婚中的保单处理和企业家财富管理都要求先拆事实：前者区分保费来源、合同权利、现金价值和保险金；后者区分企业经营风险与家庭财富风险。保险不能替代夫妻财产定性、公司治理和责任保险。

## Frameworks Introduced

### 两张事实图

婚姻图记录关系人、出资、时间、现金价值、给付与债务；企业图记录法人、股权、账户、出资、担保、经营责任、家庭责任和传承。

**何时使用**：销售说明、保单检视或争议初筛时；先核验规范时效，再应用框架。

## Key Concepts

- **概念关系**：离婚保单、企业经营战场、家庭财富战场、责任保险通过“两张事实图”进入同一条件分析，任何单个术语都不能直接决定结论。
- **来源边界**：区分书中历史材料、当前规范、合同文本、客户事实和专业意见，并标注日期。

## Mental Models

- **条件树而非口号**：离婚中的保单处理和企业家财富管理都要求先拆事实：前者区分保费来源、合同权利、现金价值和保险金；后者区分企业经营风险与家庭财富风险。
- **合同与法律双定位**：先找合同责任，再找当前规范对其成立、效力或解释的影响。
- **销售留痕也是证据**：询问、告知、说明、客户确认和版本均需真实可追溯。

## Anti-patterns

- 将离婚率用于恐惧营销。
- 人身险替代财产责任险。
- 保单修复家企混同。
- 用企业家精神压客户成交。

## Worked Example

餐饮企业主同时担心公众责任和家庭身故，团队分别评估责任险与寿险，不用大额寿险覆盖经营侵权。

## Key Takeaways

1. 离婚中的保单处理和企业家财富管理都要求先拆事实：前者区分保费来源、合同权利、现金价值和保险金；后者区分企业经营风险与家庭财富风险。
2. 使用“两张事实图”完成条件分析：婚姻图记录关系人、出资、时间、现金价值、给付与债务；企业图记录法人、股权、账户、出资、担保、经营责任、家庭责任和传承。
3. 先排除“将离婚率用于恐惧营销”，再形成带来源日期的结论。
