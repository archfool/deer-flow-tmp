# Chapter 6: 第六章 人身保险合同纠纷的十个热点难点问题

## Core Idea

不可抗辩、解除、自杀犯罪、保险金是否遗产、医疗理赔、道德风险、责任险与团意险、强制执行、整顿接管和解散破产都是条件问题。判断应使用事实时间线、合同条款和当前法律，不能用“熬过两年都赔”等口号。

## Frameworks Introduced

### 纠纷条件树

先确定合同与主体，再列关键时间、告知询问、事故事实、因果与资料，随后匹配责任除外、法定条件、举证和争议渠道。

**何时使用**：销售说明、保单检视或争议初筛时；先核验规范时效，再应用框架。

## Key Concepts

- **概念关系**：不可抗辩、合同解除、保险金遗产、强制执行、接管破产通过“纠纷条件树”进入同一条件分析，任何单个术语都不能直接决定结论。
- **来源边界**：区分书中历史材料、当前规范、合同文本、客户事实和专业意见，并标注日期。

## Mental Models

- **条件树而非口号**：不可抗辩、解除、自杀犯罪、保险金是否遗产、医疗理赔、道德风险、责任险与团意险、强制执行、整顿接管和解散破产都是条件问题。
- **合同与法律双定位**：先找合同责任，再找当前规范对其成立、效力或解释的影响。
- **销售留痕也是证据**：询问、告知、说明、客户确认和版本均需真实可追溯。

## Anti-patterns

- 鼓励隐瞒两年。
- 承诺自杀犯罪必赔或不赔。
- 受益人一律排除遗产。
- 公司风险一律由监管兜底。

## Worked Example

投保两年后发现病史争议，先核对询问内容、回答、主观事实、解除通知和事故关联，由专业人员按当前规则判断。

## Key Takeaways

1. 不可抗辩、解除、自杀犯罪、保险金是否遗产、医疗理赔、道德风险、责任险与团意险、强制执行、整顿接管和解散破产都是条件问题。
2. 使用“纠纷条件树”完成条件分析：先确定合同与主体，再列关键时间、告知询问、事故事实、因果与资料，随后匹配责任除外、法定条件、举证和争议渠道。
3. 先排除“鼓励隐瞒两年”，再形成带来源日期的结论。
