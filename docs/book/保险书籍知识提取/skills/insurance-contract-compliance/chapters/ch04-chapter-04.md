# Chapter 4: 第四章 人身保险的四大原则

## Core Idea

保险利益、近因、损失补偿和最大诚信是分析合同的重要原则，但在人身保险中的适用方式并不完全相同。原则不能脱离具体条款、事故因果、保险类型和现行法律机械套用。

## Frameworks Introduced

### 四原则适用表

保险利益回答订约关系，近因分析事故与损失因果，损失补偿限制补偿性给付，最大诚信约束告知与说明；逐项写适用对象、事实、例外。

**何时使用**：销售说明、保单检视或争议初筛时；先核验规范时效，再应用框架。

## Key Concepts

- **概念关系**：保险利益、近因、损失补偿、最大诚信通过“四原则适用表”进入同一条件分析，任何单个术语都不能直接决定结论。
- **来源边界**：区分书中历史材料、当前规范、合同文本、客户事实和专业意见，并标注日期。

## Mental Models

- **条件树而非口号**：保险利益、近因、损失补偿和最大诚信是分析合同的重要原则，但在人身保险中的适用方式并不完全相同。
- **合同与法律双定位**：先找合同责任，再找当前规范对其成立、效力或解释的影响。
- **销售留痕也是证据**：询问、告知、说明、客户确认和版本均需真实可追溯。

## Anti-patterns

- 所有人身险都适用损失补偿。
- 凭直觉判断近因。
- 用最大诚信只要求客户。
- 忽略保险人说明义务。

## Worked Example

顾问处理医疗费用报销与重疾定额同时申请时，分别判断补偿性责任和定额责任，不用同一原则否定全部给付。

## Key Takeaways

1. 保险利益、近因、损失补偿和最大诚信是分析合同的重要原则，但在人身保险中的适用方式并不完全相同。
2. 使用“四原则适用表”完成条件分析：保险利益回答订约关系，近因分析事故与损失因果，损失补偿限制补偿性给付，最大诚信约束告知与说明；逐项写适用对象、事实、例外。
3. 先排除“所有人身险都适用损失补偿”，再形成带来源日期的结论。
