# Chapter 2: 第二章 人身保险合同销售涉及的法律政策汇编

## Core Idea

法规汇编是历史时点的研究索引，不是当前法律数据库。使用时必须核验效力、修订、适用地域、规范层级与生效日期；财产申报、反洗钱、外汇、债务、婚姻、继承、税务和信托不能被混成保险的单一法律依据。

## Frameworks Introduced

### 规范来源五级

现行法律行政法规、司法解释与裁判规则、监管规章规范、官方解释文件、历史或地方材料分级记录，并附查询日期与适用范围。

**何时使用**：销售说明、保单检视或争议初筛时；先核验规范时效，再应用框架。

## Key Concepts

- **概念关系**：法源层级、时效性、地域适用、反洗钱外汇通过“规范来源五级”进入同一条件分析，任何单个术语都不能直接决定结论。
- **来源边界**：区分书中历史材料、当前规范、合同文本、客户事实和专业意见，并标注日期。

## Mental Models

- **条件树而非口号**：法规汇编是历史时点的研究索引，不是当前法律数据库。
- **合同与法律双定位**：先找合同责任，再找当前规范对其成立、效力或解释的影响。
- **销售留痕也是证据**：询问、告知、说明、客户确认和版本均需真实可追溯。

## Anti-patterns

- 复制书中金额阈值。
- 引用失效文件。
- 用地方规则全国化。
- 以反洗钱报告解释客户有违法。

## Worked Example

回答跨境缴费问题前，重新检索现行外汇和反洗钱规则，并区分机构报告义务与客户交易许可。

## Key Takeaways

1. 法规汇编是历史时点的研究索引，不是当前法律数据库。
2. 使用“规范来源五级”完成条件分析：现行法律行政法规、司法解释与裁判规则、监管规章规范、官方解释文件、历史或地方材料分级记录，并附查询日期与适用范围。
3. 先排除“复制书中金额阈值”，再形成带来源日期的结论。
