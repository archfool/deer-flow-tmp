# Chapter 1: 第一章 从法律和政策角度解读人身保险合同销售流程

## Core Idea

法律政策可以帮助客户理解合同，但不能被截取成促成话术。合规流程应从客户目标切入，区分保险功能与法律效果，展示条件、反例和来源日期，并在客户充分理解后自主决定。

## Frameworks Introduced

### 法律沟通六步

确定客户问题、收集事实、定位合同、查当前规范、说明适用与例外、记录理解和下一步。法律引用服务于解释，不制造权威压力。

**何时使用**：销售说明、保单检视或争议初筛时；先核验规范时效，再应用框架。

## Key Concepts

- **概念关系**：销售话题、合同功能、政策证据、知情决定通过“法律沟通六步”进入同一条件分析，任何单个术语都不能直接决定结论。
- **来源边界**：区分书中历史材料、当前规范、合同文本、客户事实和专业意见，并标注日期。

## Mental Models

- **条件树而非口号**：法律政策可以帮助客户理解合同，但不能被截取成促成话术。
- **合同与法律双定位**：先找合同责任，再找当前规范对其成立、效力或解释的影响。
- **销售留痕也是证据**：询问、告知、说明、客户确认和版本均需真实可追溯。

## Anti-patterns

- 用法条促单。
- 只讲有利条文。
- 把政策趋势说成确定结果。
- 保险顾问越界下法律结论。

## Worked Example

客户问保单能否避债，顾问不引用一句条文保证，而是收集债务时间和权利结构并转介律师。

## Key Takeaways

1. 法律政策可以帮助客户理解合同，但不能被截取成促成话术。
2. 使用“法律沟通六步”完成条件分析：确定客户问题、收集事实、定位合同、查当前规范、说明适用与例外、记录理解和下一步。法律引用服务于解释，不制造权威压力。
3. 先排除“用法条促单”，再形成带来源日期的结论。
