# 术语表

| 术语 | 含义 | 章节 |
|---|---|---|
| 法源层级 | 不同规范文件的效力和适用关系。 | ch02 |
| 时效核验 | 检查规范是否现行、修订、废止及何时适用。 | ch02 |
| 保险利益 | 法律要求的投保人与被保险人或标的之间的利益关系。 | ch04 |
| 近因 | 对损失起决定性、有效作用的原因判断。 | ch04 |
| 损失补偿 | 以实际损失为基础限制补偿性给付的原则。 | ch04 |
| 最大诚信 | 对重要事实真实说明与告知的要求，涉及合同双方。 | ch04 |
| 合同当事人 | 通常包括投保人与保险人。 | ch05 |
| 合同关系人 | 包括被保险人、受益人等与合同利益相关主体。 | ch05 |
| 成立与生效 | 合同达成与产生约定效力的不同节点。 | ch05 |
| 中止与复效 | 合同效力暂时停止及按条件恢复的过程。 | ch05 |
| 格式条款 | 由一方预先拟定、重复使用且订立时未协商的条款。 | ch05 |
| 如实告知 | 对保险人依法询问的重要事项真实回答。 | ch06 |
| 不可抗辩 | 对保险人解除权设置期限与条件的制度，不是隐瞒许可。 | ch06 |
| 保险金遗产 | 在符合法定或合同条件时，保险金进入遗产处理的情形。 | ch06 |
| 纠纷条件树 | 以主体、时间、告知、事故、条款、举证和渠道分析争议。 | ch06 |
