# 人身保险合规速查

## 回答法律问题前

1. 客户问的是合同责任、法律效力还是税务/财产结果？
2. 关键主体、时间、行为和证据是什么？
3. 合同哪一条直接相关？
4. 书中规范现在是否有效、适用于本地区和本事件？
5. 是否需要律师、税务或其他专业意见？

## 签单证据包

- 身份、关系人和真实签名
- 健康职业等询问与回答
- 合同、批注和产品资料版本
- 责任、除外、等待、缴费、现金价值说明
- 保证与非保证利益分栏
- 客户问题、理解确认和未决项

## 绝不简化

- “过两年隐瞒也赔”
- “指定受益人一定不算遗产”
- “保单一定不能执行”
- “保险公司不会倒/监管全额兜底”
- “自杀或犯罪一定赔/一定不赔”

这些都必须进入纠纷条件树。
