# 方法模式

## 1. 画像假设校验

**何时用**：知道客户职业、年龄或家庭角色，但信息不完整。

**怎么做**：将画像特征改写成问题；标记事实、客户陈述、外部来源、假设和未知；通过开放提问与复述确认更新画像。

**权衡**：画像提高准备效率，也可能放大偏见；任何标签都不能决定需求、能力或产品。

## 2. 精准KYC矩阵

**何时用**：首次规划、复杂高净值或跨境客户。

**怎么做**：依次收集人家、企业职业、资产负债现金流、身份辖区、既有保障、决策角色、目标时间和限制；记录信息来源及更新时间。

**权衡**：只收集实现服务所需信息，并取得授权、保护隐私。

## 3. 风险到工具映射

**何时用**：客户希望“一张保单解决所有问题”。

**怎么做**：逐项列出风险事件、财务后果、已有资源，再比较预防、自留、合同治理、法律税务安排和保险；对保险写明责任范围与剩余风险。

**权衡**：跨专业问题需转介，协作成本也要纳入方案。

## 4. 权利结构五问

**何时用**：大额、家庭、传承、婚姻或跨境保单。

**怎么做**：谁出钱、谁控制、谁被保障、谁领取、何时及由谁变更；再由法律税务专业人士核验预期效果。

**权衡**：角色分离会改变控制和关系，不天然产生隔离或税务结果。

## 5. 现金流压力测试

**何时用**：波动收入、企业主或长期缴费产品。

**怎么做**：用收入下降、职业中断、市场下跌和大额支出情景测试生活、经营、缴费和流动性；按保守基线调整承诺。

**权衡**：压力测试是情景，不是预测；应展示关键假设。

## 6. 面谈PDCA

**何时用**：信息不完整、需要多次会谈或客户反应偏离预期。

**怎么做**：计划已知与未知，执行并倾听，用复述检查，按新事实调整；会后复盘形成下一轮计划。

**权衡**：调整可以是暂缓、转介或停止，不只是换一种成交方式。
