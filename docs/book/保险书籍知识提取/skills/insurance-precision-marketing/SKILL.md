## Core Frameworks & Mental Models

### 1. 画像是假设，不是结论

中小企业主、跨境客户、继承人、拆迁户、内容创作者、家庭照护者、企业家、职业女性、投资者、白领、父母和中年客户等标签只用于准备问题。同一客户具有多重身份，所有判断必须由本人事实验证。

### 2. 精准KYC矩阵

`人和家庭 → 企业与职业 → 资产负债与现金流 → 身份和辖区 → 既有保障 → 决策角色 → 目标与时间 → 风险偏好和限制`

每项信息标记为已验证、客户陈述、第三方来源、顾问假设或待专业核验，避免把猜测写进方案。

### 3. 精准营销闭环

`画像准备 → 收集KYC → 区分事实与未知 → 面谈提问 → 风险排序 → 保险/非保险工具比较 → 备选方案 → 客户决定 → 服务与复盘`

面谈使用PDCA持续校验。结果可以是购买、补资料、转介、暂缓或不适合。

### 4. 客户关键模型

- 企业主：企业、家庭与连接层风险图，使用家企混同四问。
- 跨境客户：人、家、产、税法、现金流五维矩阵。
- 突发财富：住房、流动性、保障、长期目标四账户。
- 波动收入者：生活税费底线、保障、长期目标三层现金流。
- 投资者：安全、收益、流动、法律四维评价，区分投资与保险功能。
- 育儿及白领家庭：先保护人力资本和主要抚养责任，再分阶段升级。

### 5. 权利结构检视

保单必须分别回答谁缴费、谁控制、谁被保障、谁领取、何时变更。投保人、被保险人和受益人分离只是一种权利事实，不天然产生免税、避债、资产隔离或跨境便利。

### 6. 使用红线

不以群体刻板印象、恐惧、从众、奢华礼物或虚假紧迫推动成交。涉及婚姻、债务、税务、继承、执行、外汇和跨境身份时，使用当前法律与个案事实，并由有资质专业人士核验；书中历史案例不可直接复制。
