# 术语表

| 术语 | 含义 | 章节 |
|---|---|---|
| 客户画像 | 根据有限信息形成的初步特征组合，只用于准备待验证问题。 | 全书 |
| KYC | 持续了解客户的人、家、业、产、身份、目标、决策和限制，并记录信息来源。 | ch01, ch02, ch06, ch08 |
| 显性需求 | 客户主动表达并确认的目标。 | ch01 |
| 潜在风险 | 顾问根据事实提出、仍需客户确认的可能后果。 | ch01 |
| 家企混同 | 企业与个人在账户、财产、借款或交易程序上边界不清的现象。 | ch01, ch07 |
| 税收居民身份 | 判断特定辖区申报和纳税义务的重要事实，不等于国籍。 | ch02 |
| 资产属地 | 资产所在或登记的国家、地区，可能影响税务、继承和执行。 | ch02 |
| 跨境现金流 | 资金在不同辖区和币种间的缴纳、领取、汇兑与使用。 | ch02 |
| 家业传承 | 财产、企业角色、治理能力与代际共识的共同延续。 | ch03 |
| 突发财富 | 在短期内获得显著资产，可能带来消费、集中投资和决策能力错配。 | ch04 |
| 报复性消费 | 用集中消费补偿过往约束的行为风险。 | ch04 |
| 个人品牌资产 | 依靠声誉、内容或影响力产生收入，但难稳定估值和分散的职业资产。 | ch05 |
| 基线预算 | 按保守而非高峰收入安排长期支出和缴费。 | ch05 |
| 保单盘点 | 检查责任、保额、期限、角色、缴费、受益和重复缺口。 | ch06 |
| 闲置资金 | 满足经营、债务、税费、生活和应急后可用于长期安排的资金。 | ch07 |
| 黑天鹅 | 难预测且影响显著的事件，规划目标是提高韧性而非预测事件。 | ch08 |
| 风险预算 | 在保障、稳健和高波动资产间按目标分配可承受风险。 | ch09 |
| 人力资本 | 个人未来劳动收入的经济价值。 | ch10 |
| 抚养风险 | 父母身故、失能或重疾导致收入与照护能力下降。 | ch11 |
| PDCA | 计划、执行、检查、调整的循环面谈与复盘方法。 | ch12 |
| 理财四性 | 安全性、收益性、流动性和法律性四个评价维度。 | ch13 |
| 权利结构 | 投保、控制、被保障、受益及变更等角色和权利关系。 | ch02, ch03, ch06, ch09 |
