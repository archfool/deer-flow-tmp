# 精准营销速查

## 客户信息状态

为每条关键信息标记：

- `V` 已由可靠资料验证
- `C` 客户本人陈述
- `T` 第三方提供，待客户确认
- `H` 顾问假设
- `P` 待法律、税务、会计或其他专业人士核验

任何方案核心前提若仍是 `H`，先提问；若是 `P`，先转介或明确条件。

## 方案前五个检查

1. 客户标签是否已转换为问题并验证？
2. 资金是否真的可长期使用，压力情景下能否持续？
3. 风险是否分别匹配保险与非保险措施？
4. 权利结构及未来变更是否清楚？
5. 方案是否含备选、不利因素和暂缓选项？

## 法律税务红线

- 不承诺保单天然免税、避债、隔离、免申报或方便出境。
- 不为已发生的执行、债务或争议协助转移资产。
- 不用书中历史税率、豁免额、政策和案例回答当前问题。
- 不擅自起草或解释超出资质的法律文件。
- 涉跨境、婚姻、继承、公司和税务时记录专业核验人及前提。

## 沟通红线

- 不用人群刻板印象判断能力、婚姻或消费。
- 不用事故故事、同伴购买或礼物制造压力。
- 不把高收入、高资产等同于高缴费能力。
- 不用“必须现在买”替代真实时间条件。
