# Chapter 12: 第12章 中年男性

## Core Idea

中年可能叠加健康变化、事业压力、家庭责任和财富积累，但性别与年龄不能替代个体调查。最可迁移的方法是PDCA：面谈前形成假设，执行中倾听，持续验证并调整，面谈后将新事实带入下一轮计划。

## Frameworks Introduced

### 面谈PDCA

- **Plan**：列出客户已知事实、待验证假设、沟通目标和问题顺序。
- **Do**：执行提问与说明，同时观察客户反馈。
- **Check**：用复述、追问和客户自己的总结确认理解与偏好。
- **Adjust**：改变话题深度、方案或下一步；会后复盘成为新一轮计划。

### 靠问不靠猜

画像只用于准备问题。主动咨询者可问“是什么事件让您开始考虑”；被动接触者可问“刚才哪些后果与您最相关”。敏感问题先说明用途、取得同意，并允许客户不回答。

### 三个抓手、一个核心

可从客户熟悉的资产或事业、当前家庭责任、未来退休传承三个方向寻找事实抓手；核心始终是客户需要解决的问题，不是预定产品。具体抓手随客户变化，不固定套用。

## Key Concepts

- **计划假设**：根据有限信息形成、必须在面谈中验证的判断。
- **反馈信号**：语言内容、停顿和行为只能提示继续询问，不能代替客户确认。
- **复盘**：比较计划与实际，记录新事实、有效问题、误判和下一步。
- **隐私边界**：客户有权知道问题用途并拒绝披露。

## Mental Models

- **模型是起点，不是答案**：年龄、职业和资产画像帮助准备，但不决定需求。
- **倾听是执行的一半**：PDCA中的Do不是单向讲解。
- **请客户自己思考，不替客户说服自己**：问题用于澄清，不用于操控。

## Anti-patterns

- 以“中年男性不愿求助”等概括判断所有客户。
- 从表情或停顿直接推断购买意愿。
- 计划里只有产品卖点，没有待验证问题。
- 把Adjust理解为寻找更强的成交抓手，而非允许调整为暂缓或转介。

## Worked Example

50岁客户主要持有出租房。计划阶段假设他可能关心流动性、管理负担和传承，但面谈中客户明确最关注的是退休后稳定租金。顾问不强行否定房产，而是检查空置、维修和集中度情景，再比较继续持有、逐步调整和补充其他现金流的方案。会后记录客户真正优先级，下一次只深化相关问题。

## Key Takeaways

1. PDCA把画像假设转化为可验证、可调整的面谈过程。
2. 靠问不靠猜，同时尊重隐私与拒绝回答的权利。
3. 反馈信号需要复述确认，不能直接推断。
4. 调整的结果可以是换方案、补信息、转介或停止推进。
