# Chapter 7: 第7章 企业家

## Core Idea

企业家客户时间有限、重视有效信息且首先关注企业。面谈价值来自事前形成高质量假设，事中用简洁问题验证，并将企业资产、不动产、金融资产与家庭责任分层，而不是用头衔判断其需求或保费能力。

## Frameworks Introduced

### “庙算三问”

1. **为什么要买**：客户当前事件、目标或风险是什么？
2. **为什么向我买**：顾问能提供哪些可信专业能力和协作资源？
3. **为什么现在买**：是否存在真实时间窗口；若没有，不制造紧迫性。

三问用于检验准备是否充分，不用于为成交编造理由。

### 企业家资产三层

- **企业资产**：股权、经营现金流、债务、关键人员和传承。
- **不动产**：自用与投资目的、权属、现金流、集中度和变现性。
- **金融与家庭资产**：流动资金、投资组合、保单及家庭责任准备。

三层之间通过担保、借款、分红、共有和继承关系连接。

### 六类需求扫描

企业经营延续、家企风险边界、个人健康与身故、家庭生活、婚姻与代际、养老与传承。逐项标注事实、重要度、紧迫度和可用工具。

### 邀约阶梯

短信或书面说明目的 → 电话确认价值与时长 → 必要时面对面沟通。每次接触都尊重拒绝，不以连续触达制造压力。

## Key Concepts

- **决策权**：客户是否能单独决定，还是需配偶、股东、财务或专业顾问参与。
- **闲置资金**：在满足经营、税费、债务和应急后确实可作长期安排的资金。
- **专业价值**：问题质量、证据、协作边界和交付结果，不是头衔或话术。
- **真实时点**：身份、责任、产品条件或家庭事件带来的时间要求。

## Mental Models

- **企业家先看经营连续性**：从企业问题进入，再连接个人和家庭后果。
- **资产分层，关系连线**：既避免家企混为一体，也不忽略相互传导。
- **短沟通要有高信息密度**：少讲概念，多确认关键事实和下一步。

## Anti-patterns

- 把熟悉、有子女、40至60岁等当作“高成交概率”定律。
- 将账面企业价值当作可缴保费资金。
- 为回答“为什么现在买”而制造虚假稀缺。
- 只向企业家本人说明，忽略共同决策者和专业顾问。

## Worked Example

制造企业老板表示想做“财富隔离”。顾问用三层图发现其核心风险是个人为企业贷款担保、企业回款波动以及子女不准备接班。保险不能消除已存在的担保责任，因此方案先由律师和财务顾问处理债务与治理，再测算关键人身故对家庭和企业现金流的影响，最后讨论适合保险转移的部分。

## Key Takeaways

1. 庙算三问检验客户动机、顾问价值和真实时点。
2. 企业、不动产、金融家庭资产要分层并连接关系。
3. “闲钱”必须在经营与家庭义务之后确认。
4. 企业问题经常需要保险、法律、税务和治理协同。
