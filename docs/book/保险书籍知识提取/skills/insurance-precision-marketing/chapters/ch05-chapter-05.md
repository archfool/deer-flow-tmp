# Chapter 5: 第5章 网红明星

## Core Idea

网红与演艺从业者的财富能力高度依赖个人品牌、平台规则和不稳定收入。规划应把职业生涯当作波动性资产，先建立生活与保障底线，再处理投资、婚姻和长期现金流，而不是被当期高收入误导。

## Frameworks Introduced

### 五类风险地图

1. **声誉与合约风险**：人设、代言、内容和合作违约可能冲击收入。
2. **投资消费风险**：高收入期扩张支出或进入不熟悉投资。
3. **职业持续风险**：平台、流量、竞争和创作能力变化。
4. **婚姻家事风险**：资产权属、共同负担和关系变化。
5. **健康意外风险**：高强度工作中断本人这一核心收入资产。

其中并非所有风险都能由保险承保；先标注保险、合同、储备和管理措施各自作用。

### 波动收入三层现金流

`生活与税费底线 → 健康/责任保障 → 长期目标与风险投资`

用保守收入情景测算持续缴费能力，高收入月份可补充储备，不把峰值收入当作永久基线。

### 观点论证六步

话题切入 → 提出可验证观点 → 说明因果和证据 → 请客户确认影响 → 提供备选方案 → 说明责任与限制。原书的“结论成交”应改为“结论确认”，避免先定成交再找方案。

## Key Concepts

- **个人品牌资产**：能产生收入但无法像普通金融资产一样稳定估值或分散。
- **平台依赖**：流量和收入受第三方规则影响。
- **职业收入中断**：疾病、声誉或平台事件可能同时影响当前收入和未来机会。
- **基线预算**：按低于高峰收入的稳健水平安排长期承诺。

## Mental Models

- **收入高不等于收入稳**：保费能力看跨周期现金流，而非单年峰值。
- **先保护发动机**：健康、应急储备和合约管理优先于收益展示。
- **风险与工具一一对应**：声誉风险不能用寿险替代，税务问题也不能用年金包装。

## Anti-patterns

- 因客户知名或高收入就默认可以承受大额长期缴费。
- 利用隐私、婚姻或“塌房”恐惧推动成交。
- 宣称保险能覆盖声誉、平台和全部职业风险。
- 把两次面谈预设成必然成交路径，不接受客户暂缓。

## Worked Example

内容创作者过去一年收入很高，但六成来自单一平台和两个品牌。顾问以低收入情景计算生活、税费和应急储备，识别健康中断与家庭责任缺口；合约和声誉风险转交律师及团队管理，保险只覆盖符合责任的健康、身故和长期现金流目标。长期产品的缴费额按保守基线设计，并保留流动性。

## Key Takeaways

1. 网红明星规划的核心是职业和收入的集中与波动。
2. 五类风险必须分别匹配保险和非保险措施。
3. 长期承诺按保守现金流而非收入峰值测算。
4. 沟通中的结论应由客户确认，不应预设成交。
