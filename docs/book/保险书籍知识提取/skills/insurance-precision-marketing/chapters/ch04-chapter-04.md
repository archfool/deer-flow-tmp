# Chapter 4: 第4章 拆迁户

## Core Idea

突然获得大额补偿并不自动形成高净值管理能力。面对拆迁或其他一次性财富事件，首要任务是让客户从情绪和即时消费中获得决策缓冲，厘清资产权属、住房需求、现金流和代际目标，再分阶段安排安全、流动和长期资金。

## Frameworks Introduced

### 突发财富四账户

1. **近期生活与住房账户**：搬迁、购房、税费和家庭必要支出。
2. **流动性账户**：应急与短期可预见需求。
3. **保障账户**：医疗、身故、失能和责任缺口。
4. **长期目标账户**：养老、子女、传承或长期投资。

四账户是用途分层，不代表必须购买四类产品。

### 高净值面谈三段论

- **事前准备**：核实补偿性质、权属、家庭成员、负债和近期安排。
- **事中面谈**：先处理焦虑和目标，再解释控制、风险和备选，不急于给产品。
- **事后追踪**：提供书面方案、冷静期和分步执行，检查家庭关键成员是否参与。

### 控制权四问

钱归谁、谁能决定使用、什么事件会改变控制、最终希望给谁。把“安全传承”翻译为具体权利与条件，再由专业人士核验。

## Key Concepts

- **报复性消费**：财富突然增加后用高消费补偿过往约束的行为风险。
- **资产管理能力**：理解风险、流动性、期限、分散和法律关系的能力，与资产金额无必然关系。
- **选择权**：顾问提供可比较路径，客户保留决定和暂缓权。
- **分步执行**：先处理不可逆或紧迫事项，其余安排经过冷静和复核。

## Mental Models

- **先停车，再导航**：财富事件发生后先避免仓促不可逆决策。
- **房产多不等于现金流稳**：持有成本、变现和集中度要单独评估。
- **控制不是占有的同义词**：名义权属、使用权和未来受益应分别看。

## Anti-patterns

- 看到补偿款就按“保费容量”推大额产品。
- 以同类客户案例暗示结果必然相同。
- 将老年客户或拆迁户统一描述为缺乏理财能力。
- 用“绝对安全、高效传承”替代权利、条件和风险说明。

## Worked Example

退休夫妇获得拆迁补偿，女儿建议立即购买多套房产。顾问先确认过渡住房、养老开支、现有房产权属和双方意见，将资金划分为住房、流动、保障和长期目标四个用途。对女儿婚姻财产与未来传承的担忧，先形成控制权问题清单，再由法律专业人士验证；保险只参与适合长期现金流或保障的部分。

## Key Takeaways

1. 突发财富规划首先需要情绪缓冲和事实确认。
2. 四账户按用途分层，产品选择在后。
3. 控制、流动和传承应分别定义，不能用“安全”一词打包。
4. 分步执行能降低一次性错误和销售压力。
