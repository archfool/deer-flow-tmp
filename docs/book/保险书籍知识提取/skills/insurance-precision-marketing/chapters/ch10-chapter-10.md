# Chapter 10: 第10章 年轻白领

## Core Idea

年轻白领的主要资产往往是未来劳动收入，而非现有金融资产。配置应先保护健康和收入能力，在有限预算下覆盖高影响风险，并随职业、婚姻、负债和家庭责任变化逐步升级。

## Frameworks Introduced

### 人力资本资产负债表

- **资产端**：未来收入、职业技能、社保与单位福利、储蓄和既有保障。
- **负债端**：生活支出、贷款、父母支持、配偶或子女责任及长期目标。
- **风险冲击**：疾病、伤残、失业或身故如何同时减少资产并放大责任。

### 四项配置原则的条件化

1. **先人后财**：当收入能力是主要资产时，健康与责任优先；高价值财产仍按实际损失评估。
2. **阶段适配**：单身、成家、育儿、购房和创业触发不同缺口。
3. **主要责任人优先**：预算有限时先覆盖事故后果最大的成年人，不是机械地“大人永远先于孩子”。
4. **尽早评估而非立即购买**：年轻可能带来核保和期限优势，但仍要先判断需求与支付能力。

### 六步沟通

接触 → 从职业或生活事实切入 → 确认共同问题 → 测算风险金额 → 解释保障逻辑 → 由客户比较选择。把原书“六步搞定客户”改为“六步完成决策”，结果可以是购买、暂缓或不适合。

## Key Concepts

- **人力资本**：未来劳动收入的经济价值，会随职业发展、健康和时间变化。
- **单位福利缺口**：社保和雇主保障不足以覆盖的费用、收入或责任。
- **保费持续性**：当前与压力情景下都能承担的长期支付能力。
- **分阶段加保**：先解决核心缺口，责任增长时再检视。

## Mental Models

- **钱少更要按后果排序**：低频但足以破坏财务的风险优先。
- **保额先于产品丰富度**：预算有限时避免用复杂附加责任稀释核心保额。
- **不说“你要买”**：帮助客户自行确认风险与选择。

## Anti-patterns

- 用“年轻就是最佳时机”制造立即成交压力。
- 按工资固定比例配置，不计算负债和责任。
- 忽略公司福利、已有保单或短期失业风险。
- 为追求一步到位设置无法持续的长期保费。

## Worked Example

28岁白领有房贷、公司补充医疗和六个月应急金，暂未承担子女责任。人力资本表显示医疗费用已有一定补偿，但重疾停工和伤残会影响房贷。方案优先补收入中断与长期责任，不急于配置高额教育或养老产品，并约定结婚、换岗或收入变化后重新测算。

## Key Takeaways

1. 年轻客户首先要保护未来收入这一核心资产。
2. 四项原则都需结合客户事实，不能机械套用。
3. 有限预算优先覆盖高影响缺口并保持缴费可持续。
4. 销售流程帮助决策，不以“搞定客户”为目标。
