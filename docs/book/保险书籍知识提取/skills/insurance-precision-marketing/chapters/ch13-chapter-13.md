# Chapter 13: 第13章 普通投资者本

## Core Idea

普通投资者常以安全和收益评价理财工具，却可能忽略流动性、法律关系、保障与时间目标。顾问不应先否定客户熟悉的银行理财或基金，而应建立统一四维框架，识别每类资金的用途，再把保险放回风险保障与长期现金流的位置。

## Frameworks Introduced

### 理财新四性

1. **安全性**：本金和收益受到哪些市场、信用、机构及行为风险影响。
2. **收益性**：保证与非保证、名义与实际、预期与实现分别是什么。
3. **流动性**：何时可用、退出成本、市场压力下能否变现。
4. **法律性**：权属、合同主体、受益、继承、税务和执行等关系。

四性必须在同一时间跨度和风险口径下比较。

### 目标分桶

`应急与近期使用 → 风险保障 → 中期目标 → 退休与长期现金流 → 可承受损失的投资`

同一工具可以服务多个目标，但要避免一笔钱被重复计算。

### 认知更新三步

先询问客户选择现有产品的理由；再用当前文件和数据检验安全、收益、流动和法律假设；最后在保留合理习惯的基础上做小幅、可理解的调整。

## Key Concepts

- **风险收益关系**：回报需要承担相应风险，不存在脱离条件的高收益安全工具。
- **量入为出**：投资与保费承诺不破坏日常支出和应急能力。
- **长期规划**：按目标时间安排资金，而非连续滚动短期产品代替所有未来需求。
- **投资与保障兼顾**：投资积累财富，保险处理约定损失，两者功能互补。

## Mental Models

- **不要推翻客户的整个系统**：先保留有效部分，再修正集中和错配。
- **同口径比较**：不能拿保证利益与高风险历史收益直接相比。
- **现金流比产品名称重要**：看钱何时进、何时出、什么条件下受损。

## Anti-patterns

- 为卖保险而笼统宣称银行理财不安全或收益必然下降。
- 一上来谈产品，未了解客户现有习惯和目标。
- 用“保险理财”模糊保障责任、现金价值和非保证利益。
- 把复杂问题简化到遗漏风险与限制。

## Worked Example

客户将八成金融资产放在短期银行产品，重视安全和随时可用。顾问用四性框架确认其中一部分确实承担应急功能，但养老资金长期滚动带来再投资风险，家庭保障也不足。调整方案保留应急和短期工具，补足保障，再为养老比较国债、存款、基金和年金等多种路径；不以保险替代全部投资。

## Key Takeaways

1. 安全、收益、流动和法律四性应统一比较。
2. 先理解现有选择，再用证据更新认知。
3. 资金按用途和时间分桶，避免重复计算。
4. 保险补充风险保障和长期现金流，不与所有投资争夺同一功能。
