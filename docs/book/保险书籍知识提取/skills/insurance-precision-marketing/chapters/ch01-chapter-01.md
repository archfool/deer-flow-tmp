# Chapter 1: 第1章 中小企业主

## Core Idea

中小企业主的个人、家庭和企业现金流往往相互影响，精准营销的入口不是“老板有钱”，而是查清家企边界、经营波动、债务责任和家庭目标。客户画像只提示调查方向，最终方案必须由经过验证的KYC事实推导。

## Frameworks Introduced

### 中小企业主双层风险图

- **企业层**：经营、应收账款、负债、税务、关键人员和股权延续。
- **家庭层**：医疗与身故责任、养老、婚姻财产、子女教育和传承。
- **连接层**：个人账户收取企业款项、非规范分红、股东借款、个人担保和家庭资产投入企业等家企混同点。

### 家企混同四问

1. 企业是否给经营者发放并记录工资？
2. 是否使用个人账户收取企业经营款？
3. 是否存在未按规范程序将企业利润转入家庭？
4. 是否存在长期未归还的股东或关联借款？

四问用于发现需要会计、税务或法律核查的线索，不直接得出违法或资产隔离结论。

### 需求导向营销链

`收集KYC → 区分事实与假设 → 提出未知问题 → 面谈验证 → 风险排序 → 比较保险与非保险措施 → 设计并复核方案`

## Key Concepts

- **KYC**：家庭成员、身份、企业、资产负债、收入结构、既有安排、目标和限制的持续了解过程。
- **显性需求**：客户主动表达的目标，如养老、跨境生活或子女资金。
- **潜在风险**：由事实推导、仍需客户确认的经营或家庭后果。
- **家企边界**：企业财产、个人财产和交易程序是否清晰可证明。

## Mental Models

- **企业资产不等于家庭可支配财富**：账面规模、股权估值和个人流动资金必须分开。
- **先查连接点**：家企风险常通过担保、账户、债务和控制权传递。
- **保险是组合工具**：公司治理、合同、税务和现金流问题不能由保单单独解决。

## Anti-patterns

- 只知道投保人和被保险人，就声称已经完成KYC。
- 把保险描述成能解决所有经营、债务、税务和传承问题的“大力丸”。
- 以产品收益为主线，忽略企业主的流动性和持续缴费风险。
- 把未经核验的婚姻、身份或境外资产信息当作方案前提。

## Worked Example

建筑公司老板希望为家人准备境外生活资金。顾问先标注已知事实与四个未知项：夫妻共同目标、各成员身份变化、企业与个人账户往来、资金使用时间。面谈确认后，分别评估经营流动性、家庭保障和跨境合规；只有适合保险承担的长期现金流与身故责任进入保单方案，身份、税务和汇兑问题交由对应专业人员按现行规则验证。

## Key Takeaways

1. 中小企业主分析必须同时覆盖企业、家庭和连接层。
2. KYC的价值在于发现未知项并面谈验证，不是堆积资料。
3. 家企混同四问只生成核查任务，不能替代法律或税务判断。
4. 产品方案应晚于风险排序和非保险措施比较。
