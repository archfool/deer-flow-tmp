# Chapter 6: 第6章 富太太

## Core Idea

“富太太”描述的是家庭角色，不足以说明资产权属、收入能力或决策权。精准服务要把客户作为独立主体，了解其个人目标、家庭资产信息、控制与安全感来源，再形成家庭协同但不抹去个人意愿的方案。

## Frameworks Introduced

### 独立KYC六问

1. 哪些收入与资产由客户本人取得、持有或管理？
2. 家庭日常和重大财务决定由谁参与？
3. 客户对本人、配偶、子女和父母分别承担什么责任？
4. 婚姻、健康或收入变化时最担心什么？
5. 现有保单的投保人、被保险人、受益人和缴费来源是什么？
6. 客户希望获得保障、现金流、控制权还是传承安排？

### 服务型展业流程

`建立服务价值 → 收集并验证KYC → 梳理既有保单 → 发现重复与缺口 → 提供组合备选 → 记录后续服务`

保单整理本身就能创造价值，不应刻意把每次整理都转成新销售。

### 权利与安全感地图

分别标注资产所有、合同控制、缴费责任、被保障利益和最终受益。客户说“没有安全感”时，继续确认是现金流、健康、婚姻、信息不透明还是决策权问题。

## Key Concepts

- **个人目标**：客户本人希望实现的生活与财务结果，不等于配偶或子女目标。
- **保单盘点**：检查责任、保额、期限、角色、缴费状态、受益安排和重复缺口。
- **方案而非单品**：保险与现金储备、法律安排和家庭沟通共同处理问题。
- **后续服务**：保全、年度检视、理赔协助和家庭变化后的更新。

## Mental Models

- **家庭角色不等于财务事实**：全职照护者也可能拥有资产与决策权，职业女性也可能缺少独立控制。
- **先定义安全，再配置工具**：模糊情绪需要翻译为具体事件和现金流。
- **信任来自客观盘点**：指出“不需要新增”也是专业服务。

## Anti-patterns

- 预设年龄偏大、婚姻不稳或只关心子女。
- 以“客户有钱”为理由主张方案一定要足够大。
- 放大痛点或焦虑，却不核实事件概率、后果和客户意愿。
- 将客户社交圈视为转介绍资源，忽略隐私和授权。

## Worked Example

客户希望“给自己多一点保障”，但家庭保单全部由配偶管理。盘点后发现医疗与重疾保障已有基础，真正担忧是本人缺少可自主使用的应急资金以及保单信息不透明。顾问先协助建立家庭保单清单和服务授权，讨论独立流动性，再评估是否新增保险；复杂婚姻财产问题由律师核验，避免用一张大保单替代全部需求。

## Key Takeaways

1. 把客户作为独立决策主体，不用家庭标签代替事实。
2. 安全感应拆成现金流、健康、权利和关系问题。
3. 保单盘点可能得出补充、调整或无需新增三种结论。
4. 后续服务以客户授权和隐私保护为前提。
