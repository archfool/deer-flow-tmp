# Chapter 9: 第9章 职业投资者

## Core Idea

职业投资者容易用收益率和可交易性评价保险，但保险的核心价值通常是风险转移、长期责任和特定现金流。沟通不应证明保险“投资更好”，而应说明投资账户与保障账户解决不同问题，并校验客户能否持续承担保费和流动性限制。

## Frameworks Introduced

### 投资与保险功能对照

| 维度 | 投资工具 | 保险工具 |
|---|---|---|
| 主要目标 | 承担风险以获取回报 | 转移约定风险或安排合同现金流 |
| 结果来源 | 市场、资产和策略表现 | 合同责任及可能的保证/非保证利益 |
| 流动性 | 视资产而定，通常可交易 | 受期限、现金价值和保全规则约束 |
| 关键风险 | 市场、信用、操作和行为 | 责任不匹配、退保损失、持续缴费和机构履约 |

### 生命周期风险预算

随着年龄、家庭责任和资产规模变化，分别设定保障资本、稳健资金和进攻型投资的用途与上限。不能仅因年龄增加就机械要求放弃进攻型投资。

### 财富保全五问

要保护什么目标、面临什么事件、现有投资在该事件下会怎样、保险合同能覆盖哪一段、剩余风险由什么措施承担。

## Key Concepts

- **强制储蓄**：通过长期合同约束资金使用；同时意味着流动性代价。
- **定向受益**：通过受益人安排表达给付意愿，但实际法律效果受合同、事实和现行法律约束。
- **“三权”结构**：投保、被保障和受益角色可以分离；不天然产生债务隔离或税务效果。
- **生命等长现金流**：部分年金可按约定提供生存期间给付，需核对保证期间和具体责任。

## Mental Models

- **功能互补，不比单项收益**：保险不需要在收益率上战胜投资才能有价值。
- **风险预算而非产品对抗**：同一客户可以同时持有保险与高波动资产。
- **法律效果必须验证**：角色设计是事实起点，不是隔离结论。

## Anti-patterns

- 贬低客户投资能力以证明保险价值。
- 宣称保单绝对避债、免税或不被执行。
- 用历史演示收益与客户投资业绩作不对等比较。
- 仅因客户接近退休就要求其清空进攻型资产。

## Worked Example

职业投资者认为可用投资收益覆盖家庭一切风险。顾问不争论谁的收益更高，而是压力测试：若本人重疾并在市场下跌期停止工作，家庭支出是否迫使低价卖出资产。由此划出医疗与家庭责任的保障资本，剩余资产仍按其投资策略管理；保单流动性和非保证利益单独披露。

## Key Takeaways

1. 投资追求风险回报，保险处理约定风险和合同现金流。
2. 保障、稳健和进攻资金应按目标分账，而非互相排斥。
3. 强制储蓄、定向受益和角色分离都有条件与代价。
4. 债务、税务和传承法律效果必须个案核验。
