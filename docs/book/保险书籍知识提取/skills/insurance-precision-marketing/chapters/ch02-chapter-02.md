# Chapter 2: 第2章 移民跨境客户

## Core Idea

跨境客户的复杂性来自家庭成员、税收居民身份、资产所在地、法律适用和现金流币种不在同一辖区。精准服务应先建立跨境事实矩阵，再由有资质的税务与法律专业人士验证；保险方案只能处理其中明确适配的保障或现金流目标。

## Frameworks Introduced

### 跨境五维矩阵

| 维度 | 需要确认 |
|---|---|
| 人 | 国籍、居留、税收居民身份及变化计划 |
| 家 | 配偶、子女、代际关系和实际生活地 |
| 产 | 企业、房产、金融资产、保单的所在地与权属 |
| 税法 | 可能涉及的所得、赠与、遗产、申报和继承规则 |
| 流 | 收入、缴费、领取、汇兑和跨境使用的时间与币种 |

### 面谈准备四件套

1. 根据客户选择的话题准备问题清单。
2. 收集KYC并明确来源与可信度。
3. 把已知、未知和需要专家确认的事项分栏。
4. 形成沟通提纲和专业协作清单，而不是背诵固定话术。

### 顾问式沟通

先让客户描述目标与经历，再解释不同辖区的风险差异，最后比较保险、信托、遗嘱、公司安排等工具。最想销售的产品不一定是客户最迫切需要的工具。

## Key Concepts

- **税收居民身份**：决定申报和纳税义务的重要事实之一，不能仅凭国籍或签证推断。
- **资产属地**：资产所在国家或地区可能影响继承、执行、税务和手续。
- **跨境现金流**：缴费和领取是否能在需要的地点、币种和时间合法完成。
- **提前规划**：已经进入执行、争议或税务事件时，许多安排的空间会显著缩小。

## Mental Models

- **一个家庭，多套规则**：每位成员和每项资产都可能落入不同制度。
- **先画地图，再选工具**：没有矩阵就讨论产品，容易遗漏关键辖区。
- **专业边界也是方案内容**：明确哪些结论由谁验证，比给出确定口号更可靠。

## Anti-patterns

- 用过往的税率、豁免额或CRS解释直接回答当前个案。
- 宣称某种保单天然免税、免申报、免执行或可自由跨境。
- 在客户已是被执行人或争议已发生后设计资产转移。
- 把境外身份等同于必须配置某地保险。

## Worked Example

客户在中国经营企业，配偶和子女计划长期居住美国，并关心未来传承成本。顾问先按人、家、产、税法、现金流列出矩阵，确认哪些身份已取得、哪些只是计划，资产权属和资金用途是什么。随后由中美税务与法律顾问核验申报和继承规则，保险顾问仅比较寿险在保障、流动性和受益安排中的作用，不承诺税务结果。

## Key Takeaways

1. 跨境规划的第一产物是事实矩阵，不是保单结构图。
2. 身份、资产、税法和现金流必须按辖区逐项核验。
3. 保险与法律、税务、信托工具各有边界。
4. 任何“免税、隔离、出境方便”的结论都要基于当前规则和个案事实。
