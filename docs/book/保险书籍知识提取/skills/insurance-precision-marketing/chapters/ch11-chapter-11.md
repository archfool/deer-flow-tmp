# Chapter 11: 第11章 宝妈

## Core Idea

育儿家庭的保险规划不能只围绕孩子。孩子的医疗、健康和教育重要，但父母的收入与照护能力决定这些目标能否实现。沟通可以从育儿经验建立共情，决策仍应回到事实、金额、优先级和合同条件。

## Frameworks Introduced

### 家庭抚养风险链

`父母健康/收入 → 日常抚养与住房 → 儿童医疗 → 教育现金流 → 长期目标`

任何一环中断都会影响后续目标，因此先检查父母责任保障，再判断儿童保障与教育储备。

### 感性到理性四步

1. **共情切入**：理解育儿目标，不利用焦虑。
2. **理性分析**：列出健康、教育和抚养风险及现有资源。
3. **确认需求**：让客户选择最关心的后果与预算边界。
4. **合理配置**：分别处理费用补偿、定额保障、父母责任和教育资金。

### 儿童方案四项校验

投保人持续缴费能力、投保人豁免条件、医疗险责任与续保、教育资金的领取时间与流动性。万能账户、增额寿险等不能因名称直接视为适合儿童。

## Key Concepts

- **抚养风险**：父母身故、失能或重疾使收入与照护能力下降。
- **教育现金流**：在相对固定时间发生的支出，应与应急和保障资金分开。
- **投保人豁免**：达到合同约定条件后免交后续保费，需核对触发条件和责任。
- **家庭整体配置**：父母和孩子的保障、储备与预算共同规划。

## Mental Models

- **先保护抚养者**：孩子的长期计划依赖父母持续供给。
- **爱不等于保费越大越好**：保额与储备由风险缺口和支付能力决定。
- **情绪打开对话，数据完成决策**：共情不能取代事实与条款。

## Anti-patterns

- 用真实事故故事制造恐惧或暗示“不买就是不负责”。
- 把“越早、越多越好”当成不附条件的配置原则。
- 只为孩子购买长期产品，父母责任保障不足。
- 直接把销售记录或他人购买情况用于从众施压。

## Worked Example

新手父母希望把大部分预算投入孩子教育年金，但家庭只有三个月应急金，父亲是主要收入者且寿险不足。风险链显示父亲收入中断会同时破坏住房、生活和教育目标。方案先补应急和父母责任保障，再用可承受金额建立教育资金；儿童医疗和投保人豁免按具体合同核对，不追求产品堆叠。

## Key Takeaways

1. 育儿规划先看父母的收入与照护连续性。
2. 共情用于理解目标，理性分析用于确定优先级。
3. 儿童产品要检查缴费、豁免、医疗责任和资金时间。
4. “爱孩子”不能被转化为无限保费或强制成交。
