# Chapter 3: 第3章 富二代

## Core Idea

家族财富继承人的差异不在“富二代”标签，而在其经济独立、事业参与、风险意识、投资经验和家族治理角色。销售人员应尊重其自主性，区分父母目标与本人目标，再讨论保障、控制、传承和成长资金。

## Frameworks Introduced

### 继承人五维画像

1. 财富来源与本人可控制资产。
2. 是否有独立事业、收入和创富能力。
3. 投资经验、风险偏好和流动性需求。
4. 婚姻、子女和家庭责任。
5. 与上一代在控制、传承和治理上的一致或冲突。

书中的“纯粹型/新型”可作粗略假设，但不能据此判断能力或品格。

### 面谈四步

`尊重与建立边界 → 了解个人目标 → 呈现风险和选项 → 由客户确认偏好与下一步`

可用选择题降低复杂度，但选项必须真实、完整，并保留“不选择”的空间。

### 保单角色检视

逐项核对投保人、被保险人、受益人、保费来源、保全控制和未来变更。由父母代持、本人持有或代际变更各有控制和关系后果，不能只追求成交便利。

## Key Concepts

- **家业传承**：不仅是财产转移，也包括企业角色、治理能力和代际共识。
- **风险意识**：对损失概率与后果的认识，应通过具体行为和决策验证。
- **群体认同**：同辈经验可帮助建立话题，但不得利用从众制造压力。
- **仪式感**：能提升决策重视度，不应掩盖条款和真实同意。

## Mental Models

- **继承人是独立决策者**：不能把其视为上一代方案中的被动对象。
- **控制权与受益权分开看**：谁出钱、谁控制、谁受保障、谁领取可能不同。
- **风险沟通不等于贴负面标签**：把保障解释为主动治理，而非暗示客户会败家。

## Anti-patterns

- 使用“败家、纨绔”等刻板印象刺激购买。
- 让同伴成交或圈层仪式替代客户自己的需求判断。
- 只关注保费承受能力，不了解事业、家庭和流动性。
- 设计代持或未来变更安排，却不核验法律、税务和控制后果。

## Worked Example

一位年轻客户的资金来自父母赠与，但本人已创业且需要未来追加投资。顾问不按“富二代爱消费”预设，而是确认其企业现金需求、个人保障、婚姻状态和父母对资金用途的期待。方案比较本人持有与父母作为投保人的控制差异，并保留创业流动性；最终是否投保由客户与出资人分别理解后决定。

## Key Takeaways

1. 用经济独立、事业、投资、家庭和代际关系替代单一人群标签。
2. 父母与继承人的目标要分别收集、共同协调。
3. 保单架构本质上是权利、控制和现金流安排。
4. 同伴影响和仪式感只能辅助沟通，不能替代知情决定。
