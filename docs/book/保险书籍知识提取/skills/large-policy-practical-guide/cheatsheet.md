# 大额保单操作速查

## 一旦出现就停

- 已被起诉、执行或明确存在到期债务
- 资金来源、权属或实际出资无法说明
- 要求隐瞒申报、代签、修改健康或交易事实
- 要求承诺免税、避债、不可执行或绝对隔离
- 需要解释境外法律税务但尚无当地专业意见
