## Core Frameworks & Mental Models

### 1. 操作主流程

`十类风险盘点 → 大额保单五层阅读 → 法律税务停点 → 专项框架 → 工具比较 → 分阶段执行 → 定期复核`

十类风险包括资产集中、规划、披露、控制、婚姻、受益人能力、家企、意外、税务和移民。

### 2. 权利与法律专项

大额保单先读风险、产品、合同、关系人现金价值和功能前提。债务使用七事实，婚姻使用九格，传承使用四问六工具；任何隔离、执行或财产性质都不由产品名称直接决定。

### 3. 税务、信托与境外专项

税务使用主体、资产交易、时间、辖区、保险定性五问；信托完成设立地、角色、财产、撤销、分配、监督、费用和税务八项尽调；境外保单按合法性、法律、监管、币种、利益、费用、税务、服务和争议九项比较。

### 4. 健康与综合案例

健康按预防、医疗服务、费用补偿、重疾定额、收入康复和照护六层规划。综合案例只迁移关系资产图、验证、停点、量化、工具、执行和复核七步，不复制原书个案结论。

### 5. 时效边界

本书大量引用历史法律、司法解释、税率、产品和境外制度。实际使用必须查现行文本，并由对应辖区有资质专业人士确认。
