# 术语表

| 术语 | 含义 | 章节 |
|---|---|---|
| 风险盘点 | 将模糊烦恼改写为事件、后果、时间和证据。 | ch01 |
| 可保风险 | 满足保险承保条件、可由合同转移的风险。 | ch02 |
| 现金价值 | 长期合同在约定时点计算的财产性价值。 | ch02, ch03 |
| 被保险人同意 | 特定人身合同订立或变更所需的真实意思，不能代签替代。 | ch02, ch04 |
| 债务七事实 | 债务时间、主体、担保、执行、保费来源、权利人、撤销执行争议。 | ch03 |
| 婚姻九格 | 资产、来源、时间、登记、出资、约定、混同、债务、证据。 | ch04 |
| 传承四问 | 为何传、传什么、传给谁、怎么传。 | ch05 |
| 税务五问 | 主体、资产交易、时间、辖区、保单利益定性。 | ch06 |
| 健康六层 | 预防、服务、费用、定额、收入康复、照护。 | ch07 |
| 信托财产独立 | 信托财产与相关主体自有财产区分的法律属性，效果依适用法。 | ch08 |
| 受托责任 | 受托人按信托文件和法律为受益目的管理财产的义务。 | ch08 |
| 境外保单 | 在境外法域订立并受其合同、监管和税务环境约束的保单。 | ch09 |
| 多币种风险 | 缴费、资产、给付与支出币种不一致的汇率风险。 | ch09 |
| 专业停点 | 遇到争议、执行、违法或跨专业结论时停止产品推进。 | 全书 |
