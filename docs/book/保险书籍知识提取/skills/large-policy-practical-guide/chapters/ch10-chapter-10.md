# Chapter 10: 第十章 大额保单综合案例分析

## Core Idea

综合案例用于练习把家企、婚姻、债务、继承、税务、健康、跨境和治理放入同一事实图，而非复制张总、金总或上市公司家族的结论。先解决违法违规和治理缺陷，再配置保险资金。

## Frameworks Introduced

### 综合案例七步

建立关系与资产图、验证事实、识别法律税务停点、量化风险、比较工具、分阶段执行、设置复核与责任人。

**何时使用**：遇到类似场景时先应用该框架，再进入产品：企业家客户先处理上市公司股权和债务披露，再分别设计健康保障、传承流动性和家族治理；每项由对应专业人签核。

## Key Concepts

- **概念关系**：综合规划、风险优先级、专业协作、分阶段执行共同构成本章的识别变量；它们通过“综合案例七步”被放入同一事实与决策结构。
- **核验边界**：本章先排除“复制案例架构”；涉及财产、债务、税务、信托、跨境或执行效果时，由对应专业人士按当前事实和规则确认。

## Mental Models

- **先事实后功能**：综合案例用于练习把家企、婚姻、债务、继承、税务、健康、跨境和治理放入同一事实图，而非复制张总、金总或上市公司家族的结论。
- **用结构防止漏项**：建立关系与资产图、验证事实、识别法律税务停点、量化风险、比较工具、分阶段执行、设置复核与责任人。
- **用停点控制风险**：若出现“复制案例架构”或相关争议、执行与违法事项，停止产品推进并转介。

## Anti-patterns

- 复制案例架构。
- 把逃税称为筹划。
- 一次解决十类问题。
- 用败家或争产标签替代家庭访谈。

## Worked Example

企业家客户先处理上市公司股权和债务披露，再分别设计健康保障、传承流动性和家族治理；每项由对应专业人签核。

## Key Takeaways

1. 综合案例用于练习把家企、婚姻、债务、继承、税务、健康、跨境和治理放入同一事实图，而非复制张总、金总或上市公司家族的结论。
2. 本章使用“综合案例七步”组织事实：建立关系与资产图、验证事实、识别法律税务停点、量化风险、比较工具、分阶段执行、设置复核与责任人。
3. 首先排除“复制案例架构”，再判断保险是否适配。
