# Chapter 8: 第八章 大额保单与私人信托

## Core Idea

信托通过受托关系管理财产，其成立、财产独立、受托权限、受益规则和跨境承认依适用法与文件。保险金信托把保险给付与管理规则衔接，不能保证绝对隔离或永久控制。

## Frameworks Introduced

### 信托八项尽调

设立地与适用法、委托/受托/受益人、进入财产、可撤销性、分配规则、监督保护、费用能力、税务申报八项核验。

**何时使用**：遇到类似场景时先应用该框架，再进入产品：客户希望保险金按子女年龄分配，保险顾问与信托机构、律师共同确认给付进入方式、受托权限和变更机制。

## Key Concepts

- **概念关系**：固定与裁量信托、信托财产、受托责任、保险金信托共同构成本章的识别变量；它们通过“信托八项尽调”被放入同一事实与决策结构。
- **核验边界**：本章先排除“把境外信托地排名当答案”；涉及财产、债务、税务、信托、跨境或执行效果时，由对应专业人士按当前事实和规则确认。

## Mental Models

- **先事实后功能**：信托通过受托关系管理财产，其成立、财产独立、受托权限、受益规则和跨境承认依适用法与文件。
- **用结构防止漏项**：设立地与适用法、委托/受托/受益人、进入财产、可撤销性、分配规则、监督保护、费用能力、税务申报八项核验。
- **用停点控制风险**：若出现“把境外信托地排名当答案”或相关争议、执行与违法事项，停止产品推进并转介。

## Anti-patterns

- 把境外信托地排名当答案。
- 承诺不被执行。
- 顾问代拟文件。
- 忽略受托人能力费用与利益冲突。

## Worked Example

客户希望保险金按子女年龄分配，保险顾问与信托机构、律师共同确认给付进入方式、受托权限和变更机制。

## Key Takeaways

1. 信托通过受托关系管理财产，其成立、财产独立、受托权限、受益规则和跨境承认依适用法与文件。
2. 本章使用“信托八项尽调”组织事实：设立地与适用法、委托/受托/受益人、进入财产、可撤销性、分配规则、监督保护、费用能力、税务申报八项核验。
3. 首先排除“把境外信托地排名当答案”，再判断保险是否适配。
