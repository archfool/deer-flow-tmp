# Chapter 3: 第三章 大额保单与债务隔离

## Core Idea

保单债务效果取决于债务形成时间、资金来源、投保和受益关系、现金价值、撤销权、执行规则与是否损害债权人。所谓盾牌只能是待律师验证的相对效果，不能包装成避债工具。

## Frameworks Introduced

### 债务七事实

记录债务时间、责任主体、担保、执行状态、保费来源、合同权利人和可撤销/可执行争议，再讨论保单结构。

**何时使用**：遇到类似场景时先应用该框架，再进入产品：客户已被起诉后要求趸交大额保费，顾问停止产品设计并转介债务律师，不以更换投保人继续操作。

## Key Concepts

- **概念关系**：现金价值、代位与撤销、强制执行、受益人共同构成本章的识别变量；它们通过“债务七事实”被放入同一事实与决策结构。
- **核验边界**：本章先排除“为已负债或被执行客户转移资产”；涉及财产、债务、税务、信托、跨境或执行效果时，由对应专业人士按当前事实和规则确认。

## Mental Models

- **先事实后功能**：保单债务效果取决于债务形成时间、资金来源、投保和受益关系、现金价值、撤销权、执行规则与是否损害债权人。
- **用结构防止漏项**：记录债务时间、责任主体、担保、执行状态、保费来源、合同权利人和可撤销/可执行争议，再讨论保单结构。
- **用停点控制风险**：若出现“为已负债或被执行客户转移资产”或相关争议、执行与违法事项，停止产品推进并转介。

## Anti-patterns

- 为已负债或被执行客户转移资产。
- 承诺低现价不可执行。
- 误解法定受益。
- 用境外司法区规避合法债权。

## Worked Example

客户已被起诉后要求趸交大额保费，顾问停止产品设计并转介债务律师，不以更换投保人继续操作。

## Key Takeaways

1. 保单债务效果取决于债务形成时间、资金来源、投保和受益关系、现金价值、撤销权、执行规则与是否损害债权人。
2. 本章使用“债务七事实”组织事实：记录债务时间、责任主体、担保、执行状态、保费来源、合同权利人和可撤销/可执行争议，再讨论保单结构。
3. 首先排除“为已负债或被执行客户转移资产”，再判断保险是否适配。
