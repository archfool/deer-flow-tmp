# Chapter 7: 第七章 大额保单与健康风险管理

## Core Idea

健康风险管理包含预防、医疗服务、费用补偿、疾病状态给付、收入恢复和照护。高端医疗和重疾险解决不同损失，选择时以告知、定义、网络、费用、期限、续保与核保为核心。

## Frameworks Introduced

### 健康六层

预防与筛查、就医服务、费用补偿、重疾定额、收入康复、长期照护六层分别评估现有资源和缺口。

**何时使用**：遇到类似场景时先应用该框架，再进入产品：客户能自付医疗费但重视全球就医和停工现金流，方案分别比较医疗网络与定额给付，不把二者合为一个保额。

## Key Concepts

- **概念关系**：健康核保、高端医疗、重疾定义、观察/等待期共同构成本章的识别变量；它们通过“健康六层”被放入同一事实与决策结构。
- **核验边界**：本章先排除“病种越多越好”；涉及财产、债务、税务、信托、跨境或执行效果时，由对应专业人士按当前事实和规则确认。

## Mental Models

- **先事实后功能**：健康风险管理包含预防、医疗服务、费用补偿、疾病状态给付、收入恢复和照护。
- **用结构防止漏项**：预防与筛查、就医服务、费用补偿、重疾定额、收入康复、长期照护六层分别评估现有资源和缺口。
- **用停点控制风险**：若出现“病种越多越好”或相关争议、执行与违法事项，停止产品推进并转介。

## Anti-patterns

- 病种越多越好。
- 高端等于全额报销。
- 淡化健康告知。
- 用旧统一病种定义回答当前合同。

## Worked Example

客户能自付医疗费但重视全球就医和停工现金流，方案分别比较医疗网络与定额给付，不把二者合为一个保额。

## Key Takeaways

1. 健康风险管理包含预防、医疗服务、费用补偿、疾病状态给付、收入恢复和照护。
2. 本章使用“健康六层”组织事实：预防与筛查、就医服务、费用补偿、重疾定额、收入康复、长期照护六层分别评估现有资源和缺口。
3. 首先排除“病种越多越好”，再判断保险是否适配。
