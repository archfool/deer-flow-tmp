# Chapter 4: 第四章 大额保单与婚姻财富管理

## Core Idea

婚姻财富管理先判断财产来源、取得时间、出资、权属、使用混同、债务和证据，再分析保费、现金价值、年金和保险金。保单关系人设计不能替代婚姻财产定性和被保险人意愿。

## Frameworks Introduced

### 婚姻九格

资产类型、来源、时间、登记、出资、约定赠与、使用混同、债务、证据九格完成后，由律师判断个人或共同权益。

**何时使用**：遇到类似场景时先应用该框架，再进入产品：父母为已婚子女出资保单，先记录赠与对象和控制安排，由律师核验性质，并披露父母去世或退保时的变化。

## Key Concepts

- **概念关系**：婚前财产、共同财产、共同债务、受益变更共同构成本章的识别变量；它们通过“婚姻九格”被放入同一事实与决策结构。
- **核验边界**：本章先排除“宣称保单是婚前现金保险库”；涉及财产、债务、税务、信托、跨境或执行效果时，由对应专业人士按当前事实和规则确认。

## Mental Models

- **先事实后功能**：婚姻财富管理先判断财产来源、取得时间、出资、权属、使用混同、债务和证据，再分析保费、现金价值、年金和保险金。
- **用结构防止漏项**：资产类型、来源、时间、登记、出资、约定赠与、使用混同、债务、证据九格完成后，由律师判断个人或共同权益。
- **用停点控制风险**：若出现“宣称保单是婚前现金保险库”或相关争议、执行与违法事项，停止产品推进并转介。

## Anti-patterns

- 宣称保单是婚前现金保险库。
- 未经被保险人同意变更。
- 忽略退保控制。
- 用保单损害配偶合法权益。

## Worked Example

父母为已婚子女出资保单，先记录赠与对象和控制安排，由律师核验性质，并披露父母去世或退保时的变化。

## Key Takeaways

1. 婚姻财富管理先判断财产来源、取得时间、出资、权属、使用混同、债务和证据，再分析保费、现金价值、年金和保险金。
2. 本章使用“婚姻九格”组织事实：资产类型、来源、时间、登记、出资、约定赠与、使用混同、债务、证据九格完成后，由律师判断个人或共同权益。
3. 首先排除“宣称保单是婚前现金保险库”，再判断保险是否适配。
