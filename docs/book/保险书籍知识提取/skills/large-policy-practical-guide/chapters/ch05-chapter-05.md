# Chapter 5: 第五章 大额保单与家族财富传承

## Core Idea

家族传承由为何传、传什么、传给谁、怎么传四问展开，并按财产类型选择赠与、遗嘱、保险、信托、基金会或治理工具。控制、税源和隐私都是条件性目标，不是保险的绝对优势。

## Frameworks Introduced

### 传承四问六工具

先回答目的、资产、对象和方式，再比较赠与、遗嘱、保单、信托、基金会与家族办公室的功能、成本和治理要求。

**何时使用**：遇到类似场景时先应用该框架，再进入产品：家族持有企业、房产和艺术品，分别设计股权治理、登记继承和保管估值，保单仅提供部分流动资金。

## Key Concepts

- **概念关系**：法定继承、代持、隔代传承、身后控制共同构成本章的识别变量；它们通过“传承四问六工具”被放入同一事实与决策结构。
- **核验边界**：本章先排除“单靠保险完成传承”；涉及财产、债务、税务、信托、跨境或执行效果时，由对应专业人士按当前事实和规则确认。

## Mental Models

- **先事实后功能**：家族传承由为何传、传什么、传给谁、怎么传四问展开，并按财产类型选择赠与、遗嘱、保险、信托、基金会或治理工具。
- **用结构防止漏项**：先回答目的、资产、对象和方式，再比较赠与、遗嘱、保单、信托、基金会与家族办公室的功能、成本和治理要求。
- **用停点控制风险**：若出现“单靠保险完成传承”或相关争议、执行与违法事项，停止产品推进并转介。

## Anti-patterns

- 单靠保险完成传承。
- 用代持隐藏权属。
- 追求死后绝对控制。
- 用书中遗产税假设制造紧迫。

## Worked Example

家族持有企业、房产和艺术品，分别设计股权治理、登记继承和保管估值，保单仅提供部分流动资金。

## Key Takeaways

1. 家族传承由为何传、传什么、传给谁、怎么传四问展开，并按财产类型选择赠与、遗嘱、保险、信托、基金会或治理工具。
2. 本章使用“传承四问六工具”组织事实：先回答目的、资产、对象和方式，再比较赠与、遗嘱、保单、信托、基金会与家族办公室的功能、成本和治理要求。
3. 首先排除“单靠保险完成传承”，再判断保险是否适配。
