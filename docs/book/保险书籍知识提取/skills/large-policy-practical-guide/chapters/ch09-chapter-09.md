# Chapter 9: 第九章 境外大额保单

## Core Idea

境外保单差异来自精算、币种、投资、合同法律、税务、监管、服务与信托生态，不等于天然优越。跨境居民还要处理销售资格、资金出境、申报、汇率、核保理赔和争议成本。

## Frameworks Introduced

### 境外保单九项比较

主体与销售合法性、合同法、监管、币种汇率、保证非保证利益、费用退保、税务申报、缴费理赔、争议服务统一比较。

**何时使用**：遇到类似场景时先应用该框架，再进入产品：客户比较香港与内地保单，顾问用九项表统一责任和币种压力情景，并要求税务与法律顾问确认跨境义务。

## Key Concepts

- **概念关系**：多币种、属地法律、跨境服务、汇率风险共同构成本章的识别变量；它们通过“境外保单九项比较”被放入同一事实与决策结构。
- **核验边界**：本章先排除“以历史悠久证明安全”；涉及财产、债务、税务、信托、跨境或执行效果时，由对应专业人士按当前事实和规则确认。

## Mental Models

- **先事实后功能**：境外保单差异来自精算、币种、投资、合同法律、税务、监管、服务与信托生态，不等于天然优越。
- **用结构防止漏项**：主体与销售合法性、合同法、监管、币种汇率、保证非保证利益、费用退保、税务申报、缴费理赔、争议服务统一比较。
- **用停点控制风险**：若出现“以历史悠久证明安全”或相关争议、执行与违法事项，停止产品推进并转介。

## Anti-patterns

- 以历史悠久证明安全。
- 宣称严进宽出。
- 忽略购汇申报。
- 用境外信托包装避税避债。
