# Chapter 6: 第六章 大额保单与税收筹划

## Core Idea

合法税收筹划贯穿交易与持有过程，但具体税负由身份、资产、所得/交易、时间和辖区共同决定。书中的中国及境外税制、FATCA、BEPS、CRS和保单税务资料必须按当前规则重查。

## Frameworks Introduced

### 税务五问

谁是纳税或申报主体、哪项资产交易、发生在何时、适用哪个辖区、保险给付或现金价值如何定性；由税务专业人士书面核验。

**何时使用**：遇到类似场景时先应用该框架，再进入产品：跨境家庭拟用境外寿险节税，顾问先建立身份与交易表，由两地税务顾问确认后才比较产品，不在建议书写“免税”。

## Key Concepts

- **概念关系**：合法筹划、FATCA、BEPS、CRS、税源共同构成本章的识别变量；它们通过“税务五问”被放入同一事实与决策结构。
- **核验边界**：本章先排除“承诺免遗产税或所得税”；涉及财产、债务、税务、信托、跨境或执行效果时，由对应专业人士按当前事实和规则确认。

## Mental Models

- **先事实后功能**：合法税收筹划贯穿交易与持有过程，但具体税负由身份、资产、所得/交易、时间和辖区共同决定。
- **用结构防止漏项**：谁是纳税或申报主体、哪项资产交易、发生在何时、适用哪个辖区、保险给付或现金价值如何定性；由税务专业人士书面核验。
- **用停点控制风险**：若出现“承诺免遗产税或所得税”或相关争议、执行与违法事项，停止产品推进并转介。

## Anti-patterns

- 承诺免遗产税或所得税。
- 把CRS等同征税。
- 使用历史税率。
- 企业保费随意税前列支。

## Worked Example

跨境家庭拟用境外寿险节税，顾问先建立身份与交易表，由两地税务顾问确认后才比较产品，不在建议书写“免税”。

## Key Takeaways

1. 合法税收筹划贯穿交易与持有过程，但具体税负由身份、资产、所得/交易、时间和辖区共同决定。
2. 本章使用“税务五问”组织事实：谁是纳税或申报主体、哪项资产交易、发生在何时、适用哪个辖区、保险给付或现金价值如何定性；由税务专业人士书面核验。
3. 首先排除“承诺免遗产税或所得税”，再判断保险是否适配。
