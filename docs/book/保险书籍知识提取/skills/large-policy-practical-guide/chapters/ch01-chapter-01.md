# Chapter 1: 第一章 高净值家庭的“烦恼”

## Core Idea

高净值家庭的难题不是资产越多必然越烦恼，而是资产类型、权利人、企业关系、信息披露和多辖区规则增加了协调成本。所谓婚姻、败家、税收和移民风险都要改写成具体事件、后果与证据。

## Frameworks Introduced

### 十类风险盘点

资产集中、无规划、隐私披露、控制权、婚姻、受益人能力、家企混同、意外、税务、移民十类逐项记录事实、时间和影响。

**何时使用**：遇到类似场景时先应用该框架，再进入产品：企业家说担心资产曝光，团队先区分依法申报、机构尽调和无授权泄露，再分别配置合规与隐私措施。

## Key Concepts

- **概念关系**：风险清单、控制权、信息披露、多辖区共同构成本章的识别变量；它们通过“十类风险盘点”被放入同一事实与决策结构。
- **核验边界**：本章先排除“用恐惧放大所有风险”；涉及财产、债务、税务、信托、跨境或执行效果时，由对应专业人士按当前事实和规则确认。

## Mental Models

- **先事实后功能**：高净值家庭的难题不是资产越多必然越烦恼，而是资产类型、权利人、企业关系、信息披露和多辖区规则增加了协调成本。
- **用结构防止漏项**：资产集中、无规划、隐私披露、控制权、婚姻、受益人能力、家企混同、意外、税务、移民十类逐项记录事实、时间和影响。
- **用停点控制风险**：若出现“用恐惧放大所有风险”或相关争议、执行与违法事项，停止产品推进并转介。

## Anti-patterns

- 用恐惧放大所有风险。
- 把子孙称为败家者。
- 把隐私保护等同隐匿资产。
- 未核验税务身份。

## Worked Example

企业家说担心资产曝光，团队先区分依法申报、机构尽调和无授权泄露，再分别配置合规与隐私措施。

## Key Takeaways

1. 高净值家庭的难题不是资产越多必然越烦恼，而是资产类型、权利人、企业关系、信息披露和多辖区规则增加了协调成本。
2. 本章使用“十类风险盘点”组织事实：资产集中、无规划、隐私披露、控制权、婚姻、受益人能力、家企混同、意外、税务、移民十类逐项记录事实、时间和影响。
3. 首先排除“用恐惧放大所有风险”，再判断保险是否适配。
