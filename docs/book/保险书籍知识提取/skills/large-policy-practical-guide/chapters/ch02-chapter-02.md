# Chapter 2: 第二章 大额保单概述

## Core Idea

大额保单仍受保险利益、最大诚信、近因和损失补偿等基本原则以及具体合同约束。其现金价值、杠杆、融资和传承等功能具有条件，订立、变更、解除及被保险人同意不能因金额大而简化。

## Frameworks Introduced

### 大额保单五层阅读

先看风险与可保性，再看产品分类、合同责任、关系人和现金价值，最后核验所谓财富管理功能的法律经济前提。

**何时使用**：遇到类似场景时先应用该框架，再进入产品：客户准备趸交终身寿险，顾问先核对资金来源、关系人同意、退保价值和合同权限，再讨论融资或传承用途。

## Key Concepts

- **概念关系**：保险利益、最大诚信、现金价值、被保险人同意共同构成本章的识别变量；它们通过“大额保单五层阅读”被放入同一事实与决策结构。
- **核验边界**：本章先排除“把功能清单当保证”；涉及财产、债务、税务、信托、跨境或执行效果时，由对应专业人士按当前事实和规则确认。

## Mental Models

- **先事实后功能**：大额保单仍受保险利益、最大诚信、近因和损失补偿等基本原则以及具体合同约束。
- **用结构防止漏项**：先看风险与可保性，再看产品分类、合同责任、关系人和现金价值，最后核验所谓财富管理功能的法律经济前提。
- **用停点控制风险**：若出现“把功能清单当保证”或相关争议、执行与违法事项，停止产品推进并转介。

## Anti-patterns

- 把功能清单当保证。
- 代签或代告知。
- 将现金价值等同已交保费。
- 引用旧司法解释作当前结论。

## Worked Example

客户准备趸交终身寿险，顾问先核对资金来源、关系人同意、退保价值和合同权限，再讨论融资或传承用途。

## Key Takeaways

1. 大额保单仍受保险利益、最大诚信、近因和损失补偿等基本原则以及具体合同约束。
2. 本章使用“大额保单五层阅读”组织事实：先看风险与可保性，再看产品分类、合同责任、关系人和现金价值，最后核验所谓财富管理功能的法律经济前提。
3. 首先排除“把功能清单当保证”，再判断保险是否适配。
