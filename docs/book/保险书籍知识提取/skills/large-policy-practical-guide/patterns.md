# 方法模式

## 1. 专业停点

**何时用**：发现既有债务执行、税务违法、婚姻争议、权属不清或跨境申报问题。**怎么做**：记录事实，不建议转移，转介并等待书面意见。**权衡**：停止推进优先于成交。

## 2. 权利结构图

**何时用**：任何大额保单。**怎么做**：画出缴费、投保控制、被保障、受益、现金价值、质押和变更。**权衡**：权利结构不等于隔离或税务结论。

## 3. 信托八项尽调

**何时用**：保险金信托或境外信托。**怎么做**：法域、角色、财产、撤销、分配、监督、能力费用、税务。**权衡**：控制、成本和冲突一起评估。

## 4. 境外九项比较

**何时用**：比较内地与境外保单。**怎么做**：销售合法性、法律监管、币种、利益、费用、税务、服务、争议。**权衡**：不能只看演示或历史。

## 5. 综合案例七步

**何时用**：多问题家庭。**怎么做**：关系资产图、验证、停点、量化、工具、分阶段、复核。**权衡**：先治理违法与高影响问题。
