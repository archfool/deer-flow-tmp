# 术语表

| 术语 | 含义 | 章节 |
|---|---|---|
| 婚姻十事实 | 婚姻家庭安排前需核实的身份、财产、债务与证据。 | ch01 |
| 全职照护 | 无独立工资但承担家庭照护劳动的角色，不等于无财产或决策权。 | ch01 |
| 定向传承 | 希望特定对象在特定条件获得利益的目标。 | ch02 |
| 遗产管理人 | 按法律或遗嘱管理遗产事务的主体。 | ch02 |
| 未成年受益 | 未成年人获得利益后的监护、管理和监督问题。 | ch02 |
| 出资责任 | 股东依法依章程履行出资的义务。 | ch03 |
| 资产代持 | 名义权利人与实际安排不一致的持有关系。 | ch03 |
| 限定继承 | 继承人按现行法律在所得遗产范围等条件下承担相关义务的制度。 | ch03 |
| 税务外汇八格 | 税务和跨境支付规划的八类事实。 | ch04 |
| CRS | 金融账户涉税信息尽调与交换框架。 | ch05 |
| 控制人 | 特定实体账户报告中需识别的实际控制相关主体，定义依规则。 | ch05 |
| 资产五桶 | 应急、保障、中期、养老和增长的目标分桶。 | ch06 |
| 再平衡 | 资产目标或市场变化后恢复配置比例与风险的调整。 | ch06 |
