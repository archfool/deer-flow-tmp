# 方法模式

## 1. 婚姻十事实
**何时用**：婚前、婚内、离婚、再婚或父母资助。**怎么做**：完整记录身份、财产、债务和证据。**权衡**：由律师定性，不承诺保单绝对保护。

## 2. 传承七问
**何时用**：受益人、遗嘱或未成年人安排。**怎么做**：资产、对象、时间、管理、监督、争议、工具衔接。**权衡**：指定受益不等于全部执行完成。

## 3. 企业七台账
**何时用**：企业家家庭。**怎么做**：申报、债务、出资、账户、代持、继承、执行分别核查。**权衡**：先整改治理，保险不修复既有责任。

## 4. CRS四层
**何时用**：多税收居民或境外账户。**怎么做**：身份、机构账户、持有人控制人、报告后果。**权衡**：交换不等于征税，保单不天然豁免。

## 5. 资产五桶
**何时用**：高客、中产、养老或单一收入。**怎么做**：按用途期限分桶并压力测试。**权衡**：不要求固定保险占比。
