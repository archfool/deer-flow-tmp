# Chapter 3: 第三章 企业家家庭与人寿保险规划

## Core Idea

公务申报、夫妻债务、公司出资、家企混同、代持、继承债务和执行是不同法律问题。保险不修复未实缴出资、违法税务、代持权属或既有债务；先整改治理和披露，再处理关键人、家庭责任与股权流动性。

## Frameworks Introduced

### 企业家庭七台账

申报义务、夫妻债务、出资责任、账户往来、代持文件、继承债务、诉讼执行七张台账分别确认责任人与状态。

**何时使用**：遇到本章法律家庭场景时，先完成台账并标记专业停点，再讨论保险。

## Key Concepts

- **概念关系**：财产申报、出资责任、家企混同、代持、限定继承通过“企业家庭七台账”进入同一事实链，不按单个名词推断法律结果。
- **专业边界**：保险顾问识别问题与合同作用；法律、税务、会计和跨境结论由相应专业人士确认。

## Mental Models

- **先权利后产品**：公务申报、夫妻债务、公司出资、家企混同、代持、继承债务和执行是不同法律问题。
- **先合规后配置**：违法、争议、申报或资金路径未解决时停止推进。
- **保险只处理适用段**：它提供约定保障或现金流，不替代身份、权属、治理和税务制度。

## Anti-patterns

- 用境外保单逃避申报。
- 保险替代出资。
- 保单包装避债。
- 误称父债必由子还或绝不需还。

## Worked Example

企业主存在长期个人账户收款，先由会计律师整改并核验税务，保单只处理其身故后的家庭和企业现金流。

## Key Takeaways

1. 公务申报、夫妻债务、公司出资、家企混同、代持、继承债务和执行是不同法律问题。
2. 使用“企业家庭七台账”完成事实核验：申报义务、夫妻债务、出资责任、账户往来、代持文件、继承债务、诉讼执行七张台账分别确认责任人与状态。
3. 先排除“用境外保单逃避申报”，再判断保险是否适配。
