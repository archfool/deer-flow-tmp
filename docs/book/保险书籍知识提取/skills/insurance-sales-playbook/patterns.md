# 方法模式

## 1. 访前一页纸

**何时用**：每次正式会谈前。

**怎么做**：记录来源授权、已知事实、假设未知、会谈目标、问题、参与者、证据和下一步选项。

**权衡**：计划用于验证，不可把假设伪装成客户事实。

## 2. 面谈四段

**何时用**：需求访谈和方案说明。

**怎么做**：建立边界、发现需求、说明方案、确认理解；每段得到客户许可再推进。

**权衡**：关系氛围有帮助，但不能省略限制说明。

## 3. 异议四步

**何时用**：客户拒绝或提出疑问。

**怎么做**：听完整原话，问事实和标准，用证据或备选回答，再验证是否解决。

**权衡**：明确拒绝后结束；再访需授权和新价值。

## 4. 促成四前提

**何时用**：客户出现行动意愿。

**怎么做**：逐项确认需求、适配、支付和理解，再沿行动阶梯申请。

**权衡**：任何前提不满足都回到前序，而非加强施压。

## 5. 抱怨五步

**何时用**：客户投诉销售、合同、服务或理赔。

**怎么做**：接收感谢、复述事实与期望、分类、说明责任时限、跟踪并改进。

**权衡**：先解决问题，避免未经调查承诺结果。

## 6. 高额保单升级

**何时用**：安排对客户资产、现金流或家庭权利有重大影响。

**怎么做**：复杂KYC、多角色、压力测试、权利结构、专业协作、多方案、持续治理。

**权衡**：规模越大越需保守核验，不把财富标签当支付能力。
