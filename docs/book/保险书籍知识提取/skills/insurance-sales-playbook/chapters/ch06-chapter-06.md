# Chapter 6: 第六章 售后服务

## Core Idea

售后服务的本质是履行承诺和维护合同可用性。保持联系、处理抱怨、提供差异化服务和管理关系都应围绕客户利益与授权；“双赢”不能把客户服务降为转介绍工具。

## Frameworks Introduced

### 服务生命周期

保单递送与复述 → 缴费和状态维护 → 家庭事件检视 → 保全协助 → 理赔协助 → 争议与投诉处理 → 续期或退出决策。

### 抱怨处理五步

接收并感谢反馈 → 复述事实与期望 → 区分销售、合同、服务或理赔问题 → 说明处理人和时限 → 跟踪结果并记录改进。先解决客户问题，不先辩护机构。

### 客户关系记录

联系方式与偏好、保单和关键日期、服务承诺、接触记录、投诉和处理、下一次检视。仅在授权范围内使用，不把敏感信息变成营销名单。

## Key Concepts

- **保单可用性**：合同有效、客户能找到资料并知道如何保全和申请理赔。
- **服务承诺**：明确范围、负责人和时间的可交付事项。
- **服务补救**：出现失误后及时纠正、解释和减少客户损失。
- **关系管理**：依靠记录与履约维持，而非频繁社交。

## Mental Models

- 抱怨是服务失效信号，不是客户不讲理。
- 独特服务应解决真实问题，不追求表面惊喜。
- 长期关系建立在守约、隐私和稳定交付上。

## Anti-patterns

- 只在续费、增购和转介绍时联系。
- 对抱怨先解释客户为何误解。
- 用私人跑腿替代合同和专业服务。
- 未经客户同意共享信息给团队或合作方。

## Worked Example

客户投诉缴费提醒太晚导致焦虑。顾问先核对时间线和客户期望，协助确认合同状态，更新提醒渠道与提前量，并记录服务失误。复盘后将所有客户提醒规则标准化，而不是用礼物安抚后不改流程。

## Key Takeaways

1. 售后围绕合同可用性和承诺履行。
2. 抱怨处理要明确事实、责任、时限和跟踪。
3. 差异化服务解决问题，不制造人情负担。
4. 客户关系记录受授权和隐私约束。
