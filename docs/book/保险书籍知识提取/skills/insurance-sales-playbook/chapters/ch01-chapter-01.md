# Chapter 1: 第一章 保险销售准备阶段

## Core Idea

销售准备不是背产品和打扮得体，而是建立一套能持续交付的职业基础：产品责任准确、职业伦理清楚、表达与礼仪适度、心态稳定、目标可分解，并知道完整销售流程的前后依赖。

## Frameworks Introduced

### 准备六维

`产品知识 → 伦理边界 → 语言表达 → 形象礼仪 → 心理韧性 → 活动目标`

产品知识以能定位责任、除外、期限和给付为标准；形象礼仪以尊重和场景合宜为标准；心理韧性用于承受拒绝和持续服务，不用于纠缠客户。

### 结果目标到过程目标

将年度保费或收入目标反推为有效接触、需求访谈、建议书、申请、承保和服务数量，并用个人真实转化率校准。结果目标不能成为误导或降低告知质量的理由。

### 销售禁忌检查

不夸大收益、不隐瞒限制、不贬低竞品、不泄露隐私、不虚假紧迫、不代客户告知签名、不承诺无法控制的理赔结果。

## Key Concepts

- **职业道德**：把客户利益、真实说明和守约置于短期成交之前。
- **语言艺术**：准确、易懂并能根据客户反馈调整，而非操纵情绪。
- **活动目标**：销售人员可控制和记录的过程行为。
- **心理韧性**：把拒绝转为流程反馈，保持边界和恢复能力。

## Mental Models

- 准备质量决定现场能否诚实应变。
- 仪表降低沟通摩擦，内容建立专业信任。
- 目标是管理行为的工具，不是压迫客户的借口。

## Anti-patterns

- 只背产品卖点，不会说明除外和不适用场景。
- 用过度热情、礼物或私人关系换取客户顺从。
- 把“永不放弃”理解为无视明确拒绝。
- 只设签单数，不监测需求质量、投诉和持续率。

## Worked Example

新人首月接触量很高但建议书转化低。复盘不是要求其继续加量，而是发现产品说明过长、无法回答除外问题。训练目标改为每日条款定位、每周两次角色演练和访谈复盘，活动目标同步记录客户理解与未决问题。

## Key Takeaways

1. 准备涵盖产品、伦理、表达、礼仪、心态和目标。
2. 专业标准是准确应用，而非记住更多卖点。
3. 结果目标必须分解成可控过程并受合规边界约束。
4. 销售禁忌应成为每次会谈前的硬检查。
