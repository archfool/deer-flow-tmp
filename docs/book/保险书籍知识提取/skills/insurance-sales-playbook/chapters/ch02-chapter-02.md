# Chapter 2: 第二章 拜见客户前做好准备

## Core Idea

访前准备的产物不是一叠宣传资料，而是一份可验证的会谈计划：为什么联系这个客户、已知和未知是什么、谁参与决定、这次会谈要完成什么，以及可能用哪些资料支持理解。

## Frameworks Introduced

### 客户锁定五条件

初步风险或目标、接触许可、基本支付可能、决策角色、可服务性。任何条件未知都标记为待核实，不因名单来源或财富标签直接判定“优质”。

### 访前一页纸

`联系来源与授权 | 已知事实 | 假设与未知 | 会谈目标 | 关键问题 | 参与者 | 证据材料 | 下一步选项`

资料只收集实现服务所需范围，并记录来源和更新时间。

### 计划书推导链

客户事实 → 风险后果 → 既有资源 → 缺口 → 推荐与备选 → 责任/除外/费用/期限 → 未覆盖风险。访前信息不足时，先做需求访谈提纲，不提前锁定产品。

## Key Concepts

- **客户资格**：是否值得进一步核实，不等于一定可承保或应购买。
- **资料最小化**：只收集当前服务目的必要的信息。
- **拜访目标**：本次会谈可以完成的具体结果。
- **计划书**：展示风险到方案推导的决策文件，不是产品海报。

## Mental Models

- 计划写假设，面谈找事实。
- 准备材料服务于问题，不用材料数量展示专业。
- 电话预约确认会谈价值和边界，不预演完整销售。

## Anti-patterns

- 购买、交换或使用未经授权的客户数据。
- 根据职业收入猜测家庭、健康和购买能力。
- 先做产品计划书，再用会谈补齐理由。
- 把一次会谈目标设为“必须签单”。

## Worked Example

转介绍客户被描述为“企业高管、收入不错”。访前一页纸只把这两项标为第三方信息，未知项包括家庭责任、单位福利、负债和会谈参与者。首次目标设为确认需求与资料授权，不提前制作高保费方案。

## Key Takeaways

1. 锁定客户不等于给客户下结论。
2. 访前计划区分事实、假设、未知和会谈目标。
3. 资料收集遵循必要、授权与可追溯。
4. 信息不足时准备问题，不准备既定产品答案。
