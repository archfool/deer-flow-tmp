# Chapter 5: 第五章 促成客户签单

## Core Idea

促成不是用技巧跨过客户最后防线，而是在需求、适配、支付和理解都成熟时，提出明确行动并完成合同质量检查。成交时机由客户决策状态决定，不由销售人员业绩周期决定。

## Frameworks Introduced

### 促成四前提

需求已确认、方案与缺口匹配、预算可持续、关键利益与限制已理解。任何一项缺失都回到前序步骤。

### 行动阶梯

确认目标 → 选择备选 → 确定保额与预算 → 安排共同决策者 → 完成健康/职业信息 → 正式申请。客户可在任一级暂停。

### 合同九项核对

主体身份、保险利益与角色、如实告知、责任与除外、保额期限、保费缴费、等待/宽限/犹豫等期间、现金价值及保证/非保证利益、签名与资料真实性。

## Key Concepts

- **成交时机**：客户主动询问实施细节且四前提满足的状态。
- **试探性确认**：询问客户偏好和未决项，不是预设同意。
- **保险合同**：决定权利义务的正式文件，建议书和口头说明不替代合同。
- **申请与承保**：提交申请不等于保险人已经承保或责任已开始。

## Mental Models

- 好促成减少模糊，不增加压力。
- 签单速度不能优先于告知和合同质量。
- 客户选择“不申请”也是决策结果。

## Anti-patterns

- 用限时、礼品、关系或损失恐惧制造虚假紧迫。
- 代客户填写健康信息、签名或选择答案。
- 将演示利益描述为保证收益。
- 申请提交后就告诉客户已经获得保障。

## Worked Example

客户认可方案并询问何时生效。顾问先说明申请、核保、承保和责任起期的区别，完成告知与合同九项核对，再提交申请。若核保条件变化，重新让客户理解并决定，而不是把签名视为不可撤回的成交。

## Key Takeaways

1. 促成前必须满足需求、适配、支付和理解四前提。
2. 行动按阶梯推进，客户可随时暂停。
3. 合同核对比成交技巧更重要。
4. 申请、承保和责任开始是不同节点。
