# Chapter 7: 第七章 开拓更多客户资源

## Core Idea

客户资源增长来自清晰定位、持续服务和合规触达，而不是无限扩大名单。高额保单客户需要更复杂的事实调查、决策协同和专业边界，不能简单理解为“有钱、保费大”。

## Frameworks Introduced

### 客源组合

现有客户服务延伸、自愿转介绍、专业合作、公开活动、内容与自然咨询。分别记录来源、授权、转化和服务成本，避免单一渠道依赖。

### 转介绍三步

先完成可感知服务；说明希望帮助的具体人群和问题；由客户自主决定是否介绍并确认可披露信息。不给名单压力，不以礼品交换隐私。

### 高额保单升级框架

`复杂KYC → 多目标与多角色 → 流动性压力测试 → 权利结构 → 法律税务协作 → 多方案与不利因素 → 持续治理`

大额意味着错误代价更高，因此核验与服务更深，而不是促成更强。

## Key Concepts

- **客户来源质量**：不仅看数量，还看授权、适配、信任和服务成本。
- **专业合作**：与律师、税务、会计等在各自资质范围内协作。
- **大额保单**：相对于客户资产、现金流和目标具有重大影响的保单安排。
- **持续治理**：家庭、企业、法律和合同变化后的定期复核。

## Mental Models

- 最好的获客能力是已有服务可被验证和转述。
- 高净值不等于高流动性，也不等于高风险承受。
- 客源增长受服务容量约束。

## Anti-patterns

- 购买名单、群发骚扰或在社群未经许可添加客户。
- 以佣金或礼品换取转介绍。
- 用资产标签预判大额购买意愿。
- 为服务高额客户越界给出法律税务定论。

## Worked Example

老客户认可年度保单检视。顾问说明自己擅长帮助企业主梳理家企风险，请客户仅在对方愿意时转发一份公开检视清单，而不是索要电话。新客户主动联系后，仍从授权和KYC开始，不把介绍关系当作同意购买。

## Key Takeaways

1. 客源组合要同时管理授权、适配和服务成本。
2. 转介绍以已交付价值和客户自愿为前提。
3. 大额保单需要更深核验、协作和持续治理。
4. 获客规模不能超过服务能力。
