# 术语表

| 术语 | 含义 | 章节 |
|---|---|---|
| 六维准备 | 产品、伦理、表达、形象礼仪、心理和活动目标的职业基础。 | ch01 |
| 活动目标 | 有效接触、访谈、建议书、服务等可控制过程指标。 | ch01 |
| 客户资格 | 是否存在值得进一步核实的需求、许可、能力、角色与可服务性。 | ch02 |
| 访前一页纸 | 集中记录来源、事实、未知、目标、问题、参与者和下一步的工具。 | ch02 |
| 计划书 | 从客户事实和风险推导责任、成本、限制及备选的决策文件。 | ch02 |
| 理解确认 | 客户用自己的话说明关键利益、限制和未决问题。 | ch03 |
| 异议四步 | 听、问、答、验。 | ch04 |
| 再访许可 | 客户同意后续联系的时间、渠道和主题。 | ch04 |
| 促成四前提 | 需求、适配、支付和理解均成熟。 | ch05 |
| 申请 | 向保险人提出承保请求，不等于已经承保。 | ch05 |
| 服务补救 | 服务失误后纠正、解释并减少客户损失。 | ch06 |
| 客户关系记录 | 保单、日期、承诺、接触、投诉和检视的授权记录。 | ch06 |
| 客源组合 | 服务延伸、转介绍、合作、活动、内容和自然咨询等来源组合。 | ch07 |
| 持续治理 | 大额安排在家庭、企业和规则变化后的复核。 | ch07 |
