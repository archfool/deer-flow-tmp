# 保险销售作业速查

## 会谈前

- 联系来源和后续触达是否获授权？
- 哪些是事实、假设和未知？
- 这次会谈的最小成功结果是什么？
- 谁应参与决定？
- 需要哪些合同或官方证据？

## 会谈中

- 是否先确认目的、时间和隐私？
- 问题是否覆盖现状、变化、后果和已有应对？
- 推荐能否逐项追溯到客户事实？
- 是否说明责任、除外、成本、期限和不利因素？
- 客户能否复述关键理解？

## 促成前

`需求确认 + 方案适配 + 支付持续 + 充分理解`

再核对身份、告知、关系人、保额期限、缴费、重要期间、现金价值、保证/非保证利益和签名真实性。

## 售后

- 完成保单递送与理解确认。
- 记录缴费、事件检视和服务承诺。
- 抱怨明确处理人和时限。
- 理赔坚持真实事实与合同资料。
- 转介绍由客户自愿并授权披露。

## 硬性禁忌

- 夸大、隐瞒、虚假稀缺
- 代填重要告知、代签名
- 未授权收集或交换客户信息
- 把明确拒绝解释为需要继续纠缠
- 把售后服务交换成转介绍名单
- 越界给出法律、税务或理赔保证
