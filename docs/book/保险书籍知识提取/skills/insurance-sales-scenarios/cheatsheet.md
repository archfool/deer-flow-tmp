# 情景训练速查

## 听到客户一句话后

1. 先复述：“您主要担心的是……对吗？”
2. 再定位：产品、需求、信用、支付还是决策？
3. 问标准：“什么信息会帮助您判断？”
4. 给证据或备选，不给绝对承诺。
5. 请客户确认问题是否解决。
6. 约定合理下一步，或尊重拒绝。

## 常见话语分诊

| 客户说法 | 可能问题 | 先查 |
|---|---|---|
| “发资料吧” | 渠道偏好或低兴趣 | ch01 |
| “不感兴趣” | 时间、信任、无需求或拒绝 | ch02 |
| “卖得最好的是哪个” | 缺少需求标准 | ch03 |
| “存银行/买股票更好” | 功能比较错位 | ch04 |
| “我有社保/存款/旧保单” | 替代资源是否充分 | ch05 |
| “公司/业务员不可信” | 四层信用证据 | ch06 |
| “贵、怕以后交不起” | 现金流与持续性 | ch07 |
| “考虑、比较、问家人” | 合理决策步骤 | ch08 |
| “想退保/要理赔” | 合同服务事件 | ch09 |

## 绝不使用

- 假身份、隐瞒销售目的或未经授权联系
- 恐惧、忌讳、从众或人情压力
- 虚假停售、名额、最后通牒
- 私下返佣或变相折扣
- 代填告知、代签名、修改理赔事实
- 阻止客户比较、咨询家人或选择其他渠道

## 复盘四问

- 我识别的异议类型有证据吗？
- 客户的真实标准是什么？
- 我提供的信息能由合同或官方来源验证吗？
- 下一步是客户自主同意的吗？
