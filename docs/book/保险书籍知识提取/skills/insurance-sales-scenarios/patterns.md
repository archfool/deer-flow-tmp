# 方法模式

## 1. 异议澄清闭环

**何时用**：客户表达拒绝、怀疑、比较或暂缓。

**怎么做**：倾听、复述、追问标准和经历、承认合理部分、给同口径证据或备选、确认、约定下一步。

**权衡**：客户仍拒绝不是流程失败；明确拒绝后停止推进。

## 2. 需求资源净额法

**何时用**：客户称已有存款、福利或保单。

**怎么做**：按医疗、收入、责任等分别计算后果，扣除可靠资源，并测试资源何时可用及机会成本。

**权衡**：已有资源充分时，不应制造新缺口。

## 3. 信任四层证据

**何时用**：客户不信公司、人员或渠道。

**怎么做**：分别核验制度机构、合同产品、服务系统和个人能力，只引用官方、合同及可追溯记录。

**权衡**：证据有边界，不做无条件履约或理赔承诺。

## 4. 可负担性压力测试

**何时用**：客户担心贵、资金紧或未来续缴。

**怎么做**：扣除必要生活、债务、应急和近期支出，再模拟收入下降；优先保留核心保障。

**权衡**：无法持续时应降阶、分期规划或不签单。

## 5. 退保决策表

**何时用**：客户准备退保或替换。

**怎么做**：核对原因、现金价值、保障缺口、替代核保与等待期、调整选项和资金需求。

**权衡**：退保可能仍是正确选择，顾问不得因自身利益隐瞒。
