## Core Frameworks & Mental Models

### 1. 客户旅程

`电话约访 → 拜访许可 → 需求调查 → 产品说明 → 异议澄清 → 知情决定 → 保单递送 → 持续服务`

每个阶段只争取合理下一步，并允许客户拒绝、比较、邀请家人或暂缓。

### 2. 异议五类分诊

- 产品异议：功能比较、核保、通胀、理赔和价值观。
- 需求异议：存款、社保、单位福利、健康、年龄、家庭支持或已有保单。
- 信用异议：机构、合同、服务系统、人员或渠道。
- 支付异议：现金流、债务、价格、长期缴费和折扣。
- 决策异议：考虑、比较、共同决策和时间安排。

同一句“再考虑”可能属于不同类型，必须追问而非套话术。

### 3. 异议澄清闭环

`倾听 → 复述 → 追问标准和经历 → 承认合理部分 → 提供同口径证据或备选 → 请客户确认 → 约定下一步`

异议处理的目的，是让判断标准变清楚；客户仍拒绝也可能是有效结果。

### 4. 需求与支付双校验

`风险后果 - 存款/社保/福利/家庭支持/旧保单 = 缺口`

再用生活支出、债务、应急和收入下降情景测试可持续预算。核心保额优先于复杂责任，无法持续时不签单。

### 5. 知情促成

购买信号只代表适合提问。签单前核对身份意愿、告知、关系人、责任除外、保额期限、缴费、重要期间、非保证利益和签名真实性，不使用虚假稀缺、返佣或绕过共同决策者。

### 6. 售后闭环

保单递送、服务日历、保全、退保分析、理赔协助和自愿转介绍共同构成售后。服务以履约为目的，不以二次推销或索取名单为目的。
