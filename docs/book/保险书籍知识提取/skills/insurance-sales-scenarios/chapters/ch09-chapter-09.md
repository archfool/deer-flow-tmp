# Chapter 9: 第九章 售后服务实训

## Core Idea

售后服务是让合同被正确理解、持续有效并在需要时可使用。保单递送、定期联络、保全、退保分析、理赔协助和转介绍都应围绕客户利益，不把售后变成二次推销或人情索取。

## Frameworks Introduced

### 保单递送七项

核对人员与身份、保障责任、除外和等待期、保额与期限、缴费与账户、重要期间和权利、服务渠道与下次检视。请客户复述关键理解并记录未决问题。

### 服务日历

缴费日前提醒、合同重要日期、年度或事件触发检视、产品/规则变化说明、客户主动请求。联络频率和渠道遵循客户偏好，不以节日群发代替有效服务。

### 退保决策表

退保原因、当前现金价值/损失、保障缺口、替代方案核保与等待期、继续持有或调整选择、客户短期资金需求。先解决事实，再决定退保、减保、保单贷款或其他保全是否适用。

### 理赔协助流程

及时报案 → 核对全部相关保单 → 建立事故时间线 → 按合同准备资料 → 跟踪审核 → 解释结论与争议渠道。不得代客户编造或美化事实。

## Key Concepts

- **保单递送**：成交后的再次说明与合同核对，不只是交付纸质文件。
- **事件触发检视**：婚育、工作、收入、债务、健康和关系变化后复核。
- **退保损失**：现金价值、保障中断和未来可保性等综合后果。
- **转介绍许可**：客户自愿介绍并授权联系，不能以服务换名单。

## Mental Models

- 售后首先是履行承诺，其次才可能产生新业务。
- 理赔协助负责流程和证据，不负责承诺结果。
- 客户想退保先理解原因，不用道德压力挽留。

## Anti-patterns

- 递送保单时只索要转介绍名单。
- 日常联络只推新品，不记录客户服务事项。
- 为阻止退保隐瞒现金价值或替代方案风险。
- 理赔时教客户修改病史、事故经过或票据。

## Worked Example

客户因急需资金准备退保。顾问先取得当前现金价值和合同状态，确认资金缺口持续时间，再比较退保、减保、保单贷款及其他资金来源的条件和成本；若退保仍最符合客户利益，就完整说明保障中断并协助办理，而不是以佣金损失阻挠。

## Key Takeaways

1. 保单递送完成再次理解与服务交接。
2. 服务按日历和家庭事件持续，而非只在推销时联络。
3. 退保前比较经济损失、保障缺口和替代可保性。
4. 理赔坚持真实证据，转介绍坚持自愿授权。
