# Chapter 7: 第七章 支付异议处理实训

## Core Idea

资金紧张、房贷车贷、保费贵或担心未来续缴，首先是可负担性问题，不是价值异议。销售人员应保护客户基本现金流，区分核心责任与可选功能，提供降额、缩短或调整结构的方案；无法持续时不应签单。

## Frameworks Introduced

### 可负担性压力测试

`稳定可支配收入 - 必要生活 - 债务 - 应急储备补充 - 近期刚性支出 = 可考虑的持续预算`

再用收入下降、失业、疾病和利率变化情景测试缴费。一次能交不等于长期能承担。

### 保障降阶顺序

先保留高影响核心责任与足够保额，再调整可选附加责任、免赔、期限和产品形态；必要时分阶段配置。客户只要基本保额可能是合理选择，而非“买得不够全面”。

### 价格异议拆解

比较总保费、责任、保额、期限、免赔、续保与服务，判断是绝对无预算、相对价值不足，还是与不等价产品比较。

## Key Concepts

- **支付能力**：不损害必要生活、债务和应急安全的持续缴费能力。
- **核心责任**：对客户最无法自留的风险提供的主要保障。
- **中断成本**：退保损失、保障终止、重新核保或等待期等后果。
- **返佣折扣**：可能违反公司制度、销售规范或法律监管要求，必须按现行规定处理。

## Mental Models

- 预算是方案约束，不是需要突破的阻力。
- 基本保障胜过无法持续的“全保”。
- 支付测试要看坏年份，而不只看当前收入。

## Anti-patterns

- 建议客户动用应急金、借款或信用卡支付保费。
- 用“少喝咖啡就买得起”轻视真实负担。
- 隐瞒中断缴费、退保或续保困难的后果。
- 私下返佣、折扣或以礼品变相影响购买。

## Worked Example

客户有房贷且担心未来收入下降。压力测试显示当前可支付，但失业六个月会迫使其退保。顾问保留定期责任保障，降低非核心储蓄承诺，并说明未来加保受核保影响；客户也可先不购买。方案以可持续为标准，而非追求首年保费。

## Key Takeaways

1. 支付异议先做现金流与压力测试。
2. 调整顺序优先保留核心责任和必要保额。
3. 必须披露中断缴费与重新投保后果。
4. 返佣和折扣按现行规则处理，不私下承诺。
