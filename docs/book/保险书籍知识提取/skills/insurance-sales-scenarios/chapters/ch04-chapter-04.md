# Chapter 4: 第四章 产品异议处理实训

## Core Idea

“存银行更踏实、股票收益更高、理赔难、没出险就白买”等说法，通常混合了比较口径、信任、流程和价值观问题。处理异议的目标不是赢辩论，而是找出客户判断标准，用同口径事实说明保险功能，并允许客户维持不同选择。

## Frameworks Introduced

### 产品异议四分法

- **功能错位**：把储蓄、投资和风险转移当成同一目标比较。
- **信任证据**：担心欺骗、理赔或机构履约。
- **成本与价值**：担心通胀、保额不足或未出险“浪费”。
- **流程与文化**：体检麻烦、忌讳谈风险或身故保障无意义。

### 澄清闭环

`倾听 → 复述异议 → 追问标准/经历 → 承认合理部分 → 提供同口径信息 → 检查是否解决`

对银行和股票比较时，先确认客户讨论的是流动性、收益还是风险保障；不同功能不直接排名。

### 理赔证据框架

合同责任、事故事实、资料要求、审核流程和争议渠道。用具体合同和可核实数据回答，不承诺“一定赔”，也不以个别理赔故事代表全部。

## Key Concepts

- **功能错位**：用一个工具不承担的目标评价它。
- **风险保费**：用于转移约定风险的成本，未出险不等于服务无价值。
- **核保**：保险人评估风险并决定承保条件，既是流程成本也是合同公平基础。
- **实际购买力**：长期固定金额可能受通胀影响，应通过保额、期限和动态检视处理。

## Mental Models

- 先比较任务，再比较工具。
- 客户的负面经历是真实信息，不应立即否定。
- 异议解决的标志是标准变清楚，不是客户无话可说。

## Anti-patterns

- 贬低银行、股票或客户信仰来抬高保险。
- 用“你不懂”或灾难故事压制疑问。
- 对理赔做无条件保证，隐瞒除外和资料要求。
- 声称通胀、公司风险或核保麻烦都“不用担心”。

## Worked Example

客户说股票收益比保险高。销售人员确认客户想比较的是养老资金增长，而非疾病保障；随后把投资账户与保障账户分开，说明股票承担市场风险、保险按合同处理约定风险。客户可以继续投资，同时评估是否单独覆盖不能承受的医疗或收入损失，无需证明保险收益更高。

## Key Takeaways

1. 产品异议先按功能、信任、价值和流程分类。
2. 银行、股票与保险只有在相同目标和口径下才可比较。
3. 理赔问题用合同、事实、流程和渠道回答。
4. 异议处理不是辩赢客户，而是帮助其形成清楚标准。
