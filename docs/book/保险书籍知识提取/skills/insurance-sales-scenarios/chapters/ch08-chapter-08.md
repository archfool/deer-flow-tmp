# Chapter 8: 第八章 保单促成实训

## Core Idea

促成是邀请客户把已经理解的决定转化为明确行动，不是排除一切“借口”。考虑、比较、与家人商量和向朋友咨询都可能是合理决策步骤；销售人员的任务是澄清未决事项、安排参与者和核对申请细节。

## Frameworks Introduced

### 购买信号验证

客户询问缴费、流程、起保、受益或方案差异时，可问“这个问题是否是您决定前最需要确认的？”信号只是提问时机，不是默认同意。

### 四类暂缓诊断

- **信息不足**：明确缺什么资料或比较口径。
- **需要比较**：提供同口径责任表，允许咨询其他机构。
- **共同决策**：邀请家人或顾问参与，不要求客户代为转述。
- **当前不行动**：确认是否有真实时间条件，若无则约定客户自主联系或停止跟进。

### 签单九项核对

身份与意愿、健康和职业告知、投保/被保/受益角色、责任除外、保额期限、保费与缴费、等待及犹豫等期间、非保证利益、资料与签名真实性。

## Key Concepts

- **知情决定**：客户理解重要利益和限制后自主选择。
- **共同决策者**：会实质影响家庭或组织购买的人。
- **同口径比较**：以相同保额、期限、责任和假设比较方案。
- **真实签名与告知**：客户本人完成应由其确认的申请事项。

## Mental Models

- 犹豫不是敌人，而是未决信息的信号。
- 熟人关系不是适配标准，专业比较也不应贬低熟人。
- 最后的细节错误可能破坏前面全部需求分析。

## Anti-patterns

- 把“考虑一下”一律判定为假异议。
- 阻止客户比较、咨询家人或专业人士。
- 借停售、名额或健康恐惧制造虚假紧迫。
- 代填重要告知、代签名或淡化非保证利益。

## Worked Example

客户认可方案但要与配偶商量。销售人员询问配偶可能关心预算、责任还是控制权，安排一次共同说明，并把方案和限制提前发送。若配偶提出不同目标，就回到需求分析，不让客户用一句话替销售人员“说服家人”。

## Key Takeaways

1. 购买信号需要验证，不等于同意。
2. 考虑、比较和共同决策都可能是合理步骤。
3. 促成的前提是理解、自主和可负担。
4. 签单阶段要严格核对告知、角色、责任和真实性。
