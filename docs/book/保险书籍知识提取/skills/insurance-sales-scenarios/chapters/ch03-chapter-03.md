# Chapter 3: 第三章 保险推介实训

## Core Idea

客户不知道买什么或询问“卖得最好”时，销售人员不应替客户跳过需求判断。推介要把客户目标、风险后果与合同责任建立一一对应，并通过提问确认客户是否理解和认同。

## Frameworks Introduced

### 推荐前四问

1. 想解决什么事件或目标？
2. 事件发生会产生多少费用、收入或责任缺口？
3. 社保、单位福利、储蓄和旧保单已覆盖什么？
4. 预算、期限、健康和决策角色有哪些限制？

### 产品说明五步

`为什么适配 → 保什么 → 不保什么 → 多少钱和多久 → 发生后怎么申请`

儿童方案增加父母责任与缴费持续性；企业员工方案增加企业福利目标、员工结构、成本和管理流程。

### 注意力诊断

客户心不在焉或不置可否时暂停说明，询问是主题不相关、信息过多、时间不便还是未解决核心问题。不要用更长介绍挽救低注意力。

## Key Concepts

- **畅销产品**：销量只反映群体选择，不证明适合当前客户。
- **需求适配**：责任、额度、期限和成本与客户风险的匹配程度。
- **信息负荷**：客户一次能有效理解的内容有限，应按决策优先级分层。
- **反馈确认**：让客户用自己的话说明理解和未决问题。

## Mental Models

- 产品不是需求的起点，而是风险处理的候选工具。
- 客户沉默不是认可；理解需要主动验证。
- 少儿和团体保险都要保护真正承担后果的人与组织目标。

## Anti-patterns

- 用销量、奖项或他人购买代替适配分析。
- 从功能清单开始连续讲解，未说明与客户有什么关系。
- 客户失去注意力时提高音量或增加恐惧案例。
- 只讲儿童产品，不检查父母保障；只讲员工福利，不问企业目标。

## Worked Example

客户说“推荐你们卖得最好的”。销售人员先确认他担心父亲住院拖累家庭现金流，随后检查社保、储蓄和父亲可投保条件。若高龄健康限制使某类产品不适合，就坦白边界，并比较可获得保障、家庭储备和服务安排，而不是硬推畅销产品。

## Key Takeaways

1. 推荐前先完成目标、缺口、资源和限制四问。
2. 产品说明同时覆盖适配理由、责任、除外、成本和申请。
3. 沉默与分心都需要诊断，不是成交信号。
4. 特定人群方案要回到实际责任承担者和组织目标。
