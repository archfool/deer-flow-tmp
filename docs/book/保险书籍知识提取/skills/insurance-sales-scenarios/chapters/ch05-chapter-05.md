# Chapter 5: 第五章 需求异议处理实训

## Core Idea

客户说有存款、社保、单位福利、健康、年轻、子女或已有保单时，可能是在表达真实替代资源，也可能尚未测算缺口。正确动作是把现有资源纳入分析，而不是先证明客户错了；若资源已足够，结论可以是不新增保险。

## Frameworks Introduced

### 需求缺口等式

`风险财务后果 - 存款/资产 - 社保与单位福利 - 家庭支持 - 既有保单 = 待处理缺口`

分别测算医疗费用、收入中断、身故责任、照护和养老，不把所有风险合为一个金额。

### 资源可靠性四问

资源有多少、何时可用、使用后会不会破坏其他目标、在风险同时发生时是否仍存在。存款可能被其他目标占用，单位福利可能随工作变化，子女支持也有不确定性。

### 已有保单检视

核对有效状态、责任、保额、期限、除外、续保、关系人和与当前需求的差额。其他公司产品同样纳入，不以品牌为理由要求替换。

## Key Concepts

- **自留能力**：家庭用资产自行承担损失的能力和意愿。
- **基础保障**：社保和单位福利提供的重要资源，但范围和持续条件需核实。
- **可保性变化**：年龄和健康可能影响未来选择，但不能据此制造恐慌。
- **责任优先**：为孩子配置时同时检查承担收入和照护责任的成年人。

## Mental Models

- “不需要”是待验证结论，也可能是正确结论。
- 健康说明当前状态，不消除未来不确定性；风险概率小也可能后果巨大。
- 保险不改变生死，它改变部分经济后果的承担方式。

## Anti-patterns

- 否定社保、单位福利、存款或子女支持的真实价值。
- 用“现在不买以后一定买不到”制造恐惧。
- 把父母没出险或身边人没购买当成需要反驳的愚昧。
- 为抢客户要求退掉其他公司保单，未比较等待期、核保和损失。

## Worked Example

客户说单位福利很好。销售人员取得授权后核对福利手册，发现住院费用保障较好，但离职即终止，长期收入中断和身故责任有限。客户有充足资产，决定自留一部分、仅补核心责任缺口。若福利与资产已覆盖目标，则记录无需新增，而不是继续制造需求。

## Key Takeaways

1. 所有替代资源都应进入缺口计算。
2. 资源要评估金额、可用时间、机会成本和压力情景。
3. 已有保单先检视再决定保留、补充或替换。
4. 客户可能确实不需要新增保险，专业销售应接受这一结果。
