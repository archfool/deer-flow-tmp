# Chapter 6: 第六章 信用异议处理实训

## Core Idea

客户不信任保险公司、销售人员或渠道时，问题不能靠口头保证解决。应区分机构履约、产品合同、服务连续和人员行为四种信用对象，提供可验证来源、明确服务移交机制，并接受客户选择其他合规渠道。

## Frameworks Introduced

### 信任四层

1. **制度与机构**：主体资格、公开监管信息、偿付与风险处置机制。
2. **合同与产品**：责任、除外、期限、费率和给付以正式合同为准。
3. **服务系统**：保全、理赔、投诉和人员变动后的承接机制。
4. **顾问个人**：资质、陈述记录、专业边界和持续服务能力。

### 证据阶梯

客户经历或担忧 → 明确具体命题 → 查官方或合同来源 → 说明能证明什么和不能证明什么 → 记录未决问题。公司名气只能影响初始认知，不能替代四层证据。

## Key Concepts

- **机构信用**：机构履行合同与持续经营的能力，需结合当前公开信息。
- **服务连续性**：销售人员离职后，合同及公司服务渠道如何承接。
- **渠道选择**：代理、经纪、银行、线上等渠道各有服务与责任边界。
- **投诉与争议渠道**：客户对陈述或处理结果有异议时可使用的正式路径。

## Mental Models

- 信任是被证据和履约逐步建立的，不是要求客户先相信。
- 销售人员与保险公司、公司与具体合同应分别评价。
- 客户选择别的合规渠道不代表异议处理失败。

## Anti-patterns

- 以“大公司不会有问题”或“监管会兜底”作无条件保证。
- 为维护公司否定客户真实投诉或理赔经历。
- 声称自己永不离职，以个人关系替代公司服务。
- 贬低其他渠道，隐瞒自身佣金或利益冲突。

## Worked Example

客户担心销售人员离职后无人服务。顾问展示官方客服、线上保全、机构地址和团队承接流程，说明哪些服务由公司法定或合同承担，哪些是个人增值服务，并在服务记录中留下联系人。客户仍可比较其他渠道，不要求其仅凭私人承诺作决定。

## Key Takeaways

1. 信用异议分为制度机构、合同产品、服务系统和个人四层。
2. 回答依赖官方与合同证据，并说明证据边界。
3. 人员变动应由可验证的服务连续机制处理。
4. 尊重客户选择其他合规渠道。
