# Chapter 1: 第一章 电话约访实训

## Core Idea

电话约访的成功标准是获得一个双方同意、目的清楚的下一步，而不是在电话中完成销售。开场要说明身份、联系来源、对客户可能的价值和所需时间；客户拒绝或偏好其他渠道时，应尊重选择。

## Frameworks Introduced

### 约访五句式

`确认方便 → 说明身份与来源 → 说明与客户相关的主题 → 提出具体时长和时间选项 → 确认下一步`

老客户转介绍时，只说明获授权披露的关系；陌生、一面之缘和熟人客户都不能省略许可。

### 四类回应分流

- **没时间**：确认是当前不便还是不希望沟通，允许另约或结束。
- **电话里说**：用一两句说明主题，若确需资料或隐私再解释面谈价值。
- **先发资料**：询问关注点，发送最相关材料并约定是否跟进。
- **不愿提供信息**：说明收集目的、范围和保护方式；没有授权就不收集。

## Key Concepts

- **联系许可**：客户同意当前沟通和后续触达。
- **联系来源**：号码或关系如何获得，决定信任与隐私要求。
- **最小下一步**：与信息成熟度相匹配的合理行动，如发送资料或短会谈。
- **转介绍授权**：介绍人和客户均应清楚信息如何被使用。

## Mental Models

- 约访卖的是会谈价值，不是保险产品。
- 渠道偏好属于客户约束，不是需要攻破的借口。
- 信息越敏感，越需要解释用途和取得同意。

## Anti-patterns

- 假装调查、服务通知或熟人关系掩盖销售目的。
- 客户说忙时连续追问或制造紧急风险。
- 未经许可披露转介绍人的保单或隐私。
- 为了“完整KYC”在首次电话索取过量信息。

## Worked Example

客户说“资料发我就行”。销售人员询问他更关注医疗费用还是家庭责任，发送一页对应说明，并约定客户看完后自行决定是否安排15分钟交流；客户若不希望跟进，就记录停止联系。这样既保留服务入口，也不把索取面谈当作唯一成功。

## Key Takeaways

1. 约访只争取合理下一步。
2. 身份、来源、主题、时长和选项要清楚。
3. 客户渠道偏好和拒绝必须被尊重。
4. 转介绍与信息收集以授权为前提。
