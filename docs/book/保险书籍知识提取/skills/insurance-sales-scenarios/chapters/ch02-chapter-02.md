# Chapter 2: 第二章 登门拜访实训

## Core Idea

登门拜访先取得停留和提问的许可，再从客户愿意讨论的问题进入需求。客户“不感兴趣”或“很忙”可能是时间、信任、过往体验或明确拒绝，不能一律解释为尚未被说服。

## Frameworks Introduced

### 拜访许可阶梯

1. 确认当前是否方便。
2. 用一句话说明来意和可能价值。
3. 提出短时、具体的会谈范围。
4. 客户同意后再逐步进入家庭、计划和需求问题。
5. 每次扩大信息范围前说明用途。

### 需求四层提问

`现状 → 变化事件 → 风险后果 → 现有应对`

家庭情况、投保计划和购买决策权属于不同信息：先问与主题直接相关的事实，不以闲聊套取隐私。

### 决策角色确认

询问谁会共同评价方案、谁承担缴费、谁被保障以及何时适合共同沟通。确认决策角色不是绕过当前联系人。

## Key Concepts

- **进入许可**：客户同意销售人员停留并讨论明确主题。
- **提问许可**：在家庭、健康、财务等敏感领域继续了解的授权。
- **需求后果**：风险发生对费用、收入和责任的具体影响。
- **决策权**：可能由个人、配偶、家庭或组织多人共同承担。

## Mental Models

- 先降低互动成本，再增加信息深度。
- 兴趣不是被话术制造，而是客户发现主题与自身目标相关。
- 好问题产生事实，诱导问题只产生迎合。

## Anti-patterns

- 未预约上门后用礼貌压力迫使客户接待。
- 对“不感兴趣”连续反驳或贴“不懂保险”标签。
- 以关心家庭为名盘问收入、健康和婚姻。
- 得知对方非最终决策者后贬低或绕开对方。

## Worked Example

客户开门后说“又是卖保险的，免谈”。销售人员简短说明此次是受邀提供家庭保单检视，询问是否愿意用五分钟确认现有保障是否重复；若客户仍拒绝就结束。客户同意后，才从现有保单和近期家庭变化进入，而不是立刻推产品。

## Key Takeaways

1. 登门拜访首先管理许可，不是抢占注意力。
2. 需求提问从现状、变化、后果到现有应对。
3. 敏感信息只在用途明确且客户同意时收集。
4. 决策角色用于安排共同沟通，不用于绕过客户。
