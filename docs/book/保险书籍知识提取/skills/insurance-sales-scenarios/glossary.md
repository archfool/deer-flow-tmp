# 术语表

| 术语 | 含义 | 章节 |
|---|---|---|
| 联系许可 | 客户同意当前及约定范围内的后续沟通。 | ch01 |
| 最小下一步 | 与当前信息和意愿匹配的合理行动。 | ch01 |
| 提问许可 | 在家庭、健康、财务等领域继续了解的授权。 | ch02 |
| 决策角色 | 参与评价、缴费、被保障和最终决定的人。 | ch02, ch08 |
| 需求适配 | 产品责任、额度、期限和成本与客户风险的匹配。 | ch03 |
| 功能错位 | 用投资收益、储蓄流动性等标准评价风险保障功能。 | ch04 |
| 需求缺口 | 风险后果扣除资产、社保福利、家庭支持和旧保单后的不足。 | ch05 |
| 自留能力 | 客户用自身资源承担损失的能力和意愿。 | ch05 |
| 服务连续性 | 人员变动后合同和服务仍可被机构承接。 | ch06 |
| 支付能力 | 不损害必要生活、债务和应急安全的持续缴费能力。 | ch07 |
| 中断成本 | 停缴或退保带来的保障、现金价值和未来可保性影响。 | ch07 |
| 购买信号 | 提示客户进入行动评估的问题或行为，不等于同意。 | ch08 |
| 知情决定 | 客户理解重要利益和限制后自主选择。 | ch08 |
| 保单递送 | 交付合同并再次完成责任、权利与服务说明。 | ch09 |
| 事件触发检视 | 家庭、职业、收入、债务或健康变化后的保单复核。 | ch09 |
