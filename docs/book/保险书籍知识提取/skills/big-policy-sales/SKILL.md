## Core Frameworks & Mental Models

### 1. 大单能力系统

`证据化信念 → 目标市场 → 授权开拓 → 约访 → 观念沟通 → 方案七层 → 知情成交 → 异议五步 → 服务闭环`

大单不是普通方案放大保费；金额越大，KYC、现金流、权利结构、合同核验和专业协作越深。

### 2. 方案七层与成交四条件

方案依次记录客户事实、目标优先级、风险缺口、工具比较、保单角色、现金流压力和法律税务核验。只有需求确认、方案适配、支付可持续、重要限制已理解时才进入成交。

### 3. 服务三层

先完成递送、保全和理赔等基本服务，再考虑合规礼遇；跨专业问题经授权转介独立专家。服务“四现”应理解为可见、主动、有成果和有洞察，不是高频打扰。

### 4. 自我管理闭环

目标管理、时间块、情绪恢复、日行动记录和学习闭环共同保证稳定产能。结果目标同时接受投诉、持续率、告知质量和服务履约等质量指标约束。

### 5. 沟通能力链

表达采用事实、影响、选择三讲；提问使用开放到反思的问题漏斗；倾听通过关键词、复述和遗漏确认；反馈描述场景、行为与影响并形成下一步。

### 6. 品牌与渠道边界

个人品牌来自清晰定位、可验证内容和稳定履约。广告、数字、短信、邮件、礼品及嵌入营销均受真实、授权、隐私、频率和退出机制约束。
