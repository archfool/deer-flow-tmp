# 方法模式

## 1. 市场适配矩阵

**何时用**：选择重点客群。**怎么做**：比较需求、触达、专业匹配、周期、服务成本和合规风险。**权衡**：不以财富标签代替适配。

## 2. 方案七层

**何时用**：大额方案设计。**怎么做**：事实、目标、缺口、工具、角色、压力、专业核验逐层留痕。**权衡**：大额资金必须保留经营和家庭流动性。

## 3. 知情成交四条件

**何时用**：客户准备行动。**怎么做**：核验需求、适配、支付、理解。**权衡**：故事和利弊清单可组织信息，不能操纵同意。

## 4. 服务三层

**何时用**：设计客户服务。**怎么做**：先基本履约，再合规礼遇，最后经授权转介资源。**权衡**：披露利益冲突，不越界。

## 5. 自我管理周复盘

**何时用**：目标偏差或过劳。**怎么做**：检查结果、质量、时间、情绪、行动与学习指标。**权衡**：不以冲量牺牲告知和服务。

## 6. 沟通四能力

**何时用**：需求会谈。**怎么做**：三讲表达、问题漏斗、主动倾听、SBI反馈。**权衡**：非语言信号必须由客户确认。
