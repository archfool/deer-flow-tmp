# 大单销售速查

## 大单升级检查

- 客户事实和目标是否由本人确认？
- 企业、家庭和保单现金流是否分别压力测试？
- 谁缴费、控制、被保障、领取和变更是否清楚？
- 是否比较了非保险工具和未覆盖风险？
- 法律税务结论由谁按当前规则核验？
- 是否提供真实备选、不利因素和暂缓选项？

## 四条硬边界

1. 信念不能替代客户事实。
2. 成交不能替代知情决定。
3. 礼品不能替代基本服务。
4. 品牌和营销不能绕过授权、隐私与退出。
