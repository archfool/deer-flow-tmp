# Chapter 3: 寻找目标市场

## Core Idea

目标市场选择是把有限服务能力投向问题相似、可触达且自己有能力服务的人群。细分变量应与风险、决策和服务相关，不能只按财富或职业贴标签。

## Frameworks Introduced

### 市场适配矩阵

需求强度、可触达性、专业匹配、决策周期、服务成本与合规风险六项评分。

**何时使用**：出现类似本章案例的决策时：顾问在企业主与年轻家庭间选择时，不只看保费容量，而比较自己的案例经验、合作资源和持续服务成本。

## Key Concepts

- **概念关系**：本章将“市场细分、理想客户、服务能力、机会成本”放在同一决策链中讨论。其关系由“市场适配矩阵”明确：需求强度、可触达性、专业匹配、决策周期、服务成本与合规风险六项评分。
- **应用边界**：先防止“把高收入群体直接定义为目标”，再用客户事实和可验证证据决定是否采用该框架。

## Mental Models

- **从结果回到机制**：目标市场选择是把有限服务能力投向问题相似、可触达且自己有能力服务的人群。
- **用框架约束直觉**：需求强度、可触达性、专业匹配、决策周期、服务成本与合规风险六项评分。
- **以反例校正**：细分变量应与风险、决策和服务相关，不能只按财富或职业贴标签。

## Anti-patterns

- 把高收入群体直接定义为目标。
- 追逐热门圈层但没有专业能力。
- 忽略服务容量。

## Worked Example

顾问在企业主与年轻家庭间选择时，不只看保费容量，而比较自己的案例经验、合作资源和持续服务成本。

## Key Takeaways

1. 目标市场选择是把有限服务能力投向问题相似、可触达且自己有能力服务的人群。
2. 本章的可执行骨架是“市场适配矩阵”：需求强度、可触达性、专业匹配、决策周期、服务成本与合规风险六项评分。
3. 首先避免“把高收入群体直接定义为目标”，再用案例中的判断路径复盘实际行为。
