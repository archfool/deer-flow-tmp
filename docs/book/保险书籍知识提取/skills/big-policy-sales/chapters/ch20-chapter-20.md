# Chapter 20: 倾听能力

## Core Idea

倾听是接收内容、情绪和未说约束，并用复述验证。非语言信号只能提示继续询问，不能直接推断购买意愿。

## Frameworks Introduced

### 倾听四动作

停止准备反驳、记录关键词、复述含义、询问遗漏与优先级。

**何时使用**：出现类似本章案例的决策时：客户反复提流动性，顾问复述后发现其三年内要购房，于是停止推荐长期锁定方案。

## Key Concepts

- **概念关系**：本章将“主动倾听、复述、沉默、非语言信号”放在同一决策链中讨论。其关系由“倾听四动作”明确：停止准备反驳、记录关键词、复述含义、询问遗漏与优先级。
- **应用边界**：先防止“假听等着推产品”，再用客户事实和可验证证据决定是否采用该框架。

## Mental Models

- **从结果回到机制**：倾听是接收内容、情绪和未说约束，并用复述验证。
- **用框架约束直觉**：停止准备反驳、记录关键词、复述含义、询问遗漏与优先级。
- **以反例校正**：非语言信号只能提示继续询问，不能直接推断购买意愿。

## Anti-patterns

- 假听等着推产品。
- 打断。
- 把点头当同意。
- 只听能支持方案的信息。

## Worked Example

客户反复提流动性，顾问复述后发现其三年内要购房，于是停止推荐长期锁定方案。

## Key Takeaways

1. 倾听是接收内容、情绪和未说约束，并用复述验证。
2. 本章的可执行骨架是“倾听四动作”：停止准备反驳、记录关键词、复述含义、询问遗漏与优先级。
3. 首先避免“假听等着推产品”，再用案例中的判断路径复盘实际行为。
