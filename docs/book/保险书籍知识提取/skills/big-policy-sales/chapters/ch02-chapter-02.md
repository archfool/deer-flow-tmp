# Chapter 2: 如何建立成功的信念系统？

## Core Idea

可持续信念来自现实证据、可控行动和伦理边界。所谓顶级心智不是永远积极，而是能区分事实、解释和下一步；所谓因果法则是行为影响概率，不是努力必然成交。

## Frameworks Introduced

### 证据化信念

列出目标、可控行为、支持证据、反证和边界，每周用实际数据更新。

**何时使用**：出现类似本章案例的决策时：销售人员连续被拒后不喊口号，而是检查目标市场、约访转化和访谈录音，定位问题在名单适配还是表达。

## Key Concepts

- **概念关系**：本章将“心智模式、因果法则、自我效能、可控圈”放在同一决策链中讨论。其关系由“证据化信念”明确：列出目标、可控行为、支持证据、反证和边界，每周用实际数据更新。
- **应用边界**：先防止“把失败归咎于信念不够”，再用客户事实和可验证证据决定是否采用该框架。

## Mental Models

- **从结果回到机制**：可持续信念来自现实证据、可控行动和伦理边界。
- **用框架约束直觉**：列出目标、可控行为、支持证据、反证和边界，每周用实际数据更新。
- **以反例校正**：所谓顶级心智不是永远积极，而是能区分事实、解释和下一步；所谓因果法则是行为影响概率，不是努力必然成交。

## Anti-patterns

- 把失败归咎于信念不够。
- 用因果报应解释客户选择。
- 忽略市场、能力与随机性。

## Worked Example

销售人员连续被拒后不喊口号，而是检查目标市场、约访转化和访谈录音，定位问题在名单适配还是表达。

## Key Takeaways

1. 可持续信念来自现实证据、可控行动和伦理边界。
2. 本章的可执行骨架是“证据化信念”：列出目标、可控行为、支持证据、反证和边界，每周用实际数据更新。
3. 首先避免“把失败归咎于信念不够”，再用案例中的判断路径复盘实际行为。
