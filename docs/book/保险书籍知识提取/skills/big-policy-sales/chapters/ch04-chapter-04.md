# Chapter 4: 开拓目标市场

## Core Idea

社区、校友和商会只是进入场景，真正的开拓依赖授权、持续贡献和清晰定位。关系网络不能被当成可自由使用的客户名单。

## Frameworks Introduced

### 圈层开拓四步

了解共同议题、先提供公开价值、取得个别联系许可、按需求进入一对一服务。

**何时使用**：出现类似本章案例的决策时：顾问在商会先举办家企风险公开讲座，只邀请主动报名者做检视，不索取全体会员电话。

## Key Concepts

- **概念关系**：本章将“社区、校友、商会、关系授权”放在同一决策链中讨论。其关系由“圈层开拓四步”明确：了解共同议题、先提供公开价值、取得个别联系许可、按需求进入一对一服务。
- **应用边界**：先防止“群发同学录”，再用客户事实和可验证证据决定是否采用该框架。

## Mental Models

- **从结果回到机制**：社区、校友和商会只是进入场景，真正的开拓依赖授权、持续贡献和清晰定位。
- **用框架约束直觉**：了解共同议题、先提供公开价值、取得个别联系许可、按需求进入一对一服务。
- **以反例校正**：关系网络不能被当成可自由使用的客户名单。

## Anti-patterns

- 群发同学录。
- 借组织身份背书销售。
- 用赞助或礼品换名单。

## Worked Example

顾问在商会先举办家企风险公开讲座，只邀请主动报名者做检视，不索取全体会员电话。

## Key Takeaways

1. 社区、校友和商会只是进入场景，真正的开拓依赖授权、持续贡献和清晰定位。
2. 本章的可执行骨架是“圈层开拓四步”：了解共同议题、先提供公开价值、取得个别联系许可、按需求进入一对一服务。
3. 首先避免“群发同学录”，再用案例中的判断路径复盘实际行为。
