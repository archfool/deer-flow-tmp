# Chapter 7: 方案设计

## Core Idea

大单方案不是保费放大的产品组合，而是客户目标、现金流、权利结构与合同责任的可追溯映射。规模越大，压力测试和专业协作越重要。

## Frameworks Introduced

### 方案七层

客户事实、目标优先级、风险缺口、工具比较、保单角色、现金流压力、法律税务核验。

**何时使用**：出现类似本章案例的决策时：企业家拟投入大额保费，压力测试发现经营回款波动，方案降低长期承诺并保留流动账户。

## Key Concepts

- **概念关系**：本章将“保单架构、现金流、备选方案、不利因素”放在同一决策链中讨论。其关系由“方案七层”明确：客户事实、目标优先级、风险缺口、工具比较、保单角色、现金流压力、法律税务核验。
- **应用边界**：先防止“从预算倒推需求”，再用客户事实和可验证证据决定是否采用该框架。

## Mental Models

- **从结果回到机制**：大单方案不是保费放大的产品组合，而是客户目标、现金流、权利结构与合同责任的可追溯映射。
- **用框架约束直觉**：客户事实、目标优先级、风险缺口、工具比较、保单角色、现金流压力、法律税务核验。
- **以反例校正**：规模越大，压力测试和专业协作越重要。

## Anti-patterns

- 从预算倒推需求。
- 只给一个方案。
- 承诺避债避税。
- 忽略退保和缴费中断。

## Worked Example

企业家拟投入大额保费，压力测试发现经营回款波动，方案降低长期承诺并保留流动账户。

## Key Takeaways

1. 大单方案不是保费放大的产品组合，而是客户目标、现金流、权利结构与合同责任的可追溯映射。
2. 本章的可执行骨架是“方案七层”：客户事实、目标优先级、风险缺口、工具比较、保单角色、现金流压力、法律税务核验。
3. 首先避免“从预算倒推需求”，再用案例中的判断路径复盘实际行为。
