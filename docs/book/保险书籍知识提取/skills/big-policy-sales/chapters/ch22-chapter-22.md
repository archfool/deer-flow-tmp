# Chapter 22: 认识品牌经营

## Core Idea

个人品牌是客户对专业领域、行为一致性和交付记录的稳定预期。它不能靠包装替代能力，也不能与保险公司品牌混为一体。

## Frameworks Introduced

### 品牌三角

明确服务定位、持续输出可验证内容、用履约和案例边界积累信誉。

**何时使用**：出现类似本章案例的决策时：顾问以家庭保单检视为定位，持续发布条款阅读清单，并匿名化案例，不展示客户保费和身份。

## Key Concepts

- **概念关系**：本章将“定位、一致性、证据、声誉风险”放在同一决策链中讨论。其关系由“品牌三角”明确：明确服务定位、持续输出可验证内容、用履约和案例边界积累信誉。
- **应用边界**：先防止“炫耀大单和客户隐私”，再用客户事实和可验证证据决定是否采用该框架。

## Mental Models

- **从结果回到机制**：个人品牌是客户对专业领域、行为一致性和交付记录的稳定预期。
- **用框架约束直觉**：明确服务定位、持续输出可验证内容、用履约和案例边界积累信誉。
- **以反例校正**：它不能靠包装替代能力，也不能与保险公司品牌混为一体。

## Anti-patterns

- 炫耀大单和客户隐私。
- 打造全能专家。
- 购买虚假背书。
- 个人品牌凌驾合同。

## Worked Example

顾问以家庭保单检视为定位，持续发布条款阅读清单，并匿名化案例，不展示客户保费和身份。

## Key Takeaways

1. 个人品牌是客户对专业领域、行为一致性和交付记录的稳定预期。
2. 本章的可执行骨架是“品牌三角”：明确服务定位、持续输出可验证内容、用履约和案例边界积累信誉。
3. 首先避免“炫耀大单和客户隐私”，再用案例中的判断路径复盘实际行为。
