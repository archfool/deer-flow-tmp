# Chapter 11: 客户服务“四现”

## Core Idea

经常出现、主动表现、留下贡献、最后发现可理解为可见、主动、增值和洞察，但都必须尊重联系频率与隐私。服务存在感不能变成持续打扰。

## Frameworks Introduced

### 四现服务

按偏好可见；在事件前主动；留下可使用成果；从变化中发现新问题并先征求讨论许可。

**何时使用**：出现类似本章案例的决策时：年度检视前发送一页保单清单，客户可自行使用；发现新生儿信息后先询问是否需要复核。

## Key Concepts

- **概念关系**：本章将“服务可见性、主动服务、可留存成果、需求洞察”放在同一决策链中讨论。其关系由“四现服务”明确：按偏好可见；在事件前主动；留下可使用成果；从变化中发现新问题并先征求讨论许可。
- **应用边界**：先防止“高频问候制造存在感”，再用客户事实和可验证证据决定是否采用该框架。

## Mental Models

- **从结果回到机制**：经常出现、主动表现、留下贡献、最后发现可理解为可见、主动、增值和洞察，但都必须尊重联系频率与隐私。
- **用框架约束直觉**：按偏好可见；在事件前主动；留下可使用成果；从变化中发现新问题并先征求讨论许可。
- **以反例校正**：服务存在感不能变成持续打扰。

## Anti-patterns

- 高频问候制造存在感。
- 未经授权观察私人生活。
- 把发现问题直接转为推销。

## Worked Example

年度检视前发送一页保单清单，客户可自行使用；发现新生儿信息后先询问是否需要复核。

## Key Takeaways

1. 经常出现、主动表现、留下贡献、最后发现可理解为可见、主动、增值和洞察，但都必须尊重联系频率与隐私。
2. 本章的可执行骨架是“四现服务”：按偏好可见；在事件前主动；留下可使用成果；从变化中发现新问题并先征求讨论许可。
3. 首先避免“高频问候制造存在感”，再用案例中的判断路径复盘实际行为。
