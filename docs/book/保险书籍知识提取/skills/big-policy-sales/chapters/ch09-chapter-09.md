# Chapter 9: 应对拒绝

## Core Idea

拒绝是客户边界和决策信息。黄金公式应从反驳改为倾听、确认、追问、回应和验证；九类理由只能作为分类线索。

## Frameworks Introduced

### 拒绝五步

听原话、复述含义、问事实标准、用证据或备选回应、确认继续或结束。

**何时使用**：出现类似本章案例的决策时：客户说贵，追问后发现是流动性而非价值问题，方案改为较低承诺；若仍不合适则结束。

## Key Concepts

- **概念关系**：本章将“真实异议、礼貌拒绝、决策标准、再访许可”放在同一决策链中讨论。其关系由“拒绝五步”明确：听原话、复述含义、问事实标准、用证据或备选回应、确认继续或结束。
- **应用边界**：先防止“把每个拒绝当购买信号”，再用客户事实和可验证证据决定是否采用该框架。

## Mental Models

- **从结果回到机制**：拒绝是客户边界和决策信息。
- **用框架约束直觉**：听原话、复述含义、问事实标准、用证据或备选回应、确认继续或结束。
- **以反例校正**：黄金公式应从反驳改为倾听、确认、追问、回应和验证；九类理由只能作为分类线索。

## Anti-patterns

- 把每个拒绝当购买信号。
- 未经许可再访。
- 使用停售或灾难压力。

## Worked Example

客户说贵，追问后发现是流动性而非价值问题，方案改为较低承诺；若仍不合适则结束。

## Key Takeaways

1. 拒绝是客户边界和决策信息。
2. 本章的可执行骨架是“拒绝五步”：听原话、复述含义、问事实标准、用证据或备选回应、确认继续或结束。
3. 首先避免“把每个拒绝当购买信号”，再用案例中的判断路径复盘实际行为。
