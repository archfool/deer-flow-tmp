# Chapter 12: 服务的3个层次

## Core Idea

基本服务解决合同可用，礼品服务只能表达心意，资源整合处理跨专业需求。层次越高不代表越好，必须看客户问题和利益冲突。

## Frameworks Introduced

### 三层服务

合同递送/保全/理赔等基本服务；合规适度礼遇；经授权连接法律、税务、医疗等专业资源。

**何时使用**：出现类似本章案例的决策时：客户需要遗嘱咨询，顾问转介独立律师并披露合作关系，不代写文件，也不把转介绑定保单。

## Key Concepts

- **概念关系**：本章将“基本服务、礼品服务、资源整合、客户组织”放在同一决策链中讨论。其关系由“三层服务”明确：合同递送/保全/理赔等基本服务；合规适度礼遇；经授权连接法律、税务、医疗等专业资源。
- **应用边界**：先防止“基础服务没做好就建俱乐部”，再用客户事实和可验证证据决定是否采用该框架。

## Mental Models

- **从结果回到机制**：基本服务解决合同可用，礼品服务只能表达心意，资源整合处理跨专业需求。
- **用框架约束直觉**：合同递送/保全/理赔等基本服务；合规适度礼遇；经授权连接法律、税务、医疗等专业资源。
- **以反例校正**：层次越高不代表越好，必须看客户问题和利益冲突。

## Anti-patterns

- 基础服务没做好就建俱乐部。
- 以礼品换业务。
- 无授权共享客户信息。
- 越界替专家下结论。

## Worked Example

客户需要遗嘱咨询，顾问转介独立律师并披露合作关系，不代写文件，也不把转介绑定保单。

## Key Takeaways

1. 基本服务解决合同可用，礼品服务只能表达心意，资源整合处理跨专业需求。
2. 本章的可执行骨架是“三层服务”：合同递送/保全/理赔等基本服务；合规适度礼遇；经授权连接法律、税务、医疗等专业资源。
3. 首先避免“基础服务没做好就建俱乐部”，再用案例中的判断路径复盘实际行为。
