# Chapter 5: 成功约访

## Core Idea

约访的目标是获得目的明确的会谈许可。短信、电话和确认信息分别承担预告、双向确认和减少爽约的功能，不应重复轰炸。

## Frameworks Introduced

### 约访三触点

简短预告身份与主题；电话确认相关性、时长和时间；会前确认地点、参与者与资料。

**何时使用**：出现类似本章案例的决策时：企业主只愿给十分钟，顾问将目标限定为确认家企风险清单，并约定若无相关问题就结束。

## Key Concepts

- **概念关系**：本章将“联系许可、价值主张、时间选项、会前确认”放在同一决策链中讨论。其关系由“约访三触点”明确：简短预告身份与主题；电话确认相关性、时长和时间；会前确认地点、参与者与资料。
- **应用边界**：先防止“隐藏销售目的”，再用客户事实和可验证证据决定是否采用该框架。

## Mental Models

- **从结果回到机制**：约访的目标是获得目的明确的会谈许可。
- **用框架约束直觉**：简短预告身份与主题；电话确认相关性、时长和时间；会前确认地点、参与者与资料。
- **以反例校正**：短信、电话和确认信息分别承担预告、双向确认和减少爽约的功能，不应重复轰炸。

## Anti-patterns

- 隐藏销售目的。
- 客户未回复就连续触达。
- 用转介绍人施加人情压力。

## Worked Example

企业主只愿给十分钟，顾问将目标限定为确认家企风险清单，并约定若无相关问题就结束。

## Key Takeaways

1. 约访的目标是获得目的明确的会谈许可。
2. 本章的可执行骨架是“约访三触点”：简短预告身份与主题；电话确认相关性、时长和时间；会前确认地点、参与者与资料。
3. 首先避免“隐藏销售目的”，再用案例中的判断路径复盘实际行为。
