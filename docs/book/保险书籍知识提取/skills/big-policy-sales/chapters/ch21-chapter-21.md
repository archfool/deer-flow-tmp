# Chapter 21: 反馈能力

## Core Idea

反馈让客户和销售人员知道信息是否被正确理解、行动是否有效。反馈应具体、及时、基于行为，并形成下一步。

## Frameworks Introduced

### SBI反馈

描述场景、具体行为、产生影响，再共同确定保持或调整动作。

**何时使用**：出现类似本章案例的决策时：主管指出顾问在说明除外时语速加快，导致客户跳过提问，并安排下一次录音复盘。

## Key Concepts

- **概念关系**：本章将“理解反馈、行为反馈、闭环、可执行性”放在同一决策链中讨论。其关系由“SBI反馈”明确：描述场景、具体行为、产生影响，再共同确定保持或调整动作。
- **应用边界**：先防止“评价人格”，再用客户事实和可验证证据决定是否采用该框架。

## Mental Models

- **从结果回到机制**：反馈让客户和销售人员知道信息是否被正确理解、行动是否有效。
- **用框架约束直觉**：描述场景、具体行为、产生影响，再共同确定保持或调整动作。
- **以反例校正**：反馈应具体、及时、基于行为，并形成下一步。

## Anti-patterns

- 评价人格。
- 只给表扬不指出风险。
- 客户不回应就假定满意。
- 收集反馈后不改。

## Worked Example

主管指出顾问在说明除外时语速加快，导致客户跳过提问，并安排下一次录音复盘。

## Key Takeaways

1. 反馈让客户和销售人员知道信息是否被正确理解、行动是否有效。
2. 本章的可执行骨架是“SBI反馈”：描述场景、具体行为、产生影响，再共同确定保持或调整动作。
3. 首先避免“评价人格”，再用案例中的判断路径复盘实际行为。
