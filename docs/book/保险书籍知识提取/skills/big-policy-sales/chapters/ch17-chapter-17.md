# Chapter 17: 学习管理

## Core Idea

学习管理要把输入转化为客户场景中的准确行为。阅读、培训和案例只有经过练习、反馈和边界校验才成为能力。

## Frameworks Introduced

### 学习闭环

定义能力缺口、选择权威来源、提炼模型、角色练习、真实应用、反馈复盘、更新知识。

**何时使用**：出现类似本章案例的决策时：发现跨境税务问题频繁出现后，顾问学习基础识别边界并建立税务转介，而不是自称专家。

## Key Concepts

- **概念关系**：本章将“能力缺口、权威来源、刻意练习、知识更新”放在同一决策链中讨论。其关系由“学习闭环”明确：定义能力缺口、选择权威来源、提炼模型、角色练习、真实应用、反馈复盘、更新知识。
- **应用边界**：先防止“追课程数量”，再用客户事实和可验证证据决定是否采用该框架。

## Mental Models

- **从结果回到机制**：学习管理要把输入转化为客户场景中的准确行为。
- **用框架约束直觉**：定义能力缺口、选择权威来源、提炼模型、角色练习、真实应用、反馈复盘、更新知识。
- **以反例校正**：阅读、培训和案例只有经过练习、反馈和边界校验才成为能力。

## Anti-patterns

- 追课程数量。
- 照搬成功话术。
- 使用过时法规产品。
- 只学不练。

## Worked Example

发现跨境税务问题频繁出现后，顾问学习基础识别边界并建立税务转介，而不是自称专家。

## Key Takeaways

1. 学习管理要把输入转化为客户场景中的准确行为。
2. 本章的可执行骨架是“学习闭环”：定义能力缺口、选择权威来源、提炼模型、角色练习、真实应用、反馈复盘、更新知识。
3. 首先避免“追课程数量”，再用案例中的判断路径复盘实际行为。
