# Chapter 23: 营销手段

## Core Idea

广告、数字、短信、邮件、礼品和嵌入营销只是触达方式，均受真实、授权、隐私和可退出约束。渠道选择应匹配客户场景和可衡量目标。

## Frameworks Introduced

### 渠道试验表

目标人群、价值内容、授权来源、触达频率、转化指标、投诉退出和服务承接。

**何时使用**：出现类似本章案例的决策时：用公开文章引导客户主动预约保单检视，记录授权与退出，不把阅读者自动加入营销名单。

## Key Concepts

- **概念关系**：本章将“广告、数字营销、短信、邮件、礼品、嵌入营销”放在同一决策链中讨论。其关系由“渠道试验表”明确：目标人群、价值内容、授权来源、触达频率、转化指标、投诉退出和服务承接。
- **应用边界**：先防止“群发骚扰”，再用客户事实和可验证证据决定是否采用该框架。

## Mental Models

- **从结果回到机制**：广告、数字、短信、邮件、礼品和嵌入营销只是触达方式，均受真实、授权、隐私和可退出约束。
- **用框架约束直觉**：目标人群、价值内容、授权来源、触达频率、转化指标、投诉退出和服务承接。
- **以反例校正**：渠道选择应匹配客户场景和可衡量目标。

## Anti-patterns

- 群发骚扰。
- 隐性广告。
- 购买数据。
- 礼品诱导。
- 只看点击不看适配和投诉。

## Worked Example

用公开文章引导客户主动预约保单检视，记录授权与退出，不把阅读者自动加入营销名单。

## Key Takeaways

1. 广告、数字、短信、邮件、礼品和嵌入营销只是触达方式，均受真实、授权、隐私和可退出约束。
2. 本章的可执行骨架是“渠道试验表”：目标人群、价值内容、授权来源、触达频率、转化指标、投诉退出和服务承接。
3. 首先避免“群发骚扰”，再用案例中的判断路径复盘实际行为。
