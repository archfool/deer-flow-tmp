# Chapter 8: 成交是爱

## Core Idea

成交只有在客户充分理解并自主选择时才可能体现关怀。推定承诺、故事和富兰克林清单可用于组织信息，但不得预设同意或操纵情绪。

## Frameworks Introduced

### 知情成交四条件

需求确认、方案适配、支付可持续、重要限制已理解；缺一项就返回前序。

**何时使用**：出现类似本章案例的决策时：客户被故事打动准备签名，顾问仍暂停核对现金价值和非保证利益，客户理解后才决定。

## Key Concepts

- **概念关系**：本章将“推定承诺、利弊清单、故事、知情决定”放在同一决策链中讨论。其关系由“知情成交四条件”明确：需求确认、方案适配、支付可持续、重要限制已理解；缺一项就返回前序。
- **应用边界**：先防止“把不签单视为不爱家人”，再用客户事实和可验证证据决定是否采用该框架。

## Mental Models

- **从结果回到机制**：成交只有在客户充分理解并自主选择时才可能体现关怀。
- **用框架约束直觉**：需求确认、方案适配、支付可持续、重要限制已理解；缺一项就返回前序。
- **以反例校正**：推定承诺、故事和富兰克林清单可用于组织信息，但不得预设同意或操纵情绪。

## Anti-patterns

- 把不签单视为不爱家人。
- 故事替代证据。
- 默认客户同意。
- 隐瞒清单中的不利项。

## Worked Example

客户被故事打动准备签名，顾问仍暂停核对现金价值和非保证利益，客户理解后才决定。

## Key Takeaways

1. 成交只有在客户充分理解并自主选择时才可能体现关怀。
2. 本章的可执行骨架是“知情成交四条件”：需求确认、方案适配、支付可持续、重要限制已理解；缺一项就返回前序。
3. 首先避免“把不签单视为不爱家人”，再用案例中的判断路径复盘实际行为。
