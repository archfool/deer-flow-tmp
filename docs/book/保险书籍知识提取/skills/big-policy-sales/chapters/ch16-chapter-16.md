# Chapter 16: 行为管理

## Core Idea

出勤、工作日记和每日思考的价值在于形成稳定输入与反馈。形式化打卡若没有有效客户活动和改进结论，只会制造忙碌。

## Frameworks Introduced

### 日行动记录

计划活动、实际完成、客户事实、偏差原因、一个改进行动；每周汇总转化与质量。

**何时使用**：出现类似本章案例的决策时：日记显示约访多但到访少，顾问改进会前确认而非单纯增加电话数。

## Key Concepts

- **概念关系**：本章将“出勤、工作日记、反思、领先指标”放在同一决策链中讨论。其关系由“日行动记录”明确：计划活动、实际完成、客户事实、偏差原因、一个改进行动；每周汇总转化与质量。
- **应用边界**：先防止“用出勤代替产出”，再用客户事实和可验证证据决定是否采用该框架。

## Mental Models

- **从结果回到机制**：出勤、工作日记和每日思考的价值在于形成稳定输入与反馈。
- **用框架约束直觉**：计划活动、实际完成、客户事实、偏差原因、一个改进行动；每周汇总转化与质量。
- **以反例校正**：形式化打卡若没有有效客户活动和改进结论，只会制造忙碌。

## Anti-patterns

- 用出勤代替产出。
- 记录客户隐私过量。
- 只写感想不改行动。
- 数据造假。

## Worked Example

日记显示约访多但到访少，顾问改进会前确认而非单纯增加电话数。

## Key Takeaways

1. 出勤、工作日记和每日思考的价值在于形成稳定输入与反馈。
2. 本章的可执行骨架是“日行动记录”：计划活动、实际完成、客户事实、偏差原因、一个改进行动；每周汇总转化与质量。
3. 首先避免“用出勤代替产出”，再用案例中的判断路径复盘实际行为。
