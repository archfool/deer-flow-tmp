# Chapter 18: 表达能力

## Core Idea

表达的任务是让客户准确理解并能行动。“神奇三讲”可重构为讲事实、讲影响、讲选择，避免只讲公司、产品和自己。

## Frameworks Introduced

### 三讲

用可验证事实说明现状；解释与客户目标的影响；呈现选择、代价和下一步。

**何时使用**：出现类似本章案例的决策时：说明年金时先列保证与非保证现金流，再解释流动性代价，最后请客户复述，而非只讲长期收益。

## Key Concepts

- **概念关系**：本章将“结构化表达、通俗化、证据、理解确认”放在同一决策链中讨论。其关系由“三讲”明确：用可验证事实说明现状；解释与客户目标的影响；呈现选择、代价和下一步。
- **应用边界**：先防止“术语堆砌”，再用客户事实和可验证证据决定是否采用该框架。

## Mental Models

- **从结果回到机制**：表达的任务是让客户准确理解并能行动。
- **用框架约束直觉**：用可验证事实说明现状；解释与客户目标的影响；呈现选择、代价和下一步。
- **以反例校正**：“神奇三讲”可重构为讲事实、讲影响、讲选择，避免只讲公司、产品和自己。

## Anti-patterns

- 术语堆砌。
- 只讲优势。
- 故事替代条款。
- 表达流畅就认为客户理解。

## Worked Example

说明年金时先列保证与非保证现金流，再解释流动性代价，最后请客户复述，而非只讲长期收益。

## Key Takeaways

1. 表达的任务是让客户准确理解并能行动。
2. 本章的可执行骨架是“三讲”：用可验证事实说明现状；解释与客户目标的影响；呈现选择、代价和下一步。
3. 首先避免“术语堆砌”，再用案例中的判断路径复盘实际行为。
