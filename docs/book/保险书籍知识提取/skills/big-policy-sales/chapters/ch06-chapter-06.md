# Chapter 6: 观念沟通

## Core Idea

教育金、养老金、企业风险和理财观念沟通，都应从客户事实与时间目标开始。性别不是沟通脚本，女性、企业主或投资者内部差异远大于标签。

## Frameworks Introduced

### 目标现金流四问

何时需要、需要多少、现有来源、缺口在什么情景下扩大；再比较保险与非保险工具。

**何时使用**：出现类似本章案例的决策时：客户问教育金，顾问先测算时间和已有储蓄，并同时检查父母收入中断，而不是直接推荐年金。

## Key Concepts

- **概念关系**：本章将“教育金、养老金、企业风险、理财观念”放在同一决策链中讨论。其关系由“目标现金流四问”明确：何时需要、需要多少、现有来源、缺口在什么情景下扩大；再比较保险与非保险工具。
- **应用边界**：先防止“按性别套用情感话术”，再用客户事实和可验证证据决定是否采用该框架。

## Mental Models

- **从结果回到机制**：教育金、养老金、企业风险和理财观念沟通，都应从客户事实与时间目标开始。
- **用框架约束直觉**：何时需要、需要多少、现有来源、缺口在什么情景下扩大；再比较保险与非保险工具。
- **以反例校正**：性别不是沟通脚本，女性、企业主或投资者内部差异远大于标签。

## Anti-patterns

- 按性别套用情感话术。
- 先制造焦虑再卖产品。
- 把保险收益与投资错位比较。

## Worked Example

客户问教育金，顾问先测算时间和已有储蓄，并同时检查父母收入中断，而不是直接推荐年金。

## Key Takeaways

1. 教育金、养老金、企业风险和理财观念沟通，都应从客户事实与时间目标开始。
2. 本章的可执行骨架是“目标现金流四问”：何时需要、需要多少、现有来源、缺口在什么情景下扩大；再比较保险与非保险工具。
3. 首先避免“按性别套用情感话术”，再用案例中的判断路径复盘实际行为。
