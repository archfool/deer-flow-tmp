# 术语表

| 术语 | 含义 | 章节 |
|---|---|---|
| 人力资本 | 未来可支配劳动收入及其支持责任的经济价值。 | ch01 |
| 费用补偿 | 按合同对符合责任的实际费用补偿。 | ch01 |
| 定额给付 | 达到约定条件后按金额或比例给付。 | ch01 |
| 养老缺口 | 目标支出与可持续收入来源的差额。 | ch01 |
| 品质现金流 | 客户希望长期维持的、基础生活以上的支出。 | ch02 |
| 保险金信托 | 保险给付与信托管理衔接的安排。 | ch02, ch06 |
| 婚姻财产事实表 | 记录来源、时间、权属、出资、约定、债务和证据。 | ch03 |
| 财产混同 | 不同来源资金在账户、使用或证据上难以区分。 | ch03 |
| 家企风险传导 | 企业风险经担保、账户、借款等连接进入家庭。 | ch04 |
| 代为清偿 | 特定主体按法律或合同代替债务人清偿，条件须个案核验。 | ch04 |
| 股东互保 | 为股东事件提供股权过渡资金的保险安排。 | ch04 |
| 税收居民 | 决定辖区申报和纳税义务的重要身份事实。 | ch05 |
| CRS | 金融账户涉税信息交换框架，不是直接征税规则。 | ch05 |
| 税源 | 税费到期时合法、及时可用的流动资金来源。 | ch05 |
| 传承治理 | 围绕长期资产的决策、管理、监督、分配和变更机制。 | ch06 |
| 代持风险 | 名义与实际权利不一致导致的证明、控制和争议风险。 | ch06 |
