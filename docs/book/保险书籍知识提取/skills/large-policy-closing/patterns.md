# 方法模式

## 1. 人身四账户

**何时用**：高净值人身保障。**怎么做**：分生命责任、医疗费用、收入机会、养老现金流测算并扣除资源。**权衡**：资产可自留风险，企业价值不等于个人流动性。

## 2. 婚姻财产事实表

**何时用**：婚前、婚内、再婚、赠与或债务安排。**怎么做**：记录来源、时间、权属、出资、约定、混同、债务、证据与法律。**权衡**：由律师定性，保单角色不直接决定性质。

## 3. 家企风险传导图

**何时用**：企业主大额方案。**怎么做**：逐项画出股权、账户、分红借款、担保、关联交易、家庭投入和执行。**权衡**：不处理既有债务逃避。

## 4. 跨境税务六格

**何时用**：移民、境外资产或多辖区家庭。**怎么做**：核验身份、家庭、资产、所得交易、申报交换、现金流时间。**权衡**：使用当前规则和多地专业意见。

## 5. 传承六层

**何时用**：复杂传承。**怎么做**：目标、资产、人员、工具、风险、治理逐层设计。**权衡**：控制越强，复杂度、成本和冲突风险越高。
