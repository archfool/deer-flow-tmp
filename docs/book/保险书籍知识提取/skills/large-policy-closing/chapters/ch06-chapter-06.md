# Chapter 6: 第6章 家族财富传承攻略

## Core Idea

传承不是把资产交给下一代的单一交易，而是目标、控制、受益、治理、税费、能力和长期执行的系统。保险可提供合同给付，信托可按规则管理，法人结构可承载经营资产；代持和“防败家”表达都必须接受权属、受托责任和受益人权利检验。

## Frameworks Introduced

### 传承系统六层

1. **目标**：给谁、何时、用于什么、希望保留何种控制。
2. **资产**：现金、金融资产、房产、股权、知识产权等差异。
3. **人员**：委托/出资、管理、监督、受益和备用角色。
4. **工具**：遗嘱、赠与、保险、信托、公司与协议。
5. **风险**：婚姻、债务、税务、代持、能力和家族冲突。
6. **治理**：信息、决策、分配、变更、退出和定期复核。

### 控制与受益分离

分别记录谁拥有、谁管理、谁可变更、谁在什么条件下获得利益。控制安排须防止权力失衡和执行失败，不能只追求“长辈永远控制”。

### 财产类型适配

现金重流动与管理，房产重登记与使用，股权重公司治理和接班，保险重合同角色与给付，跨境资产重辖区规则。不同财产不使用同一传承模板。

## Key Concepts

- **保险金信托**：保险给付与信托管理衔接的安排，具体成立、进入和管理规则需核验。
- **资产法人化**：通过公司等法人持有和治理资产，同时带来公司、税务和管理成本。
- **代持风险**：名义与实际权利不一致引发的证明、控制和争议风险。
- **家族治理**：围绕共同资产和长期目标的决策、监督与冲突机制。

## Mental Models

- 保险解决部分资金来源，治理决定长期执行。
- 控制越强，通常意味着复杂度、成本和冲突风险越高。
- “败家”是带偏见的标签，应改写为受益人能力和支持需求。

## Anti-patterns

- 用单一保单或信托承诺完成全部传承。
- 以防败家为名剥夺受益人合理权利与尊严。
- 用法人化或代持逃避债务、税务和披露。
- 只设计首次转移，不设计管理、监督、变更和退出。

## Worked Example

家族有企业股权、房产和需要长期支持的年轻继承人。团队按六层系统分别处理股权治理、房产使用、保险流动资金与信托分配，并设置独立监督和复核。方案不以“绝对控制”承诺，而披露费用、角色冲突和法律税务前提。

## Key Takeaways

1. 传承系统由目标、资产、人员、工具、风险和治理构成。
2. 控制、管理、变更和受益必须分别定义。
3. 不同财产类型需要不同工具与证据。
4. 大额传承是长期治理，不是一次成交。
