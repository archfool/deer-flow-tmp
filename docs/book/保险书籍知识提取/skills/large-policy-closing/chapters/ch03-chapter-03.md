# Chapter 3: 第3章 婚姻财富规划攻略

## Core Idea

婚姻财富规划要识别财产来源、取得时间、登记与实际出资、赠与意思、共同债务、保单角色和证据。保单可能参与保障和现金流安排，但不能仅凭“谁做投保人/受益人”保证婚前、婚内、离婚或再婚中的财产结果。

## Frameworks Introduced

### 婚姻财产事实表

`资产来源 | 取得时间 | 名义权属 | 实际出资 | 赠与/约定 | 使用与混同 | 债务关联 | 证据 | 适用法律`

每次方案先完成事实表，再由律师判断性质和风险。

### 保单权利五问

谁缴费、谁是投保人、谁被保障、谁领取、谁能变更或退保。五问描述权利和现金流，不直接等于财产归属结论。

### 六类婚姻场景

婚前安排、婚内资产、离婚分割、共同债务、父母准备嫁妆、再婚家庭。每类分别识别客户目标、对方权利、子女利益和未来变更。

## Key Concepts

- **财产混同**：不同来源资金在账户、使用或证据上难以区分。
- **共同债务**：是否共同承担依事实和现行法律判断，保单不能自动对抗。
- **赠与意思**：赠与对象、条件和证据会影响安排效果。
- **再婚治理**：现任配偶、前婚子女和共同子女之间的责任与信息协调。

## Mental Models

- 先做事实定性，再选金融工具。
- 控制权、现金价值和保险金是不同权利对象。
- 越想对抗未来争议，越需要清楚证据和双方权利边界。

## Anti-patterns

- 宣称保单天然属于个人财产或绝对不会被分割。
- 用受益人指定替代婚姻财产与继承分析。
- 为“隔离”隐瞒资产、逃避共同债务或损害他人权利。
- 把嫁妆和再婚家庭套入固定架构。

## Worked Example

父母计划为已婚女儿准备大额保单。顾问先记录资金来源、赠与对象、投保与控制安排以及女儿家庭需求，再由律师核验赠与和婚姻财产效果。方案同时披露退保、变更和父母身故后的控制变化，不使用“完美嫁妆、绝对隔离”表述。

## Key Takeaways

1. 婚姻规划从来源、时间、出资、权属、债务和证据进入。
2. 保单五个角色描述权利，不直接决定财产性质。
3. 婚前、婚内、离婚、债务、嫁妆和再婚需分别分析。
4. 任何保护效果都受现行法律、事实和第三方权利约束。
