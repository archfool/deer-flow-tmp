# Chapter 5: 第5章 税务安排攻略

## Core Idea

税务规划不能从“保险是否免税”开始，而要从税收居民身份、资产和所得类型、交易与给付、申报义务和时间进入。企业税务、遗产税税源与CRS是不同问题；书中政策数据具有时代性，当前个案必须由相应辖区专业人士核验。

## Frameworks Introduced

### 跨境税务六格

`人及税收居民身份 | 家庭成员身份 | 资产/企业属地 | 所得与交易类型 | 申报交换义务 | 现金流与时间`

每格记录当前、计划变化和证据，不以国籍、绿卡或保单所在地单独判断税务结果。

### 企业税务与个人保单分界

先核查企业交易、发票、关联往来、分红薪酬和历史风险；个人购买保单不能“剥离”已经形成的企业税务责任。资金进入保单的来源与程序同样要合规。

### 税源准备

若专业测算确认未来可能发生税费或传承成本，再估算金额、时间、币种和流动性来源，比较现金、可变现资产、融资与保险给付。保险只是一种候选税源。

## Key Concepts

- **税收居民**：决定特定辖区税务与申报的重要身份事实。
- **CRS**：金融账户涉税信息交换框架，不等于直接征税规则。
- **税源**：税款到期时可合法、及时使用的流动资金来源。
- **合规申报**：按适用规则完整、及时披露和纳税。

## Mental Models

- 信息交换、纳税义务和税率是三个不同问题。
- 税务效果属于“人、产、交易、时间”的组合，不属于产品标签。
- 先确认有无税，再讨论税源和工具。

## Anti-patterns

- 承诺保单免税、规避CRS或无需申报。
- 用书中历史豁免额、税率和政策回答当前客户。
- 用个人保单掩盖企业既有税务问题。
- 为税务目的牺牲流动性和真实保障需求。

## Worked Example

家庭成员分居中美两地并持有企业股权。顾问先建立六格矩阵，由两地税务律师确认身份、申报与未来传承税费；只有确认存在特定时间的流动性缺口后，才比较保险给付与其他税源，不宣称一张保单实现两地免税。

## Key Takeaways

1. 税务规划先确定身份、资产、交易、申报和时间。
2. CRS信息交换不等于征税结论。
3. 个人保单不能消除企业既有税务责任。
4. 保险是税源候选，不是免税保证。
