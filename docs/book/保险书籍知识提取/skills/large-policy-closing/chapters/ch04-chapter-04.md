# Chapter 4: 第4章 家企隔离攻略

## Core Idea

家企隔离首先是公司治理、账户、交易、担保和证据问题。投保人、受益人、现金价值或低现价产品可能改变具体权利形态，但不能为已存在债务、担保或执行提供当然“防火墙”，更不能用于逃避合法债权。

## Frameworks Introduced

### 家企风险传导图

`股权与出资 → 个人/公司账户 → 分红借款 → 个人担保 → 关联交易 → 家庭资产投入 → 债务与执行状态`

每条连接标记时间、金额、合同、决策人和证据，再由公司、债务与执行专业律师核验。

### 保单权利分层

投保人合同控制、被保险人人身标的、受益人保险金请求、现金价值、质押贷款和代为清偿等是不同权利。适用条件及能否被处分或执行必须按个案和现行法律判断。

### 企业延续三工具

关键人保障提供现金、股东协议规定股权处理、治理和融资安排保证执行。所谓股东互保必须与估值、受益、税务、保费和协议同步设计。

## Key Concepts

- **个人担保**：个人为企业债务承担约定责任，会直接连接家企风险。
- **现金价值**：合同中的财产性价值，其归属和处置不能仅凭产品名称判断。
- **保单质押贷款**：以合同现金价值为基础的融资，利息和余额影响合同利益。
- **股东互保**：为股东事件提供资金的保险安排，不替代股权协议。

## Mental Models

- 防火墙来自真实治理和证据，不来自营销名称。
- 债务发生前后的安排空间与法律评价可能完全不同。
- 保险提供资金，协议和治理决定资金如何解决股权问题。

## Anti-patterns

- 宣称换投保人或受益人即可合法避债。
- 为被执行人或已发生争议设计资产转移。
- 低现价产品包装成绝对不可执行。
- 只买股东互保，不做估值和股权协议。

## Worked Example

企业主已为公司贷款提供个人担保，希望用保单“隔离”家庭资产。顾问明确保单不能消除既有担保，先让律师核查债务与执行状态；保险仅评估未来关键人和股权过渡资金，家庭账户治理与关联交易另行整改。

## Key Takeaways

1. 家企隔离从治理、账户、交易、担保和证据开始。
2. 保单各项权利必须分层判断。
3. 既有债务和执行不能靠保单当然对抗。
4. 企业延续需要保险资金、股权协议和治理协同。
