# Chapter 1: 第1章 人身风险攻略

## Core Idea

高净值客户的人身风险不因资产多而消失，只是后果结构不同：人力资本、企业关键人、医疗选择、康复收入、养老品质和家庭责任可能同时受影响。大额保障应从损失测算进入，而不是从客户资产比例或产品上限进入。

## Frameworks Introduced

### 人身风险四账户

1. **生命责任**：债务、家庭支出、教育赡养和企业关键人影响。
2. **健康费用**：基础医疗、高端医疗、院外与康复等可补偿费用。
3. **收入与机会损失**：患病、伤残和照护造成的非发票损失。
4. **养老现金流**：退休后的生活、医疗、照护和遗留目标。

### 人力资本定价

按未来可支配收入、责任期限、替代资源和折现假设形成区间，再扣除资产、单位福利和旧保单。企业价值不能直接等同于个人生命价值。

### 重疾与医疗十项核验

如实告知、疾病定义、等待期、保险期间、保额、缴费期、核保结果、除外、续保/服务、公司与地区差异。病种数量和“高端”名称都不能替代责任比较。

## Key Concepts

- **费用补偿与定额给付**：前者处理符合责任的实际费用，后者处理约定状态下的现金缺口。
- **健康核保**：根据健康与风险信息决定承保条件。
- **养老缺口**：目标支出扣除社保、租金、投资和其他可持续收入后的差额。
- **地区产品差异**：适用法律、货币、医疗网络、缴费和理赔均可能不同。

## Mental Models

- 财富能自留部分风险，也会扩大责任与服务要求。
- 医疗险负责“花了多少”，定额保障更多处理“因此少了什么”。
- 大额保费按压力情景测试，不按最好年份支付能力设计。

## Anti-patterns

- 用收入固定倍数得出唯一人身价值。
- 病种越多、医院越贵就判断产品越好。
- 为通过核保淡化告知或病史。
- 宣称境外产品天然更优，忽略法律、汇兑和服务。

## Worked Example

企业主希望配置高额重疾。测算发现其医疗费用可自留，但病后退出经营会造成家庭收入和企业关键人缺口。方案把医疗服务、定额现金和企业治理分别处理，并以经营收入下降情景检验缴费，不用一张重疾险解决全部后果。

## Key Takeaways

1. 人身风险分生命责任、健康费用、收入损失和养老现金流。
2. 人力资本采用区间和替代资源测算。
3. 重疾与医疗按合同十项核验，不看标签。
4. 跨地区产品必须额外核验法律、货币和服务。
