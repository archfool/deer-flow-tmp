# 术语表

本表按本书语境解释概念。产品责任、核保及保全规则仍以具体合同和现行制度为准。

| 术语 | 含义 | 相关章节 |
|---|---|---|
| 风险自留 | 家庭用收入、储蓄或资产自行承担损失。适合频率较高但金额可控的风险，不适合足以破坏家庭财务的损失。 | ch01 |
| 费用补偿 | 在责任范围和限额内，按实际发生且符合约定的费用补偿；不能把保额直接理解为必然到账金额。 | ch01 |
| 定额给付 | 达到合同约定的事故、疾病或状态后，按约定金额或比例给付，主要填补收入和责任缺口。 | ch01, ch03 |
| 保额 | 合同约定的保障限额或给付基数。保额高低应对应财务后果，而不是只与保费预算挂钩。 | ch01, ch03, ch04, ch07 |
| 保费 | 为取得保险保障支付的成本。比较保费时必须同时比较责任、期限、免赔、除外及续保条件。 | ch03, ch05, ch07 |
| 保障缺口 | 目标财务责任扣除社保、单位福利、可变现资产和既有保单后的不足部分。 | ch03, ch04, ch07 |
| 社保与商业保险 | 社保提供基础、普惠保障；商业保险按合同补充额度、范围或给付方式，两者不是简单替代关系。 | ch02 |
| 偿付能力 | 衡量保险机构履行保险责任能力的重要监管指标之一。判断机构风险需查现行监管披露，不能只凭规模或传闻。 | ch02 |
| 如实告知 | 投保时对保险人询问的重要事项如实回答。不可抗辩规则不等于允许故意隐瞒。 | ch02, ch07 |
| 不可抗辩 | 对保险人解除合同权设置期限和条件的制度安排；适用时仍须结合告知内容、主观状态、合同和现行法律。 | ch02 |
| 家庭生命周期 | 用单身、新婚育儿、发展中期、责任下降等阶段识别责任变化并动态调整保障。 | ch04 |
| 主要责任人 | 收入中断、身故或失能会对家庭现金流与责任履行造成最大影响的人，不一定是年龄最大或最受关爱的人。 | ch04, ch05 |
| 投保人豁免 | 符合约定情形时免交后续保费，使被保险人的保障继续；需核对触发条件、期限和除外。 | ch04, ch05, ch11 |
| 团体保险 | 以符合条件的团体成员为被保险人的安排，通常具有成本和投保便利，但保障可能随劳动或成员关系变化。 | ch06 |
| 第三者责任保险 | 被保险人依法应向第三方承担赔偿责任时，在合同范围内提供保障；公众责任、雇主责任等对应不同责任来源。 | ch06 |
| 核保 | 保险人依据健康、职业、财务等信息决定是否承保及承保条件的过程。 | ch07 |
| 投保人 | 与保险人订立合同并承担交费义务的人，通常拥有合同约定的保全权利。 | ch08 |
| 被保险人 | 其生命、身体、健康或财产受到合同保障的人。 | ch08 |
| 受益人 | 在约定保险事故发生后依法或依合同领取保险金的人；指定顺序和比例应清楚。 | ch08 |
| 保全 | 合同有效期间对投保人、受益人、缴费方式、联系方式等进行的变更和维护。 | ch08, ch11 |
| 报案 | 保险事故发生后向保险人通知事故的动作；报案不等于完成理赔申请。 | ch09 |
| 理赔申请 | 按合同提交申请、证明和资料，由保险人审核责任及金额的过程。 | ch09 |
| 建议书 | 用于展示方案、保费和利益演示的说明材料，不替代保险合同。 | ch10 |
| 保证利益 | 合同明确承诺、符合条件即可取得的利益；应与演示或非保证利益分开阅读。 | ch10 |
| 免责条款 | 约定保险人不承担责任的情形。阅读时应与责任范围、等待期、定义和特别约定一起核对。 | ch10 |
| 主险与附加险 | 主险可独立成立；附加险依附主险，终止、续保和责任关系需按条款判断。 | ch11 |
| 现金价值 | 长期保险合同在特定时点按合同计算的价值，不等于累计保费，也不等于任意时点可无损取现。 | ch11 |
| 减额交清 | 用已有现金价值一次性购买较低保额，使合同在不再缴费的情况下按调整后的责任继续。 | ch11 |
| 保单贷款 | 在合同允许范围内以现金价值为基础取得贷款；利息和未偿还余额会影响合同效力或给付。 | ch11 |
| 宽限期 | 分期保费到期未缴后，合同约定的缓冲期间；期间责任及逾期后果以条款为准。 | ch11 |
| 等待期 | 合同生效后特定时期内，部分原因导致的事故不按通常责任处理。 | ch11 |
| 演示利率 | 用于展示非保证利益的假设参数，不是承诺收益。 | ch10, ch11 |
| 多次赔付 | 同一合同允许在满足分组、间隔期、状态等条件后多次给付，不能只看“次数”判断价值。 | ch11 |
