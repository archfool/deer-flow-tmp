# Chapter 8: 买中策略与关系人调整

## Core Idea

保单签发并不意味着规划固定不变。买中和持有阶段要持续检查保额、投保人、被保险人和受益人，使合同结构与家庭关系、责任和控制意图保持一致。

## Frameworks Introduced

- **年度保单回顾**：至少每一两年检查家庭结构、收入、负债、健康、职业和已有保障变化。
  - How：更新家庭事实 → 汇总所有保单 → 重算缺口 → 检查关系人 → 提出保全动作。
- **投保人持续性检查**：投保人掌握缴费和部分合同权利，其死亡、离婚或失去缴费能力可能影响合同持续。
- **受益人顺序与比例**：可以设置同一顺序多人按比例领取，也可以设置不同顺序；设计目标是减少争议并实现照顾意图。
- **关系变化触发器**：结婚、离婚、生育、死亡、企业变化和债务变化都应触发投保人与受益人复核。

## Key Concepts

- **投保人**：与保险人订立合同并承担缴费义务的人，通常拥有现金价值等合同权利。
- **被保险人**：其生命、健康或身体受到保障的人。
- **受益人**：在约定保险事故发生后依法或依约领取保险金的人。
- **受益顺序**：前一顺序不存在或不能领取时，后一顺序才可能启动。
- **保全**：合同存续期间进行关系人、联系方式、缴费方式等变更和管理的手续。

## Mental Models

- 保额解决“多少钱”，关系人安排解决“谁控制、谁被保、谁领取”。
- 把受益人设计看成家庭应急分配方案，而不是签单时的形式字段。
- 任何家庭关系变化，都要问一次“原来的合同意图还成立吗”。

## Anti-patterns

- **长期不回顾**：家庭责任上升但保额仍停留在多年以前。
- **默认法定受益人而不理解后果**：可能增加继承手续和家庭争议。
- **忽略投保人死亡风险**：事后变更可能涉及继承手续，影响合同管理。
- **只改受益人不留证据**：未按保险公司流程完成变更，意愿可能无法生效。

## Worked Example

客户希望同时照顾配偶、父母和子女。可以在第一顺序中给配偶和母亲设置比例，再在第二顺序安排父亲和子女。执行前必须确认保险公司支持的设置方式、各受益人身份资料，并说明顺序与比例的启动逻辑；家庭关系变化后重新确认。

## Key Takeaways

1. 保单至少每一两年系统回顾一次。
2. 保额和关系人都要随家庭责任变化。
3. 投保人安排关系到缴费、控制和合同持续。
4. 受益顺序与比例必须表达清晰并完成正式保全。
5. 所有变更都应保存保险公司确认凭证。
