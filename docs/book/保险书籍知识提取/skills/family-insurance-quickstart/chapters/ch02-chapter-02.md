# Chapter 2: 关于保险的十个争论

## Core Idea

面对保险争论，不用口号回答，而要把问题拆成监管、合同、风险、服务和客户条件。多数“保险好不好”的争论，真正答案都是“在什么条件下、解决什么问题”。

## Frameworks Introduced

- **争论拆解法**：先识别客户质疑的是机构安全、工具功能、合同责任、购买顺序、收益还是诚信义务，再调用对应证据。
  - When to use：客户提出“公司会倒吗”“社保够不够”“病种越多越好吗”等问题时。
  - How：确认问题 → 说明判断维度 → 给出边界 → 回到客户事实。
- **社保与商业保险互补**：社保提供基础和广覆盖，商业保险用于补充额度、范围、收入损失和个性化服务。
  - Failure mode：把二者描述成非此即彼，或贬低社保来销售商业保险。
- **条款优先但不唯条款**：合同决定权利义务，产品设计、服务网络、理赔便利和持续服务也影响实际体验。
- **病种数量不是单一质量指标**：重疾险应比较定义、分组、触发、保额、等待期和轻症/豁免，而不是只数病名。
- **如实告知不可投机**：两年不可抗辩不是隐瞒事实的许可证；是否赔付仍涉及询问、重要事实、因果、解除权和证据。

## Key Concepts

- **偿付能力监管**：监管机构持续监控保险公司的资本和风险，不等于任何公司都没有经营风险。
- **合同责任**：保险公司承担的是条款约定责任，不是对所有疾病和事故兜底。
- **通胀风险**：长期固定保额购买力可能下降，应通过合理保额、阶段复核和可调整配置应对。
- **购买顺序**：通常先保障家庭主要责任承担者，再考虑保障责任较小的成员。
- **境外保单**：除产品外还涉及收入来源、汇率、跨境支付、资料翻译、法律管辖和服务距离。
- **返钱型产品**：现金返还不等于高收益，必须同时看保障成本、现金价值、期限和流动性。

## Mental Models

- 用“功能比较表”代替“哪个更好”：覆盖对象、触发条件、金额、期限、限制、服务。
- 用“证据层级”回答争论：现行合同与规则优先，其次是可验证数据，最后才是经验。
- 把保险看作长期合同，不把短期销售承诺当成合同权利。

## Anti-patterns

- **绝对安全叙事**：用“保险公司绝不会倒”替代偿付能力和接管机制说明。
- **病种堆砌**：只强调数量，不解释定义重叠和实际触发。
- **收益错觉**：把返还金额直接当收益，忽略时间价值和保障成本。
- **不可抗辩投机**：鼓励客户隐瞒健康事实，可能同时制造拒赔、解除和销售合规风险。

## Worked Example

客户说“我有社保，不需要商业保险”。先确认其担心的是医疗费还是收入中断；再列社保可覆盖范围、自费项目、封顶线和家庭责任；最后只针对未覆盖缺口讨论医疗、重疾或寿险。结论不是“必须买”，而是让客户看见哪些风险仍由家庭自留。

## Key Takeaways

1. 每个争论都要回到具体合同和客户事实。
2. 社保与商业保险解决的问题有重叠，也有明显边界。
3. 产品数量、病种数量和返还金额都不能单独代表价值。
4. 跨境配置必须把服务、支付和法律成本纳入比较。
5. 如实告知是投保质量的基础，不是可以绕开的流程。
