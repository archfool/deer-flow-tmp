# Chapter 7: 买前策略

## Core Idea

买前阶段的任务不是尽快获得报价，而是完成深度风险分析、确定合理保额和预算，再选择能够长期服务的保险公司、专业人员与产品组合。

## Frameworks Introduced

- **深度风险分析**：同时采集家庭结构、收入支出、资产负债、健康、职业、已有保障和未来变化。
  - How：事实清单 → 风险事件 → 财务后果 → 已有资源 → 保障缺口 → 优先级。
- **买多少与花多少分离**：保额由损失后果决定，保费由产品结构和预算决定；不能直接用预算替代保额测算。
- **公司—人员—产品三层选择**：公司决定承保与服务基础，服务人员影响持续管理，产品决定合同责任。
- **如实、准确地表达健康信息**：既不能淡化，也不要把“小三阳、病毒携带、肝炎”等不同状态混为一谈。

## Key Concepts

- **道德风险控制**：保额远高于合理收入和责任时，保险公司会关注出险获利风险。
- **核保**：保险公司依据健康、职业、财务等信息决定标准承保、加费、除外、延期或拒保。
- **长期责任比例**：长期终身产品比例越高，通常越占用持续保费预算，需要与阶段性产品平衡。
- **服务整合**：由一个专业人员协调整理多家公司保单和理赔，可以降低家庭管理成本。

## Mental Models

- 把投保看成家庭财务项目，而不是一次商品采购。
- 先确定“必须解决”，再区分“可以优化”和“暂缓处理”。
- 公司、服务人员和产品分别打分，避免一个优点掩盖其他短板。

## Anti-patterns

- **预算即保额**：手里有多少钱就买多少保障，导致核心缺口未解决。
- **健康描述失真**：夸大或淡化都可能影响核保和未来理赔。
- **只追单一明星产品**：忽略家庭需要多个责任和期限组合。
- **多头购买无人管理**：出险时家人不知道有哪些保单、找谁报案。

## Worked Example

一名客户有房贷、孩子和稳定收入，已有单位医疗与少量意外险。买前分析应先计算家庭在其身故或长期失能后的债务和生活缺口，再扣除已有保障；医疗费用与收入替代分开配置；最后根据预算决定定期与长期责任组合，而不是直接拿预算购买一款返还产品。

## Key Takeaways

1. 完整事实是方案质量的上限。
2. 先算保额，再用产品结构适配预算。
3. 健康和财务信息必须准确表达。
4. 公司、服务和合同责任应分层评价。
5. 购买前就要设计后续保单管理方式。
