# Chapter 3: 保费、保额与保险服务

## Core Idea

保险的核心不是“交了多少钱”，而是风险发生时能否获得足以维持生活的资金和服务。保费决定当期负担，保额决定风险发生后的补偿能力，两者必须同时可持续。

## Frameworks Introduced

- **保额价值优先**：如果赔付不足以抵御风险，再低的保费也不能完成保障目标。
  - When to use：预算有限、需要在多个产品间取舍时。
  - How：先测算损失缺口和目标保额，再选择责任纯粹、价格可承受的组合。
- **阶段性保护费**：不同人生阶段的收入、负债、抚养责任和储蓄不同，保障需求应随阶段变化。
  - How：每次家庭角色、收入、负债或健康状态发生显著变化时重新检视。
- **保险的危机现金流作用**：保险不能阻止死亡、疾病和意外，但能降低事件对家庭生活、教育和债务偿还的冲击。
- **产品外延服务**：医疗协助、紧急救援、费用垫付和资料指引可能降低事故处置成本，但必须确认服务触发和供应范围。

## Key Concepts

- **保费**：为获得合同保障而支付的价格，需要与长期现金流匹配。
- **保额**：风险发生时用于补偿损失或责任的金额基础。
- **保障缺口**：目标损失减去已有社保、单位福利、储蓄和既有保单后的差额。
- **救援服务**：围绕就医、转运、翻译、法律援助等提供的辅助安排，不等于保险金责任。
- **服务触发条件**：服务能否使用取决于地点、事故类型、供应商和合同约定。

## Mental Models

- 保费看“今天能不能持续交”，保额看“明天出险够不够用”。
- 把保险当作家庭资产负债表的稳定器，而不是收益竞争工具。
- 把救援服务视为降低事故摩擦成本的第二层保障。

## Anti-patterns

- **按预算直接反推保额**：容易得到“买得起但不够用”的方案。
- **只追求高保额**：忽略缴费持续性，可能在家庭最需要保障前失效。
- **把增值服务当核心责任**：服务可能调整或受地域限制，不能替代合同赔付。

## Worked Example

一名刚工作的年轻人储蓄有限，发生疾病时既要承担自费医疗，也可能失去收入。配置顺序应是：先建立基本医疗费用上限，再用定额给付补收入中断；预算不足时优先责任和保额，不急于加入高储蓄属性。

## Key Takeaways

1. 先算缺口，再谈产品和保费。
2. 保额不足会让保险失去风险对冲意义。
3. 保费必须在不破坏家庭日常现金流的前提下持续。
4. 家庭阶段变化就是重新检视保障的触发器。
5. 服务价值需要单独确认，不能与保险金混为一谈。
