# Chapter 11: 常见保险术语

## Core Idea

保险“行话”不是记忆题，而是理解合同运行方式的入口。每个术语都应回答三个问题：它影响谁的权利、在什么时间触发、会改变多少钱或什么责任。

## Frameworks Introduced

- **合同状态框架**：主险与附加险、缴费期、宽限期、等待期共同决定合同何时有效、责任何时开始。
- **价值调整框架**：现金价值、减保、加保、保单贷款、减额交清和交清增额影响合同价值与保障规模。
- **责任扩展框架**：轻度重疾、特定疾病、多次赔付和豁免条款扩展基础保障，但都有触发和间隔限制。
- **利益处理框架**：累积生息、抵交保费和演示利率决定非领取利益如何处理及如何展示。

## Key Concepts

- **主险与附加险**：主险可独立存在；附加险通常依附主险，终止条件可能联动。
- **现金价值**：长期合同积累的合同价值，可用于退保、贷款或部分变更，但不等于已交保费。
- **减额交清**：停止后续缴费，用已有价值换取较低保额并维持合同。
- **减保/加保**：降低或提高保障金额；加保通常需要重新核保。
- **保单贷款**：以现金价值为基础借款，会产生利息并可能影响合同效力和赔付。
- **宽限期**：到期未缴费后的合同缓冲期；期内出险通常仍需按合同处理欠缴保费。
- **等待期**：合同生效后特定疾病责任尚未开始的期间；意外责任通常按合同另行判断。
- **豁免条款**：达到约定风险状态后免交后续保费，合同保障继续。
- **多次赔付**：同类或不同类疾病可多次触发，但受分组、间隔期、比例和定义限制。

## Mental Models

- 时间类术语回答“什么时候有效”。
- 价值类术语回答“现在退出或借款值多少钱”。
- 责任类术语回答“发生什么情况、赔几次、赔多少”。

## Anti-patterns

- **现金价值等于保费**：退保早期尤其可能明显低于累计保费。
- **宽限期等于免费保障**：欠缴保费仍可能从赔款或现金价值中处理。
- **多次赔付等于任何疾病反复赔**：忽略分组、间隔和首次责任终止条件。
- **演示利率等于保证收益**：把不确定利益误读为合同承诺。

## Worked Example

客户在疾病等待期内确诊，同时保单处于正常缴费状态。判断不能只看“合同有效”，还要分别核对疾病责任的等待期规则、意外原因例外、合同对等待期内确诊的处理方式。若客户是宽限期内出险，还需另行核对欠缴保费如何处理。

## Key Takeaways

1. 主险终止可能影响附加险。
2. 现金价值是合同管理数字，不是简单储蓄余额。
3. 宽限期、等待期和保险期解决不同时间问题。
4. 豁免和多次赔付必须核对触发、分组和间隔。
5. 所有术语的最终含义以具体合同为准。
