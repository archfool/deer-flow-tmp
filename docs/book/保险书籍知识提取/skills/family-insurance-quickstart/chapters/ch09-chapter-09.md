# Chapter 9: 买后策略与理赔管理

## Core Idea

理赔质量不仅由合同决定，也取决于报案时机、事实表述、证据保存、保单盘点和专业协助。买后管理的目标，是让家庭在最慌乱的时候仍能启动正确流程。

## Frameworks Introduced

- **第一时间报案与求助**：只要事故可能涉及保险，就尽早联系保险公司和专业服务人员。
  - Why it works：可及时确认责任、资料和紧急服务，减少事实记忆和证据丢失。
- **事实一致性原则**：按时间线客观描述事故，不猜测、不夸大，并及时纠正错误信息。
- **证据链管理**：保存病历、检查、费用票据、事故证明、沟通记录和保险公司回执。
- **全保单扫描**：一次事故可能触发多张医疗、意外、重疾、寿险或单位保单，应集中盘点。
- **争议分层处理**：先确认争议是责任范围、事实认定、资料不足、条款解释还是服务问题，再选择补充材料、申诉或法律路径。

## Key Concepts

- **报案**：向保险公司通知可能发生保险事故，并取得后续流程和材料要求。
- **理赔申请**：提交符合要求的事实和证明，由保险公司作出赔付判断。
- **事故时间线**：按发生、就诊、诊断、治疗和通知顺序整理的事实记录。
- **重复/多重保障**：同一事故可能在不同合同下产生不同责任，需逐张核对。
- **非正常赔付**：超出合同和规则的要求会损害其他投保人的共同利益，也不是有效争议解决方式。

## Mental Models

- 理赔不是“讲得严重就赔得多”，而是“事实、证据与合同责任能否对应”。
- 事故处理中先保人、再固证、后判断责任。
- 把所有保单做成家庭可找到的应急清单。

## Anti-patterns

- **迟延报案**：错过紧急服务或增加事实核验难度。
- **情绪化叙述**：前后描述不一致，引发额外调查。
- **资料随手丢弃**：关键票据和证明无法补办。
- **只申请一张保单**：客户或家属忘记单位和网络购买的其他保障。
- **用闹事替代证据**：不能改变合同责任，反而妨碍有效沟通。

## Worked Example

客户意外住院后情绪混乱。正确动作是先就医并通知保险公司，按时间线记录事故，保存原始病历和票据；由服务人员汇总医疗险、意外医疗、伤残和单位团险，分别核对责任；若出现拒赔，再根据拒赔理由补证或申诉，而不是先假设保险公司一定不赔。

## Key Takeaways

1. 可能涉及保险就尽早报案。
2. 客观、一致地记录事故事实。
3. 原始证据和沟通回执要集中保存。
4. 一次事故需要扫描家庭全部保单。
5. 争议处理从拒赔理由和证据缺口开始。
