# Chapter 6: 企业与个人投保的差异

## Core Idea

企业保险围绕资产损失、法律责任和员工风险组织；家庭保险围绕成员责任和生活现金流组织。两者都转移风险，但被保障对象、损失计算和方案结构不同。

## Frameworks Introduced

- **企业三类风险地图**：财产风险、对第三者的责任风险、员工疾病与意外风险。
  - When to use：为企业做初步风险盘点时。
  - How：按场所和资产 → 经营活动 → 外部人员 → 员工逐层列出事故与损失承担者。
- **责任险逻辑**：公众责任险、第三者责任险和雇主责任险保护的核心，是企业依法或依约应承担的赔偿责任。
  - Why it works：它把“别人受伤”转换为“企业的资产负债风险”。
- **团体平均与家庭差异化**：企业团险常按员工群体设置统一责任，家庭规划则应按成员的收入、负债和抚养责任区分额度。
- **一切险加责任扩展**：工程或财产保障可能需要附加第三者责任，避免只保护项目本身、不处理对外损害。

## Key Concepts

- **财产保险**：针对火灾、爆炸、自然灾害、盗窃等造成的企业财产损失。
- **公众责任**：经营场所或活动造成消费者等第三方人身或财产损害的责任。
- **第三者责任**：特定工程、车辆或活动对合同关系以外人员和财物造成损害的责任。
- **雇主责任**：员工在受雇工作中遭受伤害或职业风险时，企业依法承担的责任。
- **团体补充医疗**：在基本医疗保障之外，为员工群体增加医疗费用覆盖。

## Mental Models

- 企业风险盘点用“资产、责任、人”三个抽屉。
- 看到事故先问最终由谁赔钱，再选择责任险种。
- 团险解决群体基线，不等于替每个家庭完成个性化规划。

## Anti-patterns

- **只保企业财产**：忽略客户、访客和员工受伤可能带来的赔偿责任。
- **把团险当个人保障全部**：员工离职、额度不足或责任统一都可能留下缺口。
- **险种名称驱动**：没有从经营活动和责任链识别真实风险。

## Worked Example

建筑工程已投保建筑工程一切险，但施工坠物划伤路边车辆。工程本体没有重大损失，受损的是第三方财物。仅有工程财产责任可能无法解决全部问题，需要检查是否附加第三者责任保险及其限额、免赔和除外责任。

## Key Takeaways

1. 企业方案先画经营风险地图。
2. 责任险保护的是企业承担赔偿责任后的财务结果。
3. 财产、第三者和员工风险应分别检查。
4. 企业团险与家庭个人保障不能互相替代。
