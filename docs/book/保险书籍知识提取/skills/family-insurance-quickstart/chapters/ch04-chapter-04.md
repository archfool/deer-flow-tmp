# Chapter 4: 家庭生命周期保险规划

## Core Idea

保险规划由家庭责任决定，而不是由销售人员或单一产品决定。单身、新婚、育儿、家庭发展中期和退休前后的风险结构不同，方案必须随责任和现金流变化。

## Frameworks Introduced

- **生命周期规划**：按家庭阶段识别收入来源、被抚养人、负债、未来支出和健康风险。
  - When to use：首次规划或家庭发生结婚、生育、购房、收入变化、退休等事件时。
  - How：画家庭成员与责任图 → 计算主要责任人的损失缺口 → 处理医疗费用 → 安排长期现金流 → 预留调整空间。
- **主要人物原则**：家庭主要收入和责任承担者发生风险时，财务后果通常最大，应优先获得足额保障。
- **已有保障抵扣法**：目标保额减去单位福利、社保、既有寿险和意外险，得到新增缺口。
- **投保人豁免**：长期为孩子缴费的安排中，真正需要保护的是缴费人持续供款的能力。

## Key Concepts

- **单身阶段**：责任较轻但储蓄薄弱，重点防止医疗费用和失能收入中断。
- **新组建家庭**：需要处理夫妻双方医疗、收入替代、负债和未来生育计划。
- **家庭发展中期**：教育、房贷和赡养责任叠加，需要综合规划并保留变化空间。
- **家庭发展后期**：责任逐渐下降，但健康、养老和资产安排的重要性上升。
- **收入替代**：主要责任人不能工作或身故后，用保险金维持家庭必要支出。

## Mental Models

- 谁承担最多责任，谁的保障缺口通常最大。
- 家庭保险不是人均分配，而是按风险后果分配。
- 保额是动态变量：责任上升时补充，责任下降时重新评估。

## Anti-patterns

- **平均主义投保**：每个人买相同额度，忽略收入和责任差异。
- **孩子优先、大人裸保**：孩子真正依赖的是父母持续收入。
- **只看当前预算**：没有把未来3至5年的家庭支出和变化纳入设计。

## Worked Example

书中示例为主要责任人测算约700万元身故目标。其单位已有80万元寿险和100万元意外身故保障，因此新增缺口按 `700 - 80 - 100 = 520万元` 计算。这个例子展示的是“目标责任减已有保障”，不是要求所有家庭照搬700万元；目标值必须由收入、负债和抚养责任重新计算。

## Key Takeaways

1. 规划权属于家庭目标和事实，不属于产品。
2. 按风险后果决定成员间的保障优先级。
3. 目标保额应扣除可确认的已有保障。
4. 长期儿童规划要保护实际缴费人。
5. 每个生命周期转换点都应触发一次保单检视。
