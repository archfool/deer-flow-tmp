# Chapter 1: 风险、产品与理赔

## Core Idea

买保险不是先挑产品，而是先判断哪些损失自己承受不起，再选择相应的风险转移方式。理解理赔逻辑，才能反推产品是否真正覆盖目标风险。

## Frameworks Introduced

- **两种给付逻辑**：费用补偿型产品按实际支出报销，并受保额上限约束；定额给付型产品达到约定条件后按保额或比例赔付，资金用途通常不受医疗费用限制。
  - When to use：比较医疗险、重疾险、寿险和意外伤残责任时。
  - How：先问损失是“实际费用”还是“收入/责任缺口”，再判断需要报销还是现金补偿。
  - Why it works：它把看似相似的“赔钱”拆成两种不同问题，避免用医疗报销代替收入补偿。
- **价格背后的风险定价**：保费不是产品价值本身，而是保险公司基于发生概率、损失程度、责任范围和经营成本形成的价格。
  - When to use：客户只按保费高低比较产品时。
  - How：同时比较保额、责任触发条件、免责、期限和续保稳定性。
- **用理赔反推投保**：先设想风险发生时需要哪些钱、资料和服务，再检查保单是否能按预期启动。
  - Failure mode：只看宣传中的最高保额，没有核对普通伤残、免赔额或实际费用限制。

## Key Concepts

- **保额**：保险事故发生后计算赔付上限或定额给付的基础，不等同于任何情况下都能获得的金额。
- **费用补偿**：以实际发生且符合责任范围的费用为基础，通常不能超过实际损失。
- **定额给付**：达到合同约定状态后按固定金额或比例赔付，用于弥补收入、照护和家庭责任缺口。
- **赔付比例**：意外伤残等责任可能按伤残等级乘以保额，而不是直接赔付全部保额。
- **风险自留**：损失发生后由家庭自己承担；保险的意义是转移超出承受能力的部分。

## Mental Models

- 把医疗险想成“费用报销账户”，把重疾、寿险和伤残给付想成“家庭现金流补位工具”。
- 先画损失清单，再画保单责任清单；两者无法对应的部分就是保障缺口。
- 价格便宜不等于成本低：不能发挥作用的保单，其机会成本可能高于保费。

## Anti-patterns

- **把所有赔付都理解为报销**：会忽略收入中断、长期康复和家庭责任等非票据损失。
- **把最高保额当成必赔金额**：忽略免赔、比例、触发条件和责任期限。
- **先产品后风险**：容易为产品特征寻找需求，而不是解决家庭真实问题。

## Worked Example

一个家庭担心重病。住院账单可以由医疗险解决，但康复期间收入下降、照护支出和房贷并不都能凭发票报销。正确拆法是：医疗费用用费用补偿型产品覆盖；收入和责任缺口用定额给付型产品覆盖；最后检查两者的免赔、等待期和保额是否足够。

## Key Takeaways

1. 先区分费用损失与现金流损失。
2. 保额只是计算基础，实际赔付取决于责任和触发条件。
3. 产品比较必须同时看价格、责任、限制和可持续性。
4. 用“如果今天出险，钱从哪里来”检验保障是否有效。
