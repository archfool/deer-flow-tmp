# Chapter 10: 建议书与合同阅读

## Core Idea

建议书用于解释和演示，保险合同才确定权利义务。阅读时先验证身份和责任，再核对金额、期限、限制与现金价值，不能把销售口头表述或演示收益当成保证。

## Frameworks Introduced

- **建议书核对清单**：身份信息、产品名称、责任、保额、保费、缴费期、保险期、演示假设和重要提示。
- **口头承诺落纸法**：凡是“随时取钱”“最高赔100万”“固定收益”等关键说法，都要求在正式材料中找到对应金额、条件和限制。
- **合同五要素阅读**：保什么、保多久、赔多少、什么不赔、如何维持与解除。
- **最高额度拆解**：确认最高保额对应身故、全残还是普通伤残，以及比例计算基数。
- **演示与保证分离**：预期或演示利率用于说明可能结果，不等于合同保证收益。

## Key Concepts

- **保险建议书**：投保前展示方案和利益的说明材料，不是最终合同。
- **保险条款**：规定保险责任、责任免除、期间、申请和双方权利义务的合同组成部分。
- **保证利益**：合同明确承诺且满足条件即可获得的利益。
- **非保证利益**：受经营、分红或市场等因素影响，实际结果可能变化。
- **责任免除**：合同明确不承担赔付责任的情形。
- **现金价值**：长期合同在特定时点退保、贷款或变更时的重要金额基础。

## Mental Models

- 把建议书看成地图，把合同看成法律边界。
- 任何“能不能”问题都继续追问“在什么时间、什么条件、多少钱”。
- 先读责任和免责，再看收益演示。

## Anti-patterns

- **把PPT当合同**：宣传页面无法替代正式条款。
- **只看最高数字**：忽略触发条件和比例计算。
- **把预期收益当固定收益**：错误理解非保证利益。
- **身份信息不核对**：年龄、性别等错误会影响保费、核保和合同处理。

## Worked Example

销售人员说某意外险“最高赔100万元”。客户应在建议书和条款中查明：100万元是否仅限身故或全残；普通伤残是否按10万元或其他基数乘比例；意外医疗是否另有免赔和限额。只有责任、基数和比例全部明确，最高数字才有决策意义。

## Key Takeaways

1. 建议书负责说明，合同负责约束。
2. 身份、责任、金额、期限和免责逐项核对。
3. 口头关键承诺必须在正式文件中定位。
4. 演示利益与保证利益严格分开。
5. 读合同的目标是知道何时能启动、能得到什么。
