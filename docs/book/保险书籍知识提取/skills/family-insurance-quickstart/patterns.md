# 方法模式

## 1. 家庭风险缺口测算

**何时使用**：首次规划、收入或负债变化、家庭成员新增、旧保单复核。

**怎么做**：
1. 分别估算医疗支出、收入恢复期、身故责任、债务、教育和赡养责任。
2. 扣除社保、单位福利、可变现资产和已有保单。
3. 按风险类型选择费用补偿或定额给付工具。
4. 最后用预算调整期限、免赔和产品组合，不直接压低核心保额。

**权衡**：测算依赖假设，应把收入增长、通胀和资产流动性作为情景变量，而不是伪装成精确预测。

## 2. 报销层与现金层组合

**何时使用**：疾病或意外既会产生医疗发票，也会造成停工、康复、照护等非发票损失。

**怎么做**：先用医疗类保障覆盖符合责任的实际费用，再用重疾、寿险或伤残给付覆盖收入与责任缺口；检查免赔额、既往症、等待期和给付触发条件。

**权衡**：两层并非越多越好。已有单位福利、家庭现金储备和预算都可能改变组合比例。

## 3. 生命周期触发式检视

**何时使用**：结婚、生育、购房、换岗、创业、收入显著变化、父母进入赡养期或家庭成员健康变化时。

**怎么做**：重新计算责任期限和金额，检查主要责任人、受益人、缴费能力及旧产品是否仍匹配；没有重大事件也每一至两年复核一次。

**权衡**：频繁换单可能带来等待期重启、核保变化和退保损失，调整前先比较“保留、加保、减保、替换”。

## 4. 主要责任人优先

**何时使用**：预算不能同时满足所有家庭成员的理想保障时。

**怎么做**：按事故对家庭现金流和责任履行的影响排序，先保障收入与照护责任最重的人，再配置儿童和老人可获得且性价比合理的保障。

**权衡**：优先级不是情感价值排序；儿童医疗风险和老人现有健康限制仍需单独处理。

## 5. 公司、服务人员、合同三层选择

**何时使用**：面对多个品牌和方案，或销售陈述过度集中在公司规模、熟人关系、产品热点时。

**怎么做**：
- 公司层：核验主体、服务能力和当前公开监管信息。
- 服务层：检验需求分析、告知提示、持续服务和利益冲突。
- 合同层：比较责任、定义、除外、期限、续保、保全和成本。

**权衡**：三个层面不能互相替代；品牌可靠不代表每个产品都适配，条款合适也不等于服务过程可以忽略。

## 6. 关系人四问

**何时使用**：寿险、长期险、家庭资产安排，以及婚姻或债务关系变化时。

**怎么做**：逐项回答“谁缴费、谁被保障、谁控制合同、谁领取保险金”，再检查受益顺序、比例、备用受益人和变更权限。

**权衡**：关系人安排会影响控制、税务、继承和债务风险；复杂家庭须结合当前法律和专业意见。

## 7. 理赔证据链

**何时使用**：事故发生至理赔结束全过程。

**怎么做**：及时报案，建立时间线，保存医疗、事故、身份、费用和沟通记录；按全部有效保单逐一核对责任；收到结论后针对具体条款和事实处理补件或争议。

**权衡**：材料越多不等于越有效。优先证明事故发生、因果关系、损失金额及合同触发条件。

## 8. 建议书与合同双重核对

**何时使用**：投保决定前，以及销售人员使用“最高、保证、随时、全部”等绝对表达时。

**怎么做**：把建议书中的每个关键承诺映射到正式条款，标注金额、时间、触发条件和除外；将保证利益与非保证演示分栏。

**权衡**：建议书适合沟通结构，合同适合确定权利义务；只看其中一份都会丢失信息。
