# 家庭保险决策速查

## 先判断损失类型

| 问题 | 主要损失 | 优先考虑的给付逻辑 |
|---|---|---|
| 治疗花了多少钱 | 符合约定的实际医疗费用 | 费用补偿 |
| 生病后多久不能工作 | 收入中断、康复和照护成本 | 定额给付 |
| 家庭责任人身故会留下什么 | 债务、抚养、教育、赡养缺口 | 定额给付 |
| 小额损失家庭能否自行承担 | 可承受的频繁小额损失 | 风险自留或设置免赔额 |

## 保额缺口公式

`新增保障 = 目标责任 - 社保/单位福利 - 可变现资产 - 既有保单`

先算责任，再谈预算。预算不足时依次考虑调整产品结构、保障期限和非核心责任，避免用低保额制造“已经配置”的错觉。

## 生命周期重点

| 阶段 | 重点问题 |
|---|---|
| 单身期 | 医疗费用、失能或重疾导致的收入中断 |
| 新婚育儿期 | 主要责任人、房贷、子女教育、父母赡养 |
| 发展中期 | 责任峰值、多期限组合、旧保单补缺 |
| 责任下降期 | 医疗、养老、流动性、关系人与资产安排 |

## 买前检查

- 风险清单是否先于产品清单？
- 费用补偿和定额给付是否分开测算？
- 是否扣除了社保、单位福利、资产和旧保单？
- 健康和职业询问是否如实、完整、留痕？
- 公司、服务人员、合同责任是否分别评价？
- 关键承诺能否在正式条款中定位？

## 持有期检查

- 联系方式、缴费账户和合同状态是否正常？
- 投保人、被保险人、受益人顺序与比例是否仍合适？
- 收入、负债、婚姻、生育和赡养责任是否变化？
- 加保、减保、保留或替换的成本是否完整比较？

## 理赔检查

- 及时报案，但不要把报案当作已经申请理赔。
- 记录事故时间线，保存原始证据和沟通记录。
- 扫描家庭全部有效保单，不只看最熟悉的一张。
- 对照责任定义、除外、等待期和特别约定准备材料。
- 对拒赔或少赔，先取得具体理由和条款依据再处理争议。

## 高风险表达

遇到以下说法，必须追问“在什么时间、什么条件、多少钱、写在哪条”：

- “一定赔”“什么都管”
- “随时取、没有损失”
- “演示收益就是到手收益”
- “熬过两年，隐瞒也没关系”
- “病种越多一定越好”
- “公司大，所以不用看条款”
